# 规则

> 这份文件是规则的唯一真值。要改规则，先改这里，再改 `core/` 下的代码，最后同步 `README.md`（技术文档）。
> 文中所有分数、倍数、级数结论都可以用 `core/game.js` 的 `upgradeSteps` / `resolveTrick` 直接跑出来核对。

## 1. 人数、用牌、分值

| 项目 | 取值                                                    |
| ---- | ------------------------------------------------------- |
| 人数 | 4 人，隔位两人一队（座位 0/2 一队，1/3 一队）           |
| 用牌 | 两副共 108 张（4 花色 × 13 点 × 2 + 小王 ×2 + 大王 ×2） |
| 发牌 | 每家 25 张，底牌 8 张                                   |
| 分牌 | 5 计 5 分，10 计 10 分，K 计 10 分                      |
| 总分 | 两副牌合计 200 分                                       |

## 2. 级别与主牌

- 双方各有级别，都从 **2** 起，逐局按成绩往上爬。
- 当前坐庄那一方的级别，就是本局「打几」。例：我方打 5、对方打 3，庄家是我方 → 本局打 5。
- **级牌** = 当前级别的四张花色牌（打 10 时，四门 10 都是级牌）。级牌永远算主牌。
- **主牌** = 大王 + 小王 + 四门级牌 + 主花色的其余牌。主牌整体算「一门」，出牌时和副牌花色平级参与比较。
- **无主**：只有大王、小王、四门级牌是主牌（没有主花色）。

## 3. 主牌大小（tier）

内部用 `tier` 整数表示大小，数字越大越强。以「打 10、主红桃」为例：

| tier   | 牌                                                                 |
| ------ | ------------------------------------------------------------------ |
| 15     | 大王（2 张）                                                       |
| 14     | 小王（2 张）                                                       |
| 13     | 主级牌：红桃 10（2 张）                                            |
| 12     | 副级牌：黑桃 10 / 梅花 10 / 方片 10（共 6 张，彼此等大，互不压制） |
| 11 → 0 | 红桃 A、K、Q、J、9、8、7、6、5、4、3、2（级牌抽走后 9 与 J 相邻）  |

- 无主时：四门级牌全部等大（同一 tier），小王、大王各升一级。
- 副牌按 A > K > Q > J > 10 > 9 … > 2 排列。
- **相邻 tier 即视为连续**：所以「副级牌对 + 主级牌对 + 王对」可以串成连对（拖拉机）。

## 4. 亮主与反主

亮主阶段分三轮，每轮从同一个起始座位按座位顺序走一圈，一旦有人成功立即进入下一轮：

| 轮次    | 手段                         | 结果                                     |
| ------- | ---------------------------- | ---------------------------------------- |
| 第 1 轮 | 一张级牌                     | 定该花色为主，**先亮者得**，本轮立即结束 |
| 第 2 轮 | 一对同花色级牌               | 反主：换掉当前主花色                     |
| 第 3 轮 | 一对王（两张大王或两张小王） | 反无主                                   |

补充约定：

- 第一局的起始座位随机；之后每局由上一局庄家起手。
- 第 1 轮一旦有人亮主就结束，所以同级之间不存在互反。
- 第 2、3 轮只有在已经有人亮主的前提下才进行；**没人亮主则直接收尾**，不存在反主。
- 收尾时若仍无人亮主：翻底牌找第一张级牌，其花色即主；底牌没有级牌则无主。
- **第一局由首亮者坐庄**；没人亮主时随机指定庄家。

## 5. 埋底（扣底）

1. 庄家把 8 张底牌收入手牌，共 33 张。
2. 庄家从 33 张里扣 8 张回底，扣下的牌不公开。
3. 底牌分只在最后一墩被闲家赢走时结算（见第 8 节）。

## 6. 出牌规则

**首家**（庄家开第一墩，之后每墩由上一墩赢家首出）可以出同门任意组合，「同门」指同一副牌花色，或全部属于主牌：

| 牌型           | 说明                                               |
| -------------- | -------------------------------------------------- |
| 单张           | 任意 1 张                                          |
| 对子           | 同花色同点数 2 张                                  |
| 连对（拖拉机） | 2 对及以上，且 tier 连续，如 tier 5/6 两连对       |
| 甩牌           | 同门多组牌一起打出（如 1 对 + 2 单张、两对不连续） |

**甩牌失败**：只要其他任意一家在该门里存在能压过其中某一组（单张或对子）的牌，这次甩牌不成立，实际只打出其中**最小的一组**，界面会提示「甩牌被压」。

**跟牌**（其余三家）：

1. 张数必须与首家完全一致。
2. 本门牌够 → 必须跟本门；且首家出对子 / 连对时，手里有对子必须跟足对子数量（跟不足则按实际能跟的对子数，规则上要求「有几个跟几个」）。
3. 本门牌不够 → 本门剩余的牌必须全部打出，缺的张数用别门补足（补什么花色不限，可以补主牌，也可以几门混着垫）。
4. 跨门混垫的那一手按「垫牌」处理，永远压不了人。

**比较大小**（决定这一墩归属）：

- 同门比 tier，大者赢。
- 主牌可以压任意副牌花色；不同副牌花色之间互不比较（首出黑桃时，红桃再大也压不过）。
- 对子数量少于首家的一手，无论多大都不能赢（不能拿单张冒充对子）。

## 7. 赢墩与收分

- 一墩四家出完后，最大的一手收走本墩所有分牌，分数记给该手所在队伍。
- 只有**闲家**（非庄家队）的得分决定升降级；庄家队收到的分只是阻止闲家得分。
- 因为允许甩牌，一局不一定是 25 墩，手牌出完即结束。

## 8. 抠底

最后一墩由**闲家**赢走时触发抠底：底牌 8 张的分值全部归闲家，并按赢牌那一手的对子数量翻倍。

| 最后一手 | 倍数 | 说明    |
| -------- | ---- | ------- |
| 单张     | ×2   | 2^(0+1) |
| 1 对     | ×4   | 2^(1+1) |
| 2 连对   | ×8   | 2^(2+1) |
| 3 连对   | ×16  | 2^(3+1) |

最后一墩由庄家队赢走则不抠底。

## 9. 升降级（闲家得分 = 抓分）

| 闲家得分  | 结果     | 庄家队级别 |
| --------- | -------- | ---------- |
| 0         | 大光     | +3         |
| 5 ~ 35    | 小光     | +2         |
| 40 ~ 75   | 保级升级 | +1         |
| 80 ~ 115  | 闲家上台 | 不变       |
| 120 ~ 155 | 闲家上台 | 闲家 +1    |
| 160 ~ 195 | 闲家上台 | 闲家 +2    |
| 200       | 闲家上台 | 闲家 +3    |

- 门槛 80 分 = 200 分的一半。
- 不换庄时（庄家队升级），由庄家的**对家**坐下一庄（队内轮庄）。
- 闲家上台时，由庄家的**下一座位**坐庄。

## 10. 过 A 与通关

- 打到 A（庄家队级别 = A）时，只要**保级**（闲家不足 80 分）即通关，比赛结束。
- 打 A 被打下台则继续打 A，不会降级。
- 升级不跳过 A：跳级最多停在 A（如打 K 大光也只到 A）。

## 11. 本实现的取舍（与部分地方规则的差异）

- 只做 4 人 2v2，不做 6 人、找朋友、抄底等玩法。
- 不实现「加固」（同一花色再补一张级牌加固定主）。
- 甩牌被压只降级为最小一组，不做额外罚分。
- 本门不足时的跟牌不强制「优先跟对子」，只要求本门牌全部打出。
- 抠底只翻底牌分，不做「底牌翻倍再乘」的叠加。
- 不做叫分 / 加倍。
- 三家 AI 自动亮主、埋底、出牌；玩家操作座位 0（「你」）。
- 托管：可把座位 0 也交给 AI（顶栏「托管」或 `T` 键）。托管只借用同一套 AI 决策、自动续局，不改变任何规则；打到一方过 A 通关时自动停止。
- 调试面板（`~` 键）：亮出四家手牌与底牌，支持换牌与「下局必进某张」的发牌安排。所有调试动作只做位置置换，牌堆恒为两副牌（108 张、每种牌 2 张），每次操作后自动体检，不完整即回滚。
