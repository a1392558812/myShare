## 目标

28 只星宿在地图上各自巡游，点它 → 玩家走过去 → 进入 1v2 星宿战 → 打完回地图；被击败/捕获的 60 秒后换个位置重生。

## 需求来源

README §11.5（二十八星宿：等级口径 / 刷新与全清 / 战斗形态）、§11.5.1（28 宿表）、§4.1（战斗形态）、§17.1 A-05

## 本期做什么

- [ ] 生成：每层 28 只全部出现（不是随机抽 10 只），等级 = `n + 偏移(−3…0)`，出生阶位按 9.3 加权 roll（**地图不显示阶**）
- [ ] 游荡：每只在自己所属的环形扇区里随机选点、走过去、停 1–3s 再选；速度 80–110px/s，用 4 邻简单避障（不接 A*，避免 28 只同时寻路）
- [ ] 点星宿：命中半径 26px → 玩家自动寻路到 90px 内 → 进入战斗
- [ ] 星宿战：敌方只有 E1（本尊），E2/E3 空置；战斗时长目标 20–40 秒
- [ ] 结束回地图：胜利后该星宿消失、60 秒后在同一环形区域另一处重生（阶位重新 roll）；逃跑后星宿回满血留原地
- [ ] 未清计数：击破或捕获都写入 `mobDefeated`（捕获取值在 34 期接，本期先只记击破）
- [ ] 20–40 秒**不达标不改数值**：只记录实测 TTK 到补充需求，数值调整是第 41 / 42 期的事

## 本期不做（防膨胀）

- 不做捕捉投绳 → 第 34 期
- 不做掉落（装备/兽魂/灵石）→ 第 32 期（本期战斗结束只给经验占位）
- 不做星宿 AI 技能 → 星宿只用普攻（技能留给 19 期星君）
- 不做图鉴记录 → 第 22 期

## 验收

1. 地图上数得到 28 只星宿，各自在动，不会全部挤成一坨。
2. 点一只星宿：玩家绕障走过去，到 90px 内自动进战斗，敌方只有 1 个单位。
3. 打赢回地图：该星宿消失；等 60 秒在原地附近的另一处重新出现。
4. 逃跑回地图：星宿仍在原位、满血。
5. 第 1 层星宿等级在 1–4 区间（偏移 −3…0 加层数），第 10 层在 7–10 区间。
