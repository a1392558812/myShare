## 本期做什么

- [ ] 携带上限 3 / 仓库不限；`activePetId` 唯一；战斗外可换宠（拖动或点击"出战"）
- [ ] 宠物面板（配置页 · 宠物标签）：等级、六维（气血/物攻/法攻/防御/速度/法力）、成长、五项资质、亲密度、加点入口
- [ ] 宠物加点：每级 4 点、四项系数照 9.5（力量 1.6 / 敏捷 0.55+0.12+0.15 / 体质 6.5+0.22 / 灵力 0.8+1.5），免费重置

- [ ] 亲密度：初始 50、上限 100；显示与影响（本期只做数值与显示，影响具体收益按 9.10 表接）

- [ ] 战斗锁：战斗中换宠/加点全部拒绝
- [ ] 空状态：无宠物时宠物页显示"尚未收服任何星宿"

## 验收

1. 抓 4 只宠物：携带只显示 3 只，第 4 只自动进仓库，仓库不限。
2. 换宠后战斗 S2 槽的立绘换成新宠，属性面板同步。
3. 宠物等级 = 主人 + 15 时再给经验，等级不动。
4. 宠物加点后六维按 9.5 变化；重置后回到分配前。
5. 战斗中打开宠物页：换宠与加点按钮灰显。
