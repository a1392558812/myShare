# 第 04 期 · 回合状态机与速度序列

> 阶段 B ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：03

## 目标

纯内核跑得动一场战斗：能开打、能每回合收指令、按速度排序逐个出手、能结束；全程只输出事件数组，控制台能读完整回放。

## 需求来源

README §4.1（战斗形态）、§4.2（回合状态机）、§4.3（出手顺序与速度）、§3.10（事件流解耦）

## 本期做什么

- [ ] `core/battle.js`：`createBattle({ allies, enemies, mode })`，`mode ∈ starLord | mansion`
- [ ] 阶段流转：`roundStart → command → resolve → roundEnd`，每阶段末尾 `emit(phase)` 事件
- [ ] 速度序列：按 `spd` 降序排一次，回合内不变；同速按 `id` 升序（确定性，便于复现）
- [ ] 指令枚举先只开 `attack` 与 `defend`；其余（法术/道具/捕捉/逃跑/换宠/召唤）留空槽返回 `{ ok: false, reason: '未开放' }`
- [ ] 防御指令：本回合受伤 ×0.5 并解除（数值取自 4.4 的 `MIT` 段，防御只做这一个效果）
- [ ] 命中/伤害先写死为 `target.hp -= 1`，只验证"谁先谁后、谁跳过"（真实判定进第 05 期）
- [ ] `core/events.js`：事件类型常量集中管理，本期只放 `BATTLE_START / ROUND_START / TURN_START / TURN_END / ROUND_END / BATTLE_END`
- [ ] 自动战斗开关：`battle.auto = true` 时玩家侧指令自动选 `attack`（不做 1.5×，那是星君战 P1）
- [ ] `.tmp/battle.mjs` 探针：固定两队（玩家 100spd / 宠物 88 / 星君 95 / 四象 92·90），跑 20 回合打印顺序

## 本期不做（防膨涨）

- 不做真实伤害、闪避、暴击 → 第 05 期
- 不做倒地/起身，`hp<=0` 先直接移出队列 → 第 06 期（届时改回"留队跳过"）
- 不做表现层订阅与动画 → 第 12 / 13 期
- 不做连锁裁决（同帧多目标结算顺序）→ 第 09 期

## 验收

1. 探针输出 20 回合，每回合出手顺序严格按 `spd` 降序，同速时稳定（连跑 3 次结果一致）。
2. 一方全灭时立刻发 `BATTLE_END`，不再进入下一回合。
3. 玩家指令未提交时不进入 `resolve`（阻塞等待）。
4. `battle.auto = true` 后无需外部输入，战斗能自行推进到结束。
5. `core/battle.js` 内无任何 `setTimeout` / `requestAnimationFrame`——节奏由外部驱动。
