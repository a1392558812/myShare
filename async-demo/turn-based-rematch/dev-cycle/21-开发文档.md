# 第 21 期 · 星宿全清与扫荡

> 阶段 D ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：20

## 目标

28 星宿全清后右上出现扫荡面板：每 45 秒累积一场，离线也累积；点领取一次拿到经验、灵石与本批抓到的宠物（低概率），离开本层自动结算。

## 需求来源

README §11.5.3（刷新与全清）、§11.6.2（扫荡）、§9.4.1（扫荡捕捉）、§12.6.1（捕捉期望）、§14.2（`tower` 字段）

## 本期做什么

- [ ] 全清：`mobDefeated` 集合（击破或捕获都记），28/28 时解锁扫荡并在提示条显示"可扫荡"；重生不清除记录
- [ ] 扫荡面板（右上 940,120,300,190）：`扫荡中` / `已累积 N 场` / `已抓 N 只` / `领取`；领取时向下展开战果列表
- [ ] 节奏：每 45 秒一场，用时间戳差值计算（`floor((now - lastTick) / 45000)`），页面关闭再打开能补上离线场次
- [ ] 收益：经验 `0.6 × 本层星宿平均经验`、灵石 `1.0 × 本层星宿平均灵石`；**无装备、无兽魂、无牛皮**
- [ ] 捕捉：每场先等概率抽本层一只星宿（种族 + 偏移），再按 `出现率 × 0.16` 逐阶判定，最多一只；命中即 `createUnit('pet')` 入仓
- [ ] 战果列表：`经验 +N / 灵石 +N` + 宠物逐条（种族 · 阶 · Lv · 五行 · 定位），未抓到时列表只有两行
- [ ] 领取：经验进 `expPool`（**不自动升级**，见 22 期）、灵石进账、宠物进仓库、队列清空
- [ ] 离开本层（登塔 / 回退）：未领取的自动结算入账，队列清空
- [ ] 存档：`tbr.tower` 增加 `lastSweepAt`、`pendingExp`、`pendingGold`、`pendingPets[]`；`visibilitychange` 时立即写盘

## 本期不做（防膨胀）

- 不做扫荡上限（第一期不设上限，P2 再议）
- 不做扫荡的战斗演出（完全是后台计算）
- 不做手打投绳捕捉 → 第 35 期
- 不做图鉴与"已捕获最高阶"记录 → 第 22 期

## 验收

1. 清完 28 只后扫荡面板出现；面板出现前点不到。
2. 面板停留 4 分 30 秒 → `已累积 6 场`（45s × 6）。
3. 关掉标签页 8 分钟再回来 → 场次按实际时间补上（不是从 0 开始）。
4. 连领 100 场（调试按钮直接 +100）：大致得到 11 野生 / 4 宝宝 / 0.9 变异，全部进仓库且不占携带 3 格。
5. 不点领取直接登塔：经验与灵石照样入账，队列清空，没有丢东西。
