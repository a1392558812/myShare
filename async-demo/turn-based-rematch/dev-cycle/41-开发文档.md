## 本期做什么

- [ ] 背包 24 格，只放道具与材料（装备走 60 格仓库）；同种堆叠，显示 `×N`
- [ ] 道具表照 10.2 落地：回血药、回蓝（清心散）、解控、捆仙绳 120、九转金丹、洗髓丹 300、洗髓丹碎片、天外陨石、兽魂 200
- [ ] 战斗快捷栏 8 格（13 期已画）：药物可用、捆仙绳固定第一格、空格虚线框
- [ ] 商店四个标签：`买` / `卖` / `强化` / `镶嵌`；洗髓与内丹入口在配置面板（30 / 38 期）
- [ ] 库存：药品与绳子无限；宝石 / 兽诀 / 天外陨石每层各 3 件；洗髓丹 2 个/层
- [ ] 每层刷新：进层时重置库存与已购数量（20 期已留钩子）
- [ ] 卖出：按 7.3 品质给价（凡 10% / 仙 60% 之类以 10.3 为准），卖出二次确认
- [ ] 灵石不足：按钮灰显 + 差额；背包满：买不进并 toast
- [ ] 补齐 33 期留下的筛选：装备仓库可按**品质 / 是否套装**筛选，背包可按类别筛选
- [ ] 九转金丹：把倒地目标拉起来（玩家或敌方都能用），与"宠物不可复活"不冲突

## 本期不做（防膨胀）

- 不做拍卖行 / 玩家交易（需求明确不做）
- 不做商店刷新收费
- 不做道具快捷购买（背包内点击直接补货）
- 不做道具的品质差异（同名同效）

## 验收

1. 买 3 个回血药：背包出现 `回血药 ×3`；再买 22 格不同道具，第 25 格提示"背包已满"。
2. 装备 60 格全满不影响背包买药。
3. 星宿战的 8% 药品掉落能叠到已有堆上，不新开格。
4. 进下一层后：宝石/兽诀/陨石库存回到 3、洗髓丹回到 2，已购数量清零。
5. 卖出仙品装备的灵石与 10.3 的回收比例一致。
