# 第 08 期 · 法术与法力

> 阶段 B ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：07

## 目标

玩家能用门派法术与通用法术打出单体/群体伤害，法力扣得对、放不出来时按钮就是灰的；并跑通 12.2 的"普攻单体系数 ≥ 法术单体 1.4 倍"校验。

## 需求来源

README §8.1（门派与法术点）、§8.2（门派法术表）、§8.3（通用法术）、§8.4（无槽位上限）、§8.5（法力无冷却）、§8.6（进修）、§12.2（对照表）、§17.2 R-03 / R-17

## 本期做什么

- [ ] `config/skills.js`：五门派主动法术 + 通用法术，字段 `{ id, school, element, power, mp, targets, kind: single|aoe, control? }`，数值照 8.2 / 8.3 抄，不自创
- [ ] 施法流程：选法术 → 检查法力 → 扣蓝 → 走第 05 期的判定链（法术用 `matk`）→ 产 `CAST` 事件
- [ ] 群体：多目标按槽位 S1→E3 顺序**逐个独立判定**（暴击/闪避各自 roll）；已倒地目标跳过、伤害不转移
- [ ] 无冷却：同法术可连续施放，只受法力限制；法力不足返回 `{ ok:false, reason:'法力不足' }` 供 UI 灰显
- [ ] 法力来源本期只做两条：普攻命中回 3% 最大法力、清心散以外的暂不做（回复法术在下一行）
- [ ] 木系回复法术：给目标回血，超上限溢出转护盾（上限 10% maxHp）——本期只做普通回血，护盾留到补充需求
- [ ] 法术进修：`skill.lv` 抬高 `power` 的接口与价格表（8.6），但**不做面板**，只用探针验证曲线
- [ ] 探针 `.tmp/skill.mjs`：固定 L=50 面板，算普攻单体 / 法术单体 / 法术群体三档伤害，核对 12.2 与 R-03

## 本期不做（防膨胀）

- 不做法术面板 UI（学 / 换 / 进修）→ 第 13 期只做战斗内滑出列表，配置页的法术标签在第 33 期随"配置面板"一起做
- 不做星君技能（AI 施法）→ 第 18 期
- 不做特效与弹道 → 第 14 期
- 不做装备/相性带来的法伤加成 → 第 26 / 28 期

## 验收

1. 12.2 校验：同等级同装备下 `普攻单体 / 法术单体 ∈ [1.40, 1.60]`，探针断言通过。
2. 群体法术打 3 个目标时，每个目标独立出现命中/闪避，倒地目标被跳过。
3. 法力 632 的 50 级玩家连放 50 蓝群攻，第 13 发返回"法力不足"。
4. 同一法术连续放 3 次无需等待（无冷却字段）。
5. 普攻命中后法力 +3% maxHp 对应的值，且不超过上限。
