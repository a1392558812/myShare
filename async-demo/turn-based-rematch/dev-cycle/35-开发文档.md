# 第 35 期 · 捕捉（手打投绳）

> 阶段 G ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：34

## 目标

星宿打到 20% 血以下，「捕捉」按钮亮起；投一次绳占一回合，成功则进仓库、失败则它回 10% 血继续打；连点不会无限刷。

## 需求来源

README §9.4（来源与捕捉 / 成功率 / 修正项）、§10.2（捆仙绳 120 灵石）、§17.1 A-05、§17.2 R-24

## 本期做什么

- [ ] 捕捉按钮：目标气血 ≤ 20% 时可点（第 5 键 / `G`），占玩家一次行动，消耗 1 个捆仙绳
- [ ] 成功率：`clamp(0.03, 0.95, 0.03 + (1 − 血量%) × 0.45 + 道具加成 + 阶修正)`
- [ ] 修正：捆仙绳 +25%、阶 野生 +10% / 宝宝 0 / 变异 −15% / 神兽 −30%
- [ ] 成功：`CAPTURE_OK` → 星宿消失、生成宠物（保留阶位与种族）、进仓库（携带未满则进携带）
- [ ] 失败：星宿回 10% 气血，战斗继续，本回合玩家已消耗；**失败不给任何补偿**
- [ ] 星君与四象：`捕捉` 按钮永不可用（R-24），点了提示"无法捕捉"
- [ ] 图鉴：捕获写入 `codex` 的"已捕获最高阶"
- [ ] 表现：绳光 #17 / 成功 #18 特效（15 期已备）
- [ ] 探针：血量 20% / 10% / 5% 三档的成功率与 9.4 的 0.64 / 0.69 / 0.71 对上

## 本期不做（防膨胀）

- 不做捕捉道具的其他种类（只有捆仙绳）
- 不做捕捉失败保底
- 不做扫荡捕捉（21 期已独立实现，两条通道互不影响）
- 不做"重开刷变异"的额外封堵（失败回血已足够，见 18.1）

## 验收

1. 星宿 25% 血时按钮灰显；打到 19% 立刻可用。
2. 血量 20% + 带绳抓宝宝：成功率 0.64，投 100 次命中约 64 次。
3. 抓神兽的成功率明显低于抓野生（同一血量下差 40%）。
4. 失败后星宿从 0.5% 血回到 10.5%，战斗继续。
5. 星君战里点捕捉：按钮灰、提示"无法捕捉"，不消耗绳子。
