# 第 07 期 · 道行与障碍控制

> 阶段 B ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：06

## 目标

六种障碍法术能按道行差命中、能被抗性削减、能持续 N 回合并正确解除；用探针复现"不买道行被稳定控住 / 买够后回到中位"两段曲线。

## 需求来源

README §4.7（道行与障碍）、§5.6（道行口径）、§6.3（障碍抗性）、§12.6（0.90 / 0.15 截断）

## 本期做什么

- [ ] `config/controls.js`：六种障碍登记（冰封 / 昏睡 / 眩晕 / 中毒 / 遗忘 / 定身），每条含 `duration` 与"是否阻止行动"
- [ ] 命中公式：`clamp(0.15, 0.90, 0.55 + (DAO攻 − DAO防) / (2 × 攻方等级))`，再乘 `(1 − R/(R+P))`，`P = 20 + 0.04 × 攻方等级`
- [ ] DAO 口径：玩家 `4 × 等级 + 已购道行`、宠物 `0.7 × 主人道行`、星君/星宿/四象 `6 × 等级`
- [ ] 状态槽：每单位一个 `control = { type, turns }`，同种刷新持续回合，**不同种覆盖**（不叠多层）
- [ ] 回合结束 `turns -= 1`，归零清除并发 `CONTROL_CLEAR`；被"解除"效果立即清除
- [ ] 阻止行动的障碍（冰封 / 昏睡 / 眩晕 / 定身）在轮到该单位时跳过，与倒地共用 `TURN_SKIP` 分支
- [ ] 冰封特殊：施加即清空其它 buff，期间免疫伤害与治疗（在 `applyDamage` / `applyHeal` 入口统一拦截，不做分叉）
- [ ] 中毒：回合结束扣 `0.02 × maxHp`（按 4.7 若未给具体系数，先按此实现并写进补充需求待确认）
- [ ] 探针 `.tmp/control.mjs`：玩家 Lv 与星君 Lv 的关系取 1.4 倍，验证被控率 ≈ 0.75；再买 `0.4 × 星君等级` 点道行，验证回到 ≈ 0.55

## 本期不做（防膨胀）

- 不做障碍的抗性来源（水相性点数 / 词条 / 套装）→ 第 26 / 28 / 31 期，本期 `R` 由参数注入
- 不做障碍图标与动画 → 第 14 期
- 不做"遗忘"屏蔽具体法术格 → 与 8.4"无槽位上限"冲突，本期先等同"跳过回合"，差异进补充需求

## 验收

1. 同级不买道行：星君对玩家施放障碍，命中率稳定落在 0.15 附近（探针跑 1000 次）。
2. 玩家道行追平星君的 `0.98` 倍时命中率到 0.90 封顶。
3. 障碍抗性 30、攻方 100 级时，实际命中 ×(1 − 30/54) ≈ 0.56 倍。
4. 冰封中的目标受到攻击不扣血、受到治疗不加血；冰封结束恢复正常。
5. 持续 3 回合的障碍在第三次回合结束后自动消失，日志各有 `CONTROL_APPLY / CONTROL_CLEAR`。
