# 第 23 期 · 经验池与手动升级

> 阶段 E ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：22

## 目标

打完一场经验先落在池子里，等级**不会自己涨**；玩家点「升级」才扣经验、才晋级；攒了 3 级就能连点 3 次；战斗中这个按钮是灰的。

## 需求来源

README §5.1（等级与经验）、§5.1.1（手动升级）、§7.8.1（战斗配置锁）、§13.4（升级反馈）、§17.2 R-27 / R-28

## 本期做什么

- [ ] `player.expPool` 与 `player.level` 分离：战斗后只加 `expPool`，**任何情况下都不自动升级**
- [ ] 升级一次：`expPool >= EXP_TO_NEXT(level)` → 扣掉、level+1、属性点 +4、道行 +4、面板属性重算
- [ ] 可升级判定：`floor(可用经验 / 当前需求)` 得到"可升 N 级"，角标显示 `可升级 ↑` 与 `×N`
- [ ] 升级按钮：点一次升一级；长按 800ms 进入连升直到经验不足（松开即停）
- [ ] 地图 HUD：经验条反映**池内经验占当前一级的比例**，满了才亮角标；等级数字旁显示池内经验绝对值
- [ ] 战斗结束不给升级按钮（结算面板只显示 `经验 +N（可升 2 级）`）；战斗中的角色面板入口灰显
- [ ] 升级反馈：数字滚动 200ms + 金色光环 + `属性点 +4` 飘字（复用 15 期的飘字组件）
- [ ] 存档：`expPool` 落盘，刷新不丢

## 本期不做（防膨胀）

- 不做加点面板 → 第 24 期（本期属性点只累加，不分配）
- 不做道行购买 → 第 25 期
- 不做经验获取公式的调整（沿用 12.5.1）
- 不做等级上限（需求明确无上限）

## 验收

1. 打一场得 300 经验、需求 200：等级仍为原值，HUD 显示 `可升级 ↑ ×1`，池内剩 300。
2. 点一次升级：等级 +1、池内 100、属性点 +4、道行 +4。
3. 把池子灌到能升 3 级：长按升级 0.8s 连升 3 级，松开立刻停。
4. 战斗中打开角色面板：「升级」灰显并提示"战斗中不可调整配置"。
5. 升级后刷新页面：等级与剩余经验都在。
