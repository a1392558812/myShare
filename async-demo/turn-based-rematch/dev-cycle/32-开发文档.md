## 目标

战斗结束按 7.7 掉东西：星宿 18% 出装、星君首通 100% 且品质 +1 档保底；跨级打星君时天品/仙品权重上移；装备仓库满时进临时邮箱（20 条，满了顶掉最旧）。

## 需求来源

README §7.7（掉落规则）、§7.7.1（跨级牛皮加成）、§7.2（装备档位）、§7.5（降级要求）、§14.2（`bag` / `equip`）

## 本期做什么

- [ ] 星宿战：装备 18%、兽魂 12% × 1、灵石 `6 + 0.9 × L_敌`、药品 8%；**套装部件 8%**（随机）
- [ ] 星君首通：装备 100%（品质 +1 档保底，仙品封顶）、兽魂 ×2、灵石 `50 + 8 × L_敌`、天外陨石 20%、**该星君五行对应的套装部件必掉 1 件**
- [ ] 装备档位：`ceil(L_敌 / 10)` ±1 浮动；低于 1 档按 1 档
- [ ] 跨级牛皮：`Δ = max(0, 星君等级 − 玩家等级)`；天品权重 `5 + 0.30Δ`、仙品 `1 + 0.10Δ`，与凡/灵/玄一起**归一化**后抽；无上限；**只对星君战生效**，星宿战与扫荡不受影响
- [ ] 装备入仓：装备仓库 60 格；满了进临时邮箱（20 条），再满顶掉最旧并 toast 提示
- [ ] 兽魂/药品/陨石进背包 24 格；背包满时入邮箱（同上规则）
- [ ] 结算面板显示本场掉落（图标 + 名字 + 品质色），点击可查看
- [ ] 探针：Δ=0 / 50 / 100 / 400 时天+仙占比与 7.7.1 一致（21.7% / 32.9% / 63.8%）

## 本期不做（防膨胀）

- 不做卖出与商店 → 第 41 期
- 不做掉落保底次数（除星君首通 +1 档）
- 不做装备等级需求（宠物穿装只看档位，25 / 30 期已定）
- 不做重复挑战（P1）

## 验收

1. 打 100 场星宿：装备产出约 18 件、兽魂约 12 个、药品约 8 个，误差 ±20%。
2. 星君首通必掉 1 件装备，且品质不低于基准档 +1（仙品封顶）。
3. Δ=50 时天+仙占比 ≈ 21.7%；Δ=400 时 ≈ 63.8%，且永远不到 100%。
4. 装备仓库塞满 60 格后再掉装备：进临时邮箱；邮箱满 20 条再掉：最旧一条被丢弃 + toast。
5. 扫荡期间不产生任何装备/兽魂（对照 21 期）。
