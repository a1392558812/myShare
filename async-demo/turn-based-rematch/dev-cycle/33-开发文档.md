## 目标

配置面板补齐两个标签：装备页能一眼看出"换这件会变强多少"（18 槽 / 仓库 60 / 对比差值 / 锁定），法术页能看已学、换出战、花经验进修；战斗中整页只读。

README §7.8（换装与对比）、§7.8.1（战斗配置锁）、§8.4（无槽位上限）、§8.6（法术进修）、§13.4 / §13.5（反馈与空状态）

## 本期做什么

**装备标签**

- [ ] `components/EquipPanel.vue`：左 9 槽（玩家）与 9 槽（宠物）切换，右仓库 60 格 + 临时邮箱入口
- [ ] 每件显示：图标色块 + 名字 + 品质色边 + 档位 + 强化等级 + 词条摘要 + 套装归属
- [ ] 对比：点仓库装备 → 与当前同槽位对比，逐项显示 `物攻 +12（↑18）`；不只看总评
- [ ] 一键装备 / 卸下；档位不够（宠物等级不足）时灰显 + 原因
- [ ] 锁定：标记收藏；锁定件与锁定宠不参与熔铸/进阶与后续整理
- [ ] 筛选：按部位（品质与套装的筛选放 41 期）

**法术标签**

- [ ] `components/SkillPanel.vue`：已学法术列表（门派 + 通用），显示五行、耗蓝、单/群体、当前等级与伤害预览
- [ ] 出战：法术**没有槽位上限**（8.4），列表里勾选即用，超过 8 条折叠
- [ ] 进修：花经验抬 `skill.lv`，价格表照 8.6；经验不足灰显并显示差额
- [ ] 战斗锁：两个标签页整体只读，悬停 `战斗中不可调整配置`
- [ ] 空状态：无法术时"尚未参悟"；仓库为空"去打几只星宿"

## 本期不做（防膨胀）

- 不做技能重置 / 遗忘

## 验收

1. 点仓库一件比当前强的武器：逐项差值正确，穿上后面板数值立即变化。
2. 给宠物穿等级不够的装备：灰显 + 原因，不报错。
3. 玩家与宠物各自 9 槽：同一件装备不会同时出现在两边。
4. 法术页：学 10 个法术全部可用（无槽位上限），列表超 8 条折叠。
5. 战斗中打开配置：两个标签页全灰，点击提示 `战斗中不可调整配置`。
