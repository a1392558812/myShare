# 第 40 期 · 熔铸

> 阶段 G ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：39

## 目标

喂一只副宠给主宠熔铸：六项（成长 + 五项资质）随机取高并小幅上浮，其余五五开涨跌；已达上限的项永不下降；副宠阶必须 ≥ 主宠阶；次数不限。

## 需求来源

README §9.12（熔铸 9.12.1–9.12.7）、§9.3（各阶满值）、§9.11（宠物装备）、§17.2 R-35 / R-36

## 本期做什么

- [ ] 副宠筛选：阶 ≥ 主宠阶（野生吃任意、宝宝吃宝宝及以上、变异只吃变异、神兽只吃神兽）；排除出战宠与锁定宠
- [ ] 区间：每项恒在 `该阶满值 × [0.5, 1.5]`；满值取该阶资质范围上限（野生 0.95 / 宝宝 1.05 / 变异 1.15 / 神兽 1.25），成长 0.90 / 1.00 / 1.10 / 1.20
- [ ] 主融项：六项中随机 1 项；新值 = `max(主, 副) × (1 + rand(1.5%, 3%))`
- [ ] 其余五项：各 50% 上涨 / 50% 下跌，幅度 `rand(1%, 3%)`
- [ ] 已到上限的项**永不下降**；跌破下限的项钳到下限
- [ ] 消耗：每次只吃副宠，不扣灵石 / 兽魂 / 亲密度；**次数不限**
- [ ] 主宠保留：等级、加点、技能、内丹、亲密度、已穿 9 件装备一律不变
- [ ] 熔铸子页 UI：副宠列表（阶位/资质摘要）、入框红边 + "将被吞噬"角标、二次确认、页脚"已熔铸 N 次"
- [ ] 探针：150 次熔铸的典型路径（65 级变异宠、资质 1.00、成长 1.10）后区间与 9.12.4 表一致

## 本期不做（防膨胀）

- 不做"指定主融项"（需求明确随机，18.2 #13）
- 不做熔铸保底/垫刀
- 不做熔铸重置或回退
- 不做星君数值重算（用户明确不重算，12 章锚点按零熔铸）

## 验收

1. 野生主宠可以吃任意阶副宠；变异主宠只能吃变异及以上（喂宝宝时列表里直接不出现）。
2. 一次熔铸：6 项里恰好 1 项取高上浮，其余五项各自涨或跌，幅度都在 1%–3%。
3. 某项已到 `满值 × 1.5`：再熔铸它不会下降（连续 20 次验证）。
4. 主宠身上 9 件装备、加点、技能、内丹在熔铸后完全不变。
5. 连续熔铸 150 次：六项都接近上限，且从未越界（探针断言）。
