# 第 05 期 · 判定链与伤害

> 阶段 B ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：04

## 目标

普攻能打出真伤害，且七个判定环节按固定顺序执行；每个环节都能在日志里单独读到（命中→闪避→连击→暴击→抗性→减伤→五行）。

## 需求来源

README §4.4（伤害公式）、§4.5（命中·连击·暴击）、§4.6（五行克制）、§12.2（普攻/法术对照）、§4.11（边界）

## 本期做什么

- [ ] `core/damage.js`：单一入口 `resolveAttack(attacker, defender, action, ctx)`，**严格按 7 步顺序**，每步产一条 `HIT / DODGE / COMBO / CRIT / RESIST / MIT / ELEMENT` 事件
- [ ] 命中：`0.80 + (HIT − EVA) / 200`，钳制 `[0.35, 0.98]`
- [ ] 连击：基础 0（本期无词条），最多 3 段，段系数 `1.0 / 0.65 / 0.42`；第 2 段把目标打到倒地则不再结算第 3 段（倒地判定先留 stub，第 06 期接真）
- [ ] 暴击：基础 0，暴伤 1.50；钳制 `crit ≤ 0.70`、`critDmg ≤ 1.85`
- [ ] 抗性：走 6.3 的 `R/(R+P)`，本期 `R = 0`（相性面板未开），验证"0 抗性时减伤恒为 0"
- [ ] 防御减伤 `MIT`：防御指令 0.5，与技能减伤加法叠加后钳到 `≤ 0.60`
- [ ] 五行：`1.25 / 0.85 / 1.00`，接 4.6 的相克环
- [ ] 伤害：`max(1, atk × 段系数 × 五行 × (1 − MIT) × (1 − 抗性减伤) × 暴击)` 取整
- [ ] 日志格式：一条攻击事件展开成 `命中 0.86 → 暴击 ×1.5 → 火克金 ×1.25 → 减伤 33% → 伤害 412`

## 本期不做（防膨胀）

- 不做倒地后的目标转移（4.8.1 第 3 条）→ 第 06 期
- 不做装备词条带来的命中/连击/暴击加成 → 第 27 期（接口留 `getMods(unit)`，本期返回空）
- 不做数值平衡调整（一切以 12 章为准，本期只负责算对）

## 验收

1. 同等级、0 抗性、无词条时，普攻单体伤害与 12.2 的口径一致（手算 3 组对照）。
2. 把 attacker 命中改成极低（10）与极高（999），命中率分别落到 0.35 与 0.98。
3. 五行相克时伤害 ×1.25，被克 ×0.85，无关系 ×1.00，三种都能在日志中看到系数行。
4. 防御指令下同一次攻击的伤害约为不防御的 50%（MIT 0.5）。
5. 判定顺序被日志验证：任何一次攻击的事件序列里，`DODGE` 之后不再出现 `CRIT`。
