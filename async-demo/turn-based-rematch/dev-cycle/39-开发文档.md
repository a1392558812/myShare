# 第 39 期 · 宠物装备（9 槽）

> 阶段 G ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：38

## 目标

把 27 / 33 期已经做好的装备系统接到宠物身上：9 件全开、100% 生效、人宠可互换但加成各归各；宠物穿装只看它自己的等级够不够档。

## 需求来源

README §9.11（宠物装备）、§7.1（归属）、§7.6（套装独立判定）、§17.2 R-30 / R-31 / R-32 / R-34

## 本期做什么

- [ ] 宠物 9 槽全开：1 级新宠也能穿满，不受等级/亲密度/阶位限制（唯一拦截是穿装等级）
- [ ] 穿装等级：装备档位对应等级由 7.2 的 `tier = ceil(L/10)` 反推，宠物等级不够则灰显 + 原因
- [ ] 100% 生效：白板、词条、强化、宝石、洗髓、套装对宠物全额计算，不打折
- [ ] 各归各的：`getEquipBonus(unit)` 只吃自己 9 件；玩家面板一分不动（断言）
- [ ] 流转：玩家换下的装备可直接给宠物（反向亦然），`wornBy` 保证唯一
- [ ] 套装独立：玩家 2 件 + 宠物 2 件不触发任何套装（复用 31 期的独立判定）
- [ ] 木套特例：回合首回血只对**在场的宠物**生效；宠物离场后不再结算
- [ ] 面板：宠物页「装备」子页复用 33 期组件，切 `owner = pet`
- [ ] 探针：宠物穿 9 件 5 档 +10 装，面板与 9.2 / 9.11 的合计口径一致

## 本期不做（防膨胀）

- 不做宠物专属装备（人宠同一张白板表）
- 不做宠物装备的独立强化/镶嵌界面（走同一套商店与面板）
- 不做"宠物装备绑定"
- 不做第二只宠物的槽位（P1）

## 验收

1. 1 级宠物能穿 0 档装 9 件，面板立即可见加成。
2. 给 10 级宠物穿 5 档装（需 Lv 41+）：灰显 + "等级不足"。
3. 同一件 +10 强化装从玩家脱给宠物：宠物拿到满额强化，玩家面板同步减少。
4. 玩家 2 件金套 + 宠物 2 件金套：双方都不触发套装（断言）。
5. 宠物离场后木套 4 件不给它回血（它已不在场）。
