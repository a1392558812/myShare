# 第 36 期 · 脱战与召唤

> 阶段 G ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：35

## 目标

宠物气血归零不做倒地：先判「神佑复生」，没触发就当场淡出离场、槽位释放、本场不可复活；玩家可以用一次行动召唤替补。

## 需求来源

README §9.9（气血归零、脱战与召唤）、§4.8.1 第 10 条、§3.3（宠物脱战与召唤槽位）、§17.1 A-11、§17.2 R-10 / R-33

## 本期做什么

- [ ] 宠物 `hp <= 0` → 判定 `神佑复生`（37 期接真实兽诀，本期先恒为 `false`）→ 未触发：**立刻离场**
- [ ] 离场：播 `retreat` 400ms 淡出、槽位当场释放；**不做 down 姿态、不进目标池、不占出手位**
- [ ] 本场不可复活：喂药 / 木套回血 / 治疗法术一律无效（在 `applyHeal` 入口按"是否在场"拦截）
- [ ] 召唤：宠物已离场且有替补 → 指令入口出现「召唤」，占玩家一次行动；S3 光点聚合 600ms → 移到 S2
- [ ] 召唤后的行动时序：当回合不参与速度序列，**下回合起**才行动
- [ ] 判负修正：玩家倒地且宠物已离场（或本就无宠）且无待结算持续治疗 → 判负
- [ ] 木套 4 件的回合首回血只对**在场的宠物**生效（离场即无回合）
- [ ] 术语：全仓无 `revive / resurrect`；`retreat` 只用于宠物离场

## 本期不做（防膨胀）

- 不做神佑复生的真实触发 → 第 37 期（本期接口留好）
- 不做第二只宠物同时在场（P1）
- 不做召唤的入场属性衰减（新宠按自己面板直接上）
- 不做"宠物保护/援护"类技能

## 验收

1. 宠物被打到 0：立绘淡出 400ms、S2 空出、日志"宠物脱战"，**没有倒地姿态**。
2. 脱战后使用治疗法术或喂药：无效，日志提示"宠物已离场"。
3. 有替补时点「召唤」：占玩家一回合，新宠在 S3 出现并移到 S2，**当回合不出手**，下回合正常行动。
4. 宠物离场且玩家随后倒地：判负（不再因为"宠物还在场"而卡住）。
5. 全场 `grep revive` 为 0。
