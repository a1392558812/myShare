# 第 01 期 · 工程骨架与画布适配

> 阶段 A ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：无

## 目标

页面能打开、能缩放到任意窗口不变形，屏幕上出现一块 1280×720 的塔层背景，路由可从 async-demo 入口进入。

## 需求来源

README §3.1（画布规格与坐标系）、§13.1（canvas 边界）、§16.1（宿主集成）、§15.2（缩放）

## 本期做什么

- [ ] 建目录：`core/` `stage/` `draw/` `components/` `config/`，每个目录只放一个 `.gitkeep`
- [ ] `index.vue`：一个全屏容器 + 一个 `<canvas>`，无其他业务逻辑
- [ ] `stage/toDesign.js`：设计坐标 1280×720 → 容器 `contain` 等比缩放；导出 `toDesign(x,y)` 与 `scale`；DPR 上限 2
- [ ] 窗口 `resize` 时重算尺寸与 DPR（不使用媒体查询）
- [ ] 画一张静态 L0 背景：塔层壁画底纹 + 五行雾（纯色渐变即可，不追求美术）
- [ ] 在 `1230, 706` 画一行调试文字，显示当前 `scale ×DPR` 与画布像素尺寸（本期唯一的"内容"，用于肉眼验证清晰度）
- [ ] `?debug=1` 开关：`core/debug.js` 暴露 `isDebug()`，正式构建（无参数）为 `false`
- [ ] 在 `/route-list/demo.json` 登记：`path: "turn-based-rematch"`、`component: "turn-based-rematch/index.vue"`、`fileType: "vue"`、`meta.demoName: "通天塔"`

## 本期不做（防膨胀）

- 不做任何立绘、角色、UI 面板 → 第 10–14 期
- 不做存档、不做路由跳转逻辑 → 第 02 期
- 不做动画循环（`requestAnimationFrame` 都先不接）→ 第 04 期
- 不做降级策略 → 第 43 期

## 验收

1. 访问 `http://127.0.0.1:5501/#/demo/turn-based-rematch` 能出画面，控制台无业务报错。
2. 浏览器窗口从 1280×720 拖到 2560×1440，背景不变形、不留黑边（等比）。
3. 浏览器缩放 100% / 125% / 150% 三档，右下角调试文字都不模糊。
4. 宿主页面原有的 `StringBuffer` 报错除外，无新增报错。
5. 不带 `?debug=1` 时调试文字不显示。
