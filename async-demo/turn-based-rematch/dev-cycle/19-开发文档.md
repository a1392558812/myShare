# 第 19 期 · 星君 · 四象随行 · 对话挑战

> 阶段 D ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：18

## 目标

七角形上的 7 位星君都能点、能对话、能挑战；每场敌方是"1 星君 + 2 四象"，四象按层轮转；对话面板画在 Canvas 上（地图内不出现 DOM）。

## 需求来源

README §11.3（七位星君与四象随行）、§11.3.1（星君总表）、§11.4（对话触发与挑战流程）、§13.1（地图内无 DOM）、§17.1 A-02 / A-03

## 本期做什么

- [ ] 7 个星君点位：固定顺序（天权 / 摇光 / 开阳 / 天玑 / 天枢 / 天璇 / 玉衡），**同层等级全部 = n+1**，无先后强弱差
- [ ] 星君光柱：未击败为亮柱 + 名字；已击败转灰并显示"已击败"
- [ ] 四象轮转：第 n 层第 i 位随行 = `FOUR[(i+n−2)%4]` 与 `FOUR[(i+n−1)%4]`
- [ ] 点星君 → 自动走到 90px 内 → 对话面板升起（Canvas 绘制，240ms）：道号、等级、五行、定位、随行两只四象、`挑战` / `离开`
- [ ] `挑战` → 进战斗：S1 玩家 + S2 出战宠物（没有则为空），E1 星君 + E2/E3 四象
- [ ] 星君战斗 AI 骨架：普攻 + 每场 2 个主动技能（技能**照 11.3 的星君技能列逐条落地**，不自创）；四象只做"喂药救人"的空壳（真正拉人在第 20 期接判负逻辑）
- [ ] 战斗结束后星君血量与进度：胜利标记已击败、失败则星君回满血
- [ ] 对话面板的所有矩形进 `hitmap`，与地图移动的点击互斥

## 本期不做（防膨胀）

- 不做失败惩罚与归因 → 第 20 期
- 不做层推进 → 第 20 期
- 不做星君技能的真实数值平衡（只照 11.3 抄，验收到第 43 期统一看）→ 第 43 期
- 不做四象救人概率 60% 的细节 → 第 20 期（本期四象只会普攻）

## 验收

1. 7 位星君等级完全相同（悬停/对话里显示同一个数字），只有五行与定位不同。
2. 第 1 层与第 2 层的某一位星君，随行四象不同（轮转正确，连续 4 层不重复组合）。
3. 点星君能出对话面板，面板不遮挡角色；点「离开」面板收起、角色不动。
4. 挑战后进入 3v2：敌方 1 星君 + 2 四象，E2/E3 有立绘。
5. 待机时连续开两次对话不会叠两层。
