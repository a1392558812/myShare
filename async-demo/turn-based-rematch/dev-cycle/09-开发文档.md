## 本期做什么

- [ ] 逃跑：`fleeChance = min(1, 0.30 + 0.15 × 已失败次数)`，占玩家一次行动；成功发 `FLEE_OK` 结束战斗，失败本回合照常挨打
- [ ] 逃跑计数只在单场内累计，`BATTLE_END` 后清零；星君战、星宿战都允许
- [ ] 失败结果接：回出生点、敌方回满血、不扣灵石、出战宠物亲密 −5（亲密字段本期可只写不读）
- [ ] 4.9 十条逐条落位，每条一个分支 + 探针断言：

| # | 场景 | 实现要点 |
|---|---|---|
| 1 | 反震打死施法者 | 反震先结算再判断施法者倒地，伤害结果不回滚 |
| 2 | AOE 多目标 | 按槽位 S1→E3 结算，已倒地跳过 |
| 3 | 治疗与伤害同回合 | 严格按行动顺序，后手读先手后的血量 |
| 4 | 护盾与减伤 | 先抗性 + MIT，再扣护盾，溢出进血 |
| 5 | DoT 致倒 | 行动前倒地 → 指令作废，不算"被击倒" |
| 6 | 起身后再倒 | 同回合允许"倒→起→再倒"，每次正常结算 |
| 7 | 冰封中受击 | 免疫伤害，但可被"解除" |
| 8 | 连击第 2 段打倒 | 第 3 段作废 |
| 9 | 目标倒地改打 | AI 按仇恨重选；玩家手动目标不自动改 |
| 10 | 同时全灭 | 比较倒地时刻，后倒方获胜 |

- [ ] 4.11 的边界：页面失焦暂停在"等待指令"、刷新视为中断回入口（不判负）、全屏白屏 3s 回滚到回合快照（快照只存必要字段）
- [ ] `.tmp/rules.mjs`：十条各一例，全部断言通过

## 验收

1. 连点逃跑 5 次，成功率序列为 30 / 45 / 60 / 75 / 100%，第 5 次必成。
2. 逃跑成功：战斗结束、回到出生点、灵石不变；逃跑失败：本回合玩家未造成伤害。
3. 4.9 十条探针全绿，其中"AOE 跳过倒地目标"与"DoT 致倒不算击杀"必须有独立断言。
4. 玩家与星君同回合全灭时，按倒地先后判定胜负（两例：己方先倒 → 负；敌方先倒 → 胜）。
5. 一台终端里 `node .tmp/rules.mjs` 一次跑完，无需浏览器。
