# 第 14 期 · 飘字 · 命中特效 · hitstop / 震屏

> 阶段 C ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：13

## 目标

打一下能看到东西：伤害数字飘、命中特效炸、暴击有停顿和震屏；动作帧跟着事件播，不再让立绘一直站着。

## 需求来源

README §3.6（飘字系统）、§3.5 特效 #4–#7 #13 #14（斩击 / 爆点 / 冰晶 / 灼烧 / hitstop / 震屏）、§3.10（事件→表现）、§3.4（动作帧）

## 本期做什么

- [ ] `stage/animator.js`：从事件队列取出 `ATTACK / CAST / CRIT / DAMAGE / DOWN / GETUP`，映射到动作名与帧推进（`ready → attack/cast → hurt → idle`）
- [ ] 飘字：伤害（白/黄暴击/红被克）、治疗（绿）、闪避（灰 `MISS`）、免疫（`免疫`）；字号/描边/上浮/淡出照 3.6 表
- [ ] 命中特效 4 条：斩击（物理）/ 爆点（法术）/ 冰晶（冰系）/ 灼烧（火系），按 3.5 参数与层级
- [ ] `hitstop` 70ms：冻结渲染时钟，**UI 输入不受影响**（只停动画时间轴）
- [ ] 震屏：振幅 6px、180ms 指数衰减；叠加多个震屏取最大振幅不累加
- [ ] 粒子池：同屏上限 220，超出丢弃不排队；AOE 命中 5 目标时每目标粒子降到 60%
- [ ] 事件消费与表现解耦：`animator` 只读事件数组，禁止读 `battle.units` 改数值

## 本期不做（防膨胀）

- 不做弹道（#1–#3）→ 第 15 期（需要法术弹道与目标坐标）
- 不做回合横幅、捕捉/逃跑特效、召唤聚形 → 第 15 期

## 验收

1. 一次普攻：`ready` 前倾 → 前冲 40px → 斩击特效 → 目标 `hurt` 后仰 8px → 伤害数字上浮淡出 → 双方回 `idle`。
2. 暴击：数字为黄色并放大 1.2 倍，同时有一次 70ms 停顿 + 震屏。
3. 连续 10 次 AOE 命中，粒子数不超过 220，帧率不低于 55fps。
4. 把飘字关掉（调试开关）后战斗逻辑完全不变，证明表现层只消费事件。
5. 拖动窗口缩放后，飘字位置仍贴着目标头顶（用设计坐标换算，不用屏幕像素）。
