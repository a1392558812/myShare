# 第 26 期 · 相性面板与溢出

> 阶段 E ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：25

## 目标

每 5 级给 1 点相性点，五项各能点到 30；**五项全满**后整体抬到 60，再满抬 90 / 120 / 200；加成按加法叠加乘到基础面板，抗性走对抗式。

## 需求来源

README §6.1（点数与上限 / 溢出阶梯）、§6.2（五项收益）、§6.3（对抗式减伤）、§6.4（相性 ≠ 五行）、§17.1 A-15、§17.2 R-15 / R-16

## 本期做什么

- [ ] 相性点总数 = `floor(level / 5)`（派生，不累加，避免升级/降级口径漂移）；已分配存 `player.affinity = { metal, wood, water, fire, earth }`
- [ ] 面板（配置页 · 相性标签）：五项各 5 格进度条 + `+1` 按钮 + 当前上限 + 未分配红点
- [ ] 单项上限：初始 30；五项全部达上限 → 整体 +30，弹一次性提示 `相性上限提升：30 → 60`，阶梯 30 / 60 / 90 / 120 / 200
- [ ] 未满时不能单点超过当前上限；点数不足时 `+1` 灰显；多余点数只能存着（红点）
- [ ] 收益：金 法攻 +2%/点、木 气血 +1.8%、水 物抗/法抗 +1% 与障碍抗性 +1.5%、火 速度 +1%、土 物攻 +2%
- [ ] 叠加：五项百分比**各自加法**后整体乘到"基础 + 加点 + 装备"（`(1 + 相性% + 套装% + buff%)` 统一乘区）
- [ ] 抗性：`减伤 = R / (R + P)`，`P = 20 + 0.04 × 攻方等级`；面板实时显示"对同级的物理减伤 %"
- [ ] 术语隔离：面板上明确写"相性 ≠ 五行"（6.4），避免和相克混为一谈
- [ ] 战斗锁：战斗中相性页只读

## 本期不做（防膨胀）

- 不做宠物相性（宠物没有相性系统）
- 不做相性软绑定的门派限制（只做提示，不禁止）
- 不做相性重置的价格与商店入口 → 第 30 期（需要洗髓丹，道具在 40 期落地；本期只留一个 `resetAffinity()` 空函数）
- 不做装备词条带来的抗性 → 第 27 期

## 验收

1. 等级 50：相性点 = 10，五项各点 2 点，面板四项加成按 6.2 生效。
2. 把五项各点到 30（用调试直接给点）：第 31 点被拦，提示"需五项全满"；五项都满后上限跳到 60 并弹提示。
3. 土 20 点：物攻 ×1.40（不是 1.02^20），与 6.2 一致。
4. 水 30 点、攻方 100 级：物理减伤显示 55.6%（±0.1%）。
5. 战斗中打开相性页：只读，已加成的数值仍生效。
