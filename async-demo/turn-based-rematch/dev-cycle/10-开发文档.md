# 第 10 期 · 立绘 painter A（玩家 / 宠物）

> 阶段 C ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：09

## 目标

玩家（5 门派配色）与宠物（5 定位）各有 12 个动作帧的程序化立绘，能在一张离屏画布上按动作名 + 帧序号画出来，脚底锚点对齐。

## 需求来源

README §3.4（画布尺寸 / 锚点 / 动作帧表 / 绘制规格）、§8.1（门派色）、§9.2（宠物定位）

## 本期做什么

- [ ] `draw/painter.js`：导出 `drawUnit(ctx, unit, action, frame)`，只读纯数据，不 import `core`
- [ ] 玩家立绘 132×176、锚点 (66,172)：头/躯干/四肢/武器分层绘制，5 门派换主色 + 1 处门派标识（如剑/符/珠）
- [ ] 宠物立绘 120×96、锚点 (60,92)、兽形横长：按 5 定位改体型（物理壮 / 法术瘦长 / 高速细长 / 肉盾矮胖 / 控制尾饰）
- [ ] 12 个动作全部可用：`idle 4 / ready 3 / attack 4 / cast 5 / hurt 2 / defend 3 / down 4 / down_idle 1 / getup 3 / retreat 4 / summon 4 / win 4`
- [ ] `idle` 呼吸 ±2px、`attack` 冲刺 40px 回位、`hurt` 后仰 8px、`down` 躺地头部朝外（**不碎裂、不血泊**）
- [ ] 外描边 3px（主色压暗 40%）；受击闪白用 `lighter` 叠白色剪影，不用 `filter`
- [ ] 脚底阴影椭圆 `rgba(0,0,0,0.28)`，半宽 = 宽 × 0.32；倒地时拉长 1.4 倍、透明度 0.18
- [ ] `draw/preview.html` 或调试页：一屏排开"5 门派 × 3 动作"与"5 定位 × 3 动作"，逐帧播放

## 本期不做（防膨胀）

- 不做星君 / 四象 / 星宿 → 第 11 期
- 不做动作与战斗事件的绑定、不做站位排布 → 第 12 期
- 不做特效、飘字 → 第 14 / 15 期
- 不做换装外观（装备不影响立绘）→ 明确不做

## 验收

1. 调试页能在一屏看到 10 个单位 × 3 个动作，帧序正确、不闪烁。
2. 12 个动作逐个手点，没有一帧出现"穿地"（脚低于锚点）或"飘空"（脚高于锚点）。
3. `down` 姿态肉眼可辨"躺在地上但还活着"，没有血泊、没有碎裂。
4. `idle` 在 6fps 下循环无跳帧；`hurt` 的闪白只在描边上，不糊整图。
5. `draw/` 下 `grep -r "core/" draw/` 为 0。
