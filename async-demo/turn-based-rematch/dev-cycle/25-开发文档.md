# 第 25 期 · 道行购买

> 阶段 E ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：24

## 目标

能用经验买道行：越买越贵、不可退回、没有上限；买完面板上 `道行 = 4×等级 + 已购` 立刻生效，并直接影响对星君的控制命中率。

## 需求来源

README §5.6（道行）、§4.7（道行决定障碍命中）、§13.4（反馈）、§17.2 R-13 / R-14

## 本期做什么

- [ ] 定价：第 d 点价格 = `round(20 × L^0.7 × (1 + d / 200))`，`L` 为当前等级、`d` 为已购点数（0 起）
- [ ] 购买面板（配置页 · 道行标签）：显示当前道行、已购点数、下一档价格、`买 1 点` / `买 10 点`（够钱才可点）
- [ ] 消耗来源：**只扣经验池**，不扣灵石；经验不足时按钮灰显并显示差多少
- [ ] 道行 = `4 × 等级 + 已购`，升级时自动 +4（23 期已接），购买后立即重算控制命中预览
- [ ] 不可退回：面板上没有退款入口；文案明确写"道行不可退回"
- [ ] 预览：面板常驻一行"对同级星君的障碍命中 ≈ 0.55"，买完后实时变化（用 4.7 公式）
- [ ] 战斗锁：战斗中道行页只读
- [ ] 存档：`player.daoBought`，与等级分开存

## 本期不做（防膨胀）

- 不做道行的其他来源（装备/套装/药品都不给道行，R-13）
- 不做批量购买的折扣
- 不做"一键追平星君"按钮 → 明确不做（那会让取舍消失）
- 不做相性 → 第 26 期

## 验收

1. 1 级买第 1 点：价格 = `round(20 × 1^0.7 × 1)` = 20 经验。
2. 连买 10 点，价格逐点上涨，且总是比上一点贵（单调）。
3. 经验不够时按钮灰显；买完后经验池减少、道行增加，刷新后仍在。
4. 100 级买 40 点：面板"对同级星君命中"从 0.15 升到 0.55 附近（±0.02）。
5. 面板上找不到任何退款/重置按钮。
