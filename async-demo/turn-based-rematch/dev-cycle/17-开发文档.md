# 第 17 期 · A* 寻路与障碍碰撞

> 阶段 D ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：16

## 目标

点地图任意可达位置，角色沿路径绕过障碍走过去；点不可达位置时给一次失败提示而不是原地抖。

## 需求来源

README §11.2.2（点击寻路）、§15.1（单次 A* ≤ 3ms）、§16.2（寻路唯一）、§16.3（网格生成失败降级）

## 本期做什么

- [ ] `stage/pathfind.js`：A*（4 邻或 8 邻，取 8 邻 + 不穿角），网格 20×20（可按层微调），障碍外扩 18px
- [ ] 网格生成：从布局的装饰物矩形栅格化；生成失败 → 回退"直线 + 遇障碍停住"并打日志（16.3）
- [ ] `findPath(from, to)` 返回点列；路径首尾对齐实际像素坐标（不出现"走到格子中心才停"）
- [ ] 移动：沿路径逐点走，速度 220px/s，接近拐点时平滑切向（不做加速度）
- [ ] 路径线：2px 金色，1s 淡出（只在点击瞬间画，不常驻）
- [ ] 不可达：目标被围死 / 在障碍里 → 目标环变红闪一下 + toast `无法到达`，角色不动
- [ ] 性能：单次寻路 ≤ 3ms（在 HUD 调试行打印耗时，跑 100 次取最大）

## 本期不做（防膨胀）

- 不做动态障碍（星宿/星君不参与寻路阻挡，避免"被怪物堵死"）
- 不做战斗内位移 → 战斗仍静态站位
- 不做寻路缓存与分帧 → 地图规模小，不需要
- 不做触摸/拖拽移动 → 明确不做

## 验收

1. 在七角形柱体与装饰之间点地，角色绕过去而不是穿墙。
2. 点进装饰物内部：不移动、`无法到达` 提示、目标环红闪。
3. 点地图对角最远处：单次寻路 ≤ 3ms，角色正常抵达。
4. 连续快速点 5 个不同位置：只响应最后一次，不出现"走两步再回头"。
5. 关闭寻路（调试开关）时退化为直线移动并在障碍前停住，程序不崩。
