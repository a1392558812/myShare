# 第 24 期 · 加点与洗点

> 阶段 E ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：23

## 目标

升级拿到的 4 点能分配到力/敏/体/灵四项，面板数值实时变化；点错了能免费重置；战斗中加点入口全部禁用。

## 需求来源

README §5.2（属性点分配）、§5.3（洗点）、§5.4（基础属性公式）、§15.3（可用性）、§17.2 R-28

## 本期做什么

- [ ] `components/StatPanel.vue`（配置页 · 属性标签）：等级、可用点数、四项加点按钮（+1 / +5 / 清空）、当前分配、面板换算预览
- [ ] 四项系数照 5.2：力量→物攻、敏捷→速度/命中/闪避、体质→气血/防御、灵力→法攻/法力（灵力收益是力量的 0.5 倍）
- [ ] 加点即时重算：`core/stats.js` 的 `recalcPlayer()` 单点入口，禁止面板自己算
- [ ] 上限：可用点数不足时 `+1` 灰显；不能出现负分配
- [ ] 洗点：一键把已分配点数全部退回（免费、无冷却、无损失），确认弹窗一次
- [ ] 战斗锁：战斗中整个属性标签页只读，按钮灰显 + 提示（7.8.1）
- [ ] 存档：`player.assign = { str, agi, vit, spi }`，与等级一同落盘
- [ ] 面板显示"法攻/物攻"比值，让玩家自己看到 ≤ 0.60 的约束

## 本期不做（防膨胀）

- 不做装备/相性/套装加成进面板 → 第 26 / 27 / 30 期（本期面板只到"基础 + 加点"）
- 不做推荐方案一键分配 → 明确不做
- 不做加点模拟器（可回退预览）→ 不做，洗点已足够
- 不做宠物加点 → 第 34 期（宠物面板同构，届时复用）

## 验收

1. 等级 10（36 点可用）全加体质：气血按 `+6.5 × 点数` 变化，与 5.4 口径一致。
2. 把灵力与力量各加 10 点：物攻增量正好是法攻增量的 2 倍。
3. 「清空」后可用点数回到总数，四项归零，面板回落。
4. 点数用完时 `+1` 灰显；负分配无法构造（点不出 -1）。
5. 战斗中打开属性页：所有按钮灰，点一下弹"战斗中不可调整配置"。
