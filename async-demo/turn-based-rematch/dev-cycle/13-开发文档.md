# 第 13 期 · 战斗 UI 与指令交互

> 阶段 C ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：12

## 目标

战斗里所有信息都画在画布上且能点：头像卡、指令栏、日志、快捷栏、回合区；点普攻能选中目标并提交，键位与鼠标结果一致。

## 需求来源

README §3.7（UI 布局与分区）、§3.8（指令交互）、§3.12（输入与键位）、§3.10（事件流）、§4.8.1 第 3 条（倒地单位可选中）

## 本期做什么

- [ ] L7 面板区：左侧双头像卡（气血/法力条 + 状态图标）、底部指令栏（竖排/横排按 3.7）、右侧日志（滚动 6 行）、右下快捷栏 8 格（第一格固定捆仙绳）
- [ ] 顶部回合区：`第 N 回合` + 出手顺序条 + `自动` 开关（点击切换，不实现倍速）
- [ ] 指令栏 6 键：普攻 `1` / 法术 `2` / 道具 `3` / 防御 `4` / 捕捉 `5`（或 `G`）/ 逃跑 `6`；不可用时灰显并在点击时弹原因气泡（3.8）
- [ ] 目标选择：点单位 → 白描边 + 血条加粗；**倒地单位同样可选中**（选中后伤害转移到站立目标，规则见 4.8.1 第 3 条，本期先把"可选中"做对）
- [ ] 命中测试：所有按钮矩形集中在一张 `hitmap` 里，渲染与命中用同一份矩形（禁止两处各写一套坐标）
- [ ] 键位与鼠标等价：按 `1` 与点普攻产生同一事件；输入框聚焦时不拦截按键；`Esc` 关闭浮层（本期无浮层，先留钩子）
- [ ] 指令提交 → 内核 `submitCommand`，等待 `resolve` 完成后 UI 才允许下一次输入（防连点）
- [ ] 日志：内核事件转成中文行（`玩家 普攻 天权 命中 伤害 412`），最多保留 200 条

## 本期不做（防胀）

- 不做飘字与特效 → 第 14 / 15 期
- 不做胜利/失败全屏层 → 第 15 期
- 不做法术滑出列表的完整版（先做一个 6 条以内的简易竖列，超过则翻页）→ 第 15 期补全
- 不做换宠/召唤入口 → 第 36 期（第 4 键暂不占用）

## 验收

1. 鼠标点「普攻」再点敌方星君：目标有白描边，指令提交，日志新增一条。
2. 键盘按 `1` 与点「普攻」结果完全一致；在输入框里打字时按 `1` 不触发战斗指令。
3. 法力不足时法术按钮灰显，点击弹出"法力不足"气泡且不扣蓝。
4. 点倒地的星君：仍出现描边（可选中），不报错、不崩。
5. 所有按钮在 100% / 150% 缩放下点得中（矩形随 `scale` 变换，不硬编码像素）。
