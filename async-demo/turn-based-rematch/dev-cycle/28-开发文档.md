# 第 28 期 · 品质与词条生成

> 阶段 F ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：27

## 目标

同一档装备能 roll 出 5 种品质，品质决定词条条数与孔位；词条从池子里独立抽、同名的取高值、按部位略有倾向；固定值随档缩放、百分比不随档变。

## 需求来源

README §7.3（品质与词条 / 词条池 / 部位倾向）、§12.6（闪避/暴击/连击/反震等全身上限）、§17.2 R-02（灵力约束）

## 本期做什么

- [ ] `config/affixes.js`：16 条词条照表落地，字段 `{ id, name, kind: flat|pct, base, scale: tier^1.2|none, capSingle?, capTotal? }`
- [ ] 品质表：凡 45% / 灵 32% / 玄 17% / 天 5% / 仙 1%，词条数 0/1/2/3/4，孔位 0/1/1/2/2
- [ ] `rollEquip(tier, quality?, opts)`：品质未指定时按权重抽；逐条独立抽词条，**同名不叠加取高值**；部位倾向词条最多占 1 条
- [ ] 缩放：固定值 `round(base × tier^1.2)`，百分比固定不缩放
- [ ] 单件上限：闪避 6%、反震 15%、物抗 6%、法抗 6%、障碍抗性 6%、单系增伤 20%
- [ ] 全身上限归集到一个 `sumMods(unit)`：闪避 20%、暴击 65%、暴伤 +35%、连击 50%、反震 30%、障碍抗性 24%
- [ ] 硬约束：**词条池里没有道行**（R-13），代码里也不要有 `dao` 字段
- [ ] 探针 `.tmp/equip.mjs`：同一档 roll 10000 次，品质分布误差 < 1%；同日 3 条词条不出现重复项

## 本期不做（防膨胀）

- 不做强化/宝石/洗髓 → 第 29 / 30 期
- 不做套装判定 → 第 31 期
- 不做掉落权重（跨级牛皮）→ 第 32 期（本期 `quality` 由调用方给定）
- 不做词条洗练 UI → 第 30 期

## 验收

1. 抽 10000 件 5 档装备：凡 45% / 灵 32% / 玄 17% / 天 5% / 仙 1%（±1%）。
2. 灵品永远只有 1 条词条 + 1 孔；仙品 4 条 + 2 孔。
3. 同一件装备内不出现两条同名词条；出现同名时取高值。
4. 5 档装备的"物攻"词条 = `round(8 × 5^1.2)`，与手算一致；暴击率词条恒为 1%。
5. 全身归集后：闪避永远 ≤ 20%、暴击 ≤ 65%、连击 ≤ 50%，超出的部分被截断。
