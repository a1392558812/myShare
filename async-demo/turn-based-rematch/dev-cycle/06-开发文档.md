# 第 06 期 · 倒地与起身

> 阶段 B ｜ 预估 1 天 ｜ 状态：未开始 ｜ 依赖：05

## 目标

气血归零进入"倒地"而不是死亡：留在场上、留在速度序列、轮到它时跳过；被治疗回到 >0 就起身，且起身当回合**能不能行动取决于它的出手位是否已经过去**。

## 需求来源

README §4.8（倒地与起身，含 4.8.1 规则表 / 4.8.2 / 4.8.3 三个例子）、§17.2 R-06 / R-07 / R-09、§15.4（术语唯一）

## 本期做什么

- [ ] 状态机加 `DOWN / GETUP`（**只对玩家与敌方单位**；宠物本期不接，`pet` 的 `hp<=0` 先走"移出队列"旧逻辑，第 36 期改成脱战）
- [ ] 倒地：`hp <= 0` → `state = DOWN`，**不移出队列、不清槽位、不判负**
- [ ] 跳过：`DOWN` 单位在速度序列里保留，轮到它时发 `TURN_SKIP` 并跳过
- [ ] 起身：任何治疗后 `hp > 0` → `state = GETUP`（300ms 由表现层消费，内核只切状态）
- [ ] **卡速度**：起身发生在某人出手位之前 → 当回合可行动；发生在之后 → 当回合不再出手（用 `queueIndex` 与 `currentIndex` 比较，别用"回合开始就决定"）
- [ ] 判负：玩家 `DOWN` 且场上无其他存活己方（宠物未接入时视为无）且无待结算持续治疗 → `BATTLE_END(lose)`
- [ ] 判胜：星君与 2 只四象全部 `DOWN` → `BATTLE_END(win)`；星宿战只有 1 个敌方单位
- [ ] 术语：全仓 `grep death|revive|resurrect` 必须为 0；事件名用 `UNIT_DOWN / UNIT_GETUP`
- [ ] `.tmp/down.mjs` 探针：复现 4.8.2 / 4.8.3 的三个例子，断言"能出手 / 不能出手"

## 本期不做（防膨胀）

- 不做宠物脱战与召唤 → 第 36 期（本期宠物一旦归零直接离场，与最终行为一致但无神佑判定）
- 不做倒地立绘、灰化头像、"已倒地"飘字 → 第 12 / 14 期
- 不做倒地单位被选中时的伤害转移（4.8.1 第 3 条）→ 第 13 期（有选目标之后才有意义）
- 不做 AI 救人（四象喂药拉起星君）→ 第 18 期

## 验收

1. 玩家被打到 0 血：不结束战斗、槽位还在、日志出现"已倒地"，速度序列长度不变。
2. 轮到倒地单位时日志出现"跳过"，不消耗指令。
3. 4.8.2 例：宠物比玩家快 → 玩家当回合被拉起后**还能出手**；宠物比玩家慢 → 当回合**不能出手**。两例都在探针里断言。
4. 回合开始的持续治疗把玩家救起 → 当回合可行动。
5. 星君 + 2 四象全倒地 → 立刻胜利；只倒星君而四象站着 → 不判胜。
