# 回声迷踪（Echo Hunter）玩法设计

## 1. 世界观

你操控一只深海巨鲸（圆点 + 摆动的尾巴），被困在漆黑的海底洞穴里。屏幕几乎纯黑，唯一的光源是你发出的声呐脉冲。

## 2. 核心循环（声呐双刃剑）

声呐是唯一的「灯」，也是唯一的「诱饵」——越依赖它看清路，越容易暴露自己。

- 声呐照亮地形与磷虾 → 收益
- 声呐惊动海怪冲向玩家 → 风险

玩法围绕「何时、在哪里发声呐」的决策展开。

玩家唯一的主动反制手段是**回声诱饵**（见第 6 节）：把海怪钓向一个假声源，为自己让出通路。

## 3. 操作

| 输入     | 行为                                                |
| -------- | --------------------------------------------------- |
| 鼠标移动 | 鲸鱼朝鼠标方向游动                                  |
| 左键短点 | 发出单次声呐脉冲                                    |
| 左键长按 | 持续发出声呐脉冲（消耗能量）                        |
| 松开左键 | 能量开始回复                                        |
| 右键     | 冲刺：朝鼠标方向快速位移（冷却约 1.5 秒），用于躲闪 |
| 空格 / 中键 | 抛出回声诱饵：把附近的**海怪钓向落点**（消耗能量、有冷却） |

## 4. 视野与迷雾系统

- 屏幕默认 99% 纯黑。
- 鲸鱼自带极小范围暗光晕（约 70px），只能看到自己脚下。
- **鲸鱼光晕本身就是小声呐**：光晕范围内墙壁/磷虾/道具/小鱼/藤壶会显形，海怪会被惊动（所以摸黑撞海怪也会扣血）。
- 光晕对墙壁是**局部显形**：只照到玩家附近一小段墙，越靠近玩家越亮、向两侧逐渐模糊到看不见（非整条墙亮起）。
- 声呐波纹扫过的**墙壁**显形（发光轮廓线），随后随时间**逐渐淡出到全黑**（约 16 秒），需再次发声呐才能重新看清。
- 声呐波纹扫过的**磷虾 / 海怪**只**瞬时显形**，随后回到黑暗（它们是活的，不会留残影）。

## 5. 声呐系统

| 参数         | 值                                                            |
| ------------ | ------------------------------------------------------------- |
| 能量上限     | 100                                                           |
| 长按消耗     | 30 / 秒                                                       |
| 松开回复     | 40 / 秒                                                       |
| 波纹扩散速度 | 约 500 px/秒                                                  |
| 波纹最大半径 | 约 450 px（有限范围，探路需多次）                             |
| 能量耗尽     | 暂时失明：归零后无法发声呐，需回复到阈值（约 20）才能再次发声 |

## 6. 回声诱饵（Echo Decoy）

声呐双刃剑反过来用：**既然声音能把自己卖出去，也能把替身卖出去。**

朝鼠标方向抛出一枚空心光团（自己也半透明可见），落地后持续发出假脉冲，范围内的海怪会转而冲向它，而不是你。这是玩家唯一的**主动反制手段**——从「躲着走」变成「把它支开，我再绕过去」。

| 参数       | 值                                                    |
| ---------- | ----------------------------------------------------- |
| 能量消耗   | 25 / 次（固定）                                       |
| 冷却       | 4.5 秒                                                |
| 飞行速度   | 620 px/秒                                             |
| 最大射程   | 520 px（撞墙即停在墙前）                              |
| 落地存活   | 3 秒                                                  |
| 假脉冲间隔 | 420 ms                                                |
| 假脉冲半径 | 300 px（明显小于真声呐 450，**当远程灯用不如真声呐**）|
| 场上上限   | 1 枚                                                  |

### 规则

- **双重用途**：假脉冲同样会照亮沿途的墙 / 磷虾 / 道具 / 藤壶 / 小鱼，等于一枚投掷出去的探路灯——但半径更小、还给这一路画了个「海怪会往这走」的标记。
- **每只海怪只上一次当**：海怪冲到假声源发现是空的，会当场识破，之后不再被同一枚诱饵吸引。下一枚新的诱饵仍能有效。
- **真声呐压过诱饵**：被诱饵钓着的海怪一旦进了你的真实声呐（或你自身的光晕），会立刻转向你。**偷鸡不成照样蚀米**——站得太近用诱饵，等于自己喊一嗓子。
- **不重置恐惧阶段**：丢诱饵会像主动发声一样把恐惧倒计时推回满档，但**不会把阶段清零**，只有主声呐能做到。由于 4.5 秒冷却 > 阶段 II 之后 2.5 秒的间隔，**只靠诱饵压制恐惧仍会持续掉血**。

### 视觉

虚线假脉冲环 + 空心像素菱形 + 一圈随寿命收缩的倒计时环——和真实声呐的实线环、所有实心实体在形态上区分开。

## 7. 实体

### 鲸鱼（玩家）

- 圆点，尾巴摆动动画（纯装饰）。
- 平滑插值移动 + 最高速度约 380 px/秒。
- 血量 3 点，受击后 1 秒无敌帧。

### 磷虾（得分道具）

- 普通模式 8~10 只固定位置；无尽模式随机刷新/刷没，保持场上约 9 只。
- 被声呐照到：闪烁一下并发出「叮」回响，约 1.5 秒后回到黑暗。
- 玩家需记住位置，在视觉消失前游过去吃掉。
- 吃掉：+计数、+能量（约 +10）。

### 海怪（敌人）

- 2~3 只，平时隐形、缓慢巡逻（约 120 px/秒）。
- 被声呐照到：瞬间亮红光，朝玩家**发声波的位置**冲刺（约 420 px/秒，略快于鲸鱼），撞墙会**沿墙滑动绕行**。
- 冲到声波位置或约 2.5 秒后失去目标，回到无目的漫游；期间再次被声呐照到会刷新锁定。
- 漫游 = 直线游向随机目标点（当前位置附近），到达后换新点；撞墙则随机换向自然游开。离家太远（>400px）会游回出生点。
- 碰撞：-1 血。

### 出口漩涡

- 收集完所有磷虾后，在地图最深处出现发光漩涡。
- 即使未被声呐照到，也有微弱脉冲光晕隔着迷雾透出，引导玩家方向。
- 游入漩涡 → 过关。

### 拾取道具（被声呐/光晕照到才显形）

- **回血道具**（粉十字）：+1 血（普通模式不超过上限，无尽模式无上限）。
- **回声波能量道具**（绿青闪电）：+40 能量。
- **河豚**（橙色带刺，陷阱）：吃了 -1 血；像小鱼一样漫无目的乱游，撞墙反射转向。
- 普通模式道具位置固定；无尽模式道具随机刷新/刷没。

### 小鱼生态

- 随机时间在地图刷新小鱼，漫无目的游动。
- 被声呐/光晕照到才显形。
- 玩家每吃 10 条小鱼：+30 能量、+1 血。

### 毒液藤壶（墙上的陷阱）

- 沿内部墙等距生成，保证只长在墙上。
- 被声呐/光晕照到才显形。
- 玩家碰到扣 1 血（有 1 秒无敌帧冷却）——防止玩家摸黑硬探路。

## 8. 地图

- 固定设计图，约 3000 × 3000。
- 四周洞壁封闭，构成洞穴。
- 摄像机平滑跟随鲸鱼。
- 磷虾分散在洞穴各处（含死路深处）；海怪分布在各自巡逻区；出口在最深处。

## 9. 胜负条件

- **过关**：集齐所有磷虾 → 出口漩涡出现 → 游入 → 可选择「进入无尽模式」或「再来一局」。
- **无尽模式**：通关后开启；血量无上限（HUD 血量≤3 显示 3 颗心，>3 显示 `xN`）；磷虾/道具/小鱼/海怪随机刷新/刷没；海怪只在玩家视野外刷新、只在视野外刷没；**开启熟练度积分 + DNA 强化加点**；玩家可无限玩下去。
- **失败**：血量扣至 0；死亡界面会根据致死原因显示不同副标题：
  - 被海怪撞击：「海怪抓住了你」
  - 吃到河豚：「河豚的毒刺带走了你」
  - 碰到毒液藤壶：「毒液藤壶吞噬了你」
  - 恐惧吞噬：「黑暗中的恐惧吞噬了你」
- **恐惧值机制**：玩家若一段时间没有主动开声纳，会持续扣血。首次倒计时为 X，触发扣血后变为 X/2，之后固定为 X/3，直到玩家死亡或主动开声纳重置倒计时。

### DNA 强化（无尽模式）

- **熟练度**：无尽模式吃道具积攒——磷虾 +5、小鱼 +2、回血道具 +10、能量道具 +10、河豚 +20（冒险，扣 1 血）。河豚最「值钱」。
- 在左下角 DNA 面板消耗熟练度加点（每系最高 10 级，成本随等级递增）：
  - **胆量**：恐惧基础时长 +8%/级（生存更久才被恐惧惩罚）
  - **皮肤**：无敌帧 +120ms/级（受伤后更难连击）
  - **声呐**：能量回复速度 +5/s、能量上限 +10/级
  - **肌肉**：冲刺冷却 -110ms、冲刺时长 +0.012s/级（更短 CD、更远距离）

## 10. HUD

- 恐惧倒计时进度条（洋红）：显示当前阶段剩余时间，右侧标注阶段 I / II / III+
- 声呐能量条
- 回声诱饵状态条：就绪白色满格 / 冷却中回落并显示剩余秒数 / 能量不足时灰色
- 血量：≤3 时显示 3 颗心；>3 时在 3 颗心后显示 `xN`（如血量 5 显示 `x5`）
- 磷虾收集进度（x / y，无尽模式下 y 为当前存活数）
- 小鱼计数（x / 10，集满奖励）
- 熟练度（无尽模式，基因紫块 + 数字）
- 出口开启提示

## 11. 可调旋钮

能量消耗/回复速率、波纹半径与速度、鲸鱼/海怪速度、海怪冲刺时长、无敌帧时长、残影亮度、光晕半径、磷虾/海怪数量。

诱饵（`constants.js` 的 `CONFIG.decoy`）：`cost` 能量消耗、`cooldown` 冷却、`speed` 飞行速度、`range` 射程、`lifeMs` 存活时长、`pulseMs` 假脉冲间隔、`pulseRadius` 假脉冲半径。

## 12. UI 风格（像素风 · 深海发光）

- 方向：代码生成像素风，零美术资源。
- 像素颗粒：细像素（逻辑格 1~2px）。
- 背景：深蓝黑 `#020409`。
- 辉光：硬像素主体 + 发光物多层同心半透明光晕。
