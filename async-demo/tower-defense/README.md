# 塔防（Tower Defense）玩法设计

> 单关地图：21 × 21 网格 + 两条不重叠的 S 形路径，玩家在可建区摆建筑、操作一名英雄，抵御 30 波 + 6 Boss，进入无尽模式。

---

## 核心循环

```
开始一关 → 准备阶段（建塔 / 移动旧塔 / 选英雄技能路线）
  → 敌人波次推进 → 击败 → 金币 / 经验
  → 升级塔 / 升级兵营活动范围 / 升级英雄技能
  → 下一波 → 击败 Boss → 第 30 波结束
  → 选择「结算退出」或「进入无尽」→ 难度递增、无限波次
```

- 主线 30 波 + 6 Boss（每 5 波一个）。
- 第 30 波后进入**无尽模式**：敌人难度递增、刷新精英怪，玩家可随时结算退出。
- 失败条件：英雄血量归零 或 任意一波累计漏怪 20 个。
- 玩家金币有限，必须在「地形」「塔种搭配」「兵营活动范围」「英雄技能路线」之间取舍。

## 地图与路径

- 21 × 21 网格，每格 32 px，画布 672 × 672。
- **两条单调下降的 S 形路径**，分别独立推进敌人：
  - **路径 A（蓝 · 上蛇）**：左入口 `(0, 1)` → 右出口 `(20, 10)`，4 段横向逐行下移。
  - **路径 B（红 · 下蛇）**：右入口 `(20, 11)` → 左出口 `(0, 19)`，4 段横向逐行下移（镜像）。
- 两条路径分居**上下两个半区**。
- **可建区**：去掉两条路径的所有格子，共 **382 格**。
- 路径由若干「中心点」用折线连接，敌人沿中心点按线性插值前进。

> 路径 A 30 格 / 路径 B 29 格 / 可建区 382 格。

### 路径 A 走向（蓝色 · 上蛇）

```
入口(0,1) ─横→ (3,1) ─纵→ (3,4) ─横→ (8,4) ─纵→ (8,7)
        ─横→ (13,7) ─纵→ (13,10) ─横→ 出口(20,10)
```

### 路径 B 走向（红色 · 下蛇）

```
入口(20,11) ─横→ (17,11) ─纵→ (17,14) ─横→ (12,14) ─纵→ (12,17)
          ─横→ (7,17) ─纵→ (7,19) ─横→ 出口(0,19)
```

## 建筑

> 所有塔占 1 格、不可叠加。建造冷却 0.5s。
> **全部建筑统一 6 级（Lv1 → Lv6）**，升级 5 次；每一级外观都有可辨识的区别 + 顶部等级徽章。
> 每级提升 ≈ +30% 伤害 / +8% 范围 / -7% 攻速（各塔微调）。

### 兵营（Barracks）

| 属性      | 值                       |
| --------- | ------------------------ |
| 基础价    | 50 金                    |
| 满级      | 6 级（0→5，升级价 40/80/120/160/200） |
| 小兵上限  | Lv1=1 只，每级 +1，最多 6 只 |
| 小兵生命  | Lv1=18 → Lv6=140（随等级提升） |
| 小兵伤害  | Lv1=10 → Lv6=46（随等级提升） |
| 小兵索敌  | **固定 2 格**（不随升级变大） |
| **集结范围** | Lv1=1.5 格 → Lv6=8.0 格（随等级扩大；决定玩家能把集结点设到离兵营多远，选中兵营可见绿圈） |
| **集结点** | **可手动设置**：选中兵营 → 点「设置集结点」→ 在集结圈内点目标格（超出范围会被拒）。小兵默认出生在集结点、脱战后回到集结点 |
| **补给**  | 小兵有血条，被敌人磨死/换掉后兵营等待一段补给延迟再补一只（延迟随等级缩短：5s→2.5s） |
| 特殊      | 对飞行/隐身都有效（靠小兵物理接触） |
| **阻挡机制** | **地面敌人**进入小兵 1 格范围即**停下攻击**（击杀挡路者才继续前进）；**飞行单位（含飞行 Boss）**直接越过地面小兵、不受阻挡 |

定位：近身压制、低价铺场。**唯一具有物理阻挡、能让敌人停下脚步的塔**。集结点让小兵驻守在你指定的路段：敌人经过时会被小兵拦停并持续输出，是「留人」拖慢敌人节奏的核心手段。升级提升小兵数量/属性/补给，并扩大**集结圈**（可把集结点设到更远的路段）；小兵索敌范围固定。

## 英雄

> 英雄**等同于一座可移动的防御塔**，但**有血量**——如果数值堆错或操作不当，会被敌人打死。
> 玩家通过「技能选择」+「技能升级路线」决定英雄是偏向**辅助（治疗/减速/增益塔）**还是**输出（高伤害 DPS 塔）**。

### 英雄属性

| 属性      | 值                            |
| --------- | ----------------------------- |
| 移动      | WASD / 方向键                  |
| **血量** | **100 / 150 / 200（按难度）**  |
| 死亡      | **游戏失败**（回到准备阶段重开）|
| 移动速度  | 220 px/s                      |
| 物理碰撞  | **有**：英雄占据路径格子时，**该敌人会被挡住**（不能前进），这是英雄的核心功能之一 |
| **普攻** | **自动近战斩击**：攻击范围内（84px）自动锁定最近敌人，射出弧形光刃，18 伤害 / 480ms 冷却；被斩中的敌人短暂僵直（会短暂停下，利于继续集火）。敌人**停下攻击英雄**时仍会被普攻击中 |
| 升级      | 升级技能 = 提升英雄实力         |

> 英雄不是无敌路障，而是「需要操作的高价值塔」：占位能挡路，被集火会死（敌人停下打他），但也会用普攻反击。
> 因此科技前哨站不仅提供技能，还提供 **治疗 / 护盾 / 减伤**类升级路线，让玩家能"奶"自己。

### 英雄操作

| 操作        | 效果                          |
| ----------- | ----------------------------- |
| 移动        | WASD / 方向键平滑移动           |
| 鼠标位置    | 影响主动技能方向                |
| 鼠标左键    | 主动技能 1（默认：弹幕箭雨） |
| 鼠标右键    | 主动技能 2（默认：横扫冲击波）|
| Q/W/E/R     | 4 个技能槽，对应科技前哨站技能  |
| 空格        | 暂停                          |
| ~           | 开/关调试面板（默认隐藏，也可点左下角「🐞 调试面板」按钮） |

### 技能系统（由科技前哨站分配/升级）

> 起始自带 1 个「横扫冲击波」（近身 360° 推开周围敌人，2.5s 冷却，0 伤害）。
> 其余 4 个主动技能由**科技前哨站主动分配**：选中前哨站 → 面板点选技能。前哨站等级 = 技能等级，升级前哨站即升级技能。
> 另有第 6 个槽位「**血契**」——唯一**可叠加**的被动技能（见下文）。

| 技能         | 满级 | 基础效果                          | 升级路线                          | 满级光环（6 级） |
| ------------ | ---- | --------------------------------- | --------------------------------- | ----------------- |
| 横扫冲击波   | 5    | 360° 推开 80px 内敌人，2.5s CD（无伤害）| 推力↑、半径↑、CD↓               | - |
| 弹幕箭雨     | 6    | 朝鼠标方向射出 5 支箭，每支 12 伤害，8s CD | 箭数↑、伤害↑、CD↓ | **攻速光环**：英雄范围内建筑攻速提升 |
| 治愈之风     | 6    | 5 格内塔每秒回血，持续 5s，15s CD | 持续↑、回血↑、CD↓ | **恢复光环**：英雄范围内小兵持续回血 |
| 雷霆链       | 6    | 向最近敌人发射连锁闪电，4 个目标，每跳 18 伤害，12s CD | 连锁↑、伤害↑、CD↓ | **吸血光环**：英雄/小兵攻击吸血 25% |
| 终极射线     | 6    | 射线持续 1.5s，期间英雄无敌，30s CD | 持续↑、伤害↑、CD↓ | **增伤光环**：英雄/小兵/塔伤害 +35% |

> 5 个技能最多 6 级（前哨站升到 6 级即满）。满级时弹幕/治愈/雷霆/终极射线各自释放一个被动光环，让英雄范围内的单位受益。
> 光环示例：
> - 弹幕箭雨满级 → 英雄附近（3.5 格）所有建筑攻速加快
> - 治愈之风满级 → 英雄附近的小兵每秒回血
> - 雷霆链满级 → 英雄和小兵每次攻击回复造成伤害的 25%
> - 终极射线满级 → 全体我方单位伤害提升 35%

### 血契（可叠加的前哨站被动技能）

不同于其他 4 个互斥技能，**多座前哨站可以同时缔结血契**，加成全部叠加：

| 项目      | 规则                                                     |
| --------- | -------------------------------------------------------- |
| 类型      | 被动（不占 Q/W/E/R/T 主动技能键，不解锁主动技能）        |
| 叠加      | 每座缔结血契的前哨站按**自身等级**提供加成，全部相加     |
| 额外生命  | Lv1=+40 → Lv6=+200，**无上限**（塔越多叠越高）           |
| 减伤      | Lv1=4% → Lv6=15%，**上限 60%**                           |
| 吸血      | Lv1=3% → Lv6=12%，**上限 35%**（与雷霆链吸血光环相加）   |
| **复活**  | 每座**满级（Lv6）血契前哨站提供 1 次复活**：英雄阵亡时原地复活 60% 生命 + 1.5s 无敌，**消耗掉该座前哨站**（塔被摧毁，其加成随之消失） |

> 示例：5 座前哨站 abcde 都选血契，英雄加成 = a塔(按其等级) + b塔 + c塔 + d塔 + e塔。
> 顶栏会显示「血契 ×N」与「复活 n」；左栏状态区显示当前叠加的总加成。

## 科技前哨站详解

科技前哨站是「技能塔」：放置后由玩家**主动选择**它携带的技能（弹幕箭雨/治愈之风/雷霆链/终极射线/**血契**）。弹幕/治愈/雷霆/终极射线互相**互斥**（一座选了 A，其他前哨站不能再选 A）；血契**可叠加**（任意多座都能选）。

| 等级 | 效果                                                         |
| ---- | ------------------------------------------------------------ |
| 0    | 放置后需在面板选技能；不攻击                        |
| 1~2  | 仅作为技能载体（等级=英雄技能等级）            |
| 3+   | 解锁攻击：低伤 + 减速敌人（升级提升伤害/攻速/减速） |
| 6    | 满级：对应的技能光环生效（见 5.3）           |

- 每级前哨站给英雄**累加**属性成长：+12 最大 HP、+3 普攻伤害、普攻冷却 -25ms。
- 多座前哨站可携带不同技能，同技能前哨站取最高等级；血契例外——按各塔等级**叠加**。
- 科技前哨站数量不限，可按需多造。

## 反隐塔详解

| 参数      | 值                            |
| --------- | ----------------------------- |
| 侦测半径  | Lv1=3 格 → Lv6=4.6 格（随等级扩大） |
| 揭示时机 | 敌人中心点进入光环即显形      |
| 离场衰减 | 离开光环后 2s 内轮廓渐隐回 0  |
| 毒雾      | **Lv3 解锁**：周期喷毒（间隔 6s → Lv6 4.6s），雾内敌人受伤 +35% → Lv6 +80%、持续掉血（DPS 6 → 13） |
| 协同      | 显形状态下，箭楼/炮营/兵营都能打 |

> **核心策略**：隐身波次必须在路径旁边铺至少 1 座反隐塔，否则隐身敌人白送。升级能扩大侦测；三级反隐塔还能用毒雾压制一整条路径。

## 经济与波次

### 经济

- 起始金币：200。
- 击杀敌人：按上表奖励。
- 每波结束奖励：10 + 波次 × 5。
- Boss 击败奖励：100 + 波次 × 20。
- 利息系统：无（避免过度囤积，强制多波博弈）。
- **塔移动花费**：基础价 × 0.3（约等同一次升级的开销）。
- **英雄治疗费用**：从塔商店购买治疗药水（可恢复 30 HP，30 金币/瓶）。

### 波次

- 主线 **30 波**，第 5/10/15/20/25/30 波为 Boss（共 6 个）。
- 1~4 波：纯普通。
- 5 波：第一个 Boss。
- 6~9 波：开始混少量飞行。
- 10 波：第二个 Boss。
- 11~14 波：开始混隐身。
- 15 波：第三个 Boss。
- 16~19 波：三型混合。
- 20 波：第四个 Boss（幽能龙）。
### 波次主题（每 5 波循环一次）

> 常规构成之外，每个波段额外叠加一种「压力类型」，让波次有辨识度而非同一模板。

| 主题 | 波段 | 附加内容 |
| --- | --- | --- |
| **冲锋潮** | 1~4 / 26~29 / … | 大量高速冲锋兵突进 |
| **空袭波** | 6~9 / … | 飞龙集群（地面塔无效，必须有箭楼/炮营） |
| **装甲纵队** | 11~14 / … | 高减伤装甲兵压境 |
| **影袭波** | 16~19 / … | 隐身单位密集（缺反隐必漏） |
| **围城波** | 21~24 / … | 巫医治疗 + 分裂怪**爆发**（叠加在常驻池之上，巫医整波封顶 6 只） |

> Boss 波（每 5 波）不套主题。同种类主题加成会**合并进既有分组**，不会出现两个同种类队列。

### 常驻敌人解锁（按波次混入基础构成）

主题每 25 波才轮到一次，单靠主题的话巫医 / 分裂怪在 30 波主线里只露面 4 波。因此这两种改为**按波次解锁的常驻池**，主题只作为它们的爆发波：

| 敌人 | 解锁波次 | 数量公式（w = 波次，上限 30 波封顶） |
| --- | --- | --- |
| 飞行 | 第 6 波 | `w - 4` |
| 隐身 | 第 11 波 | `w - 9` |
| **分裂怪** | **第 14 波** | `(w - 12) × 0.5` |
| **巫医** | **第 18 波** | `(w - 16) × 0.25`，整波封顶 6 只 |

- 21~24 波：精英怪 + 三型混合（精英怪 = 普通怪 × 3 血量 × 1.5 奖励）。
- 25 波：第五个 Boss（暗影领主）。
- 26~29 波：精英怪密度提升 + 终极混合精英。
- 30 波：第六个 Boss（终极 Boss，**关卡最终考验**）。
- 敌人数量按波次线性增长：第 n 波普通怪数 = 5 + n × 2；飞行 5 波后每波 +1；隐身 10 波后每波 +1（分裂怪 / 巫医见上表常驻解锁）。

### 出怪密度（间隔压缩）

稳态同屏敌人 ≈ 走完全程耗时（约 19s）÷ 出怪间隔，所以**同屏压力几乎全由间隔决定**，只堆数量提不上来。

| 波次 | 间隔系数 | 说明 |
| --- | --- | --- |
| 1~8 | 1.00 | 新手期不压缩，避免劝退 |
| 12 / 16 / 20 / 24 | 0.90 / 0.80 / 0.70 / 0.60 | 线性收紧 |
| 30 波以后 | 0.45 | 无尽期固定，同屏峰值可达 60+ |

> 实测：全局一刀切 ×0.6 会把新手期压死（3 座塔从撑到第 8 波 → 第 6 波就漏满），因此改为渐进式。

### 无尽模式（第 30 波之后）

> 击败 30 波终极 Boss 后自动进入无尽模式，波次无限继续。

- **波次模板**：超过 30 波沿用 30 波构成，数量按每波 +8% 增长，且**每种敌人有数量上限**（普通 84 / 飞行 45 / 隐身 39 / 冲锋 42 / 装甲 34 / 巫医 20 / 分裂 28），避免同屏敌人无限堆叠。
- **属性递增**：敌人属性（血量）按**每波 +4%** 递增（`endlessK`），叠加波次本身的线性成长。60 波时总倍率约 **8.96×**（改前为 6.16×）。
- **Boss**：每 5 波出现一次，6 种 Boss 循环复用（飞龙母舰 → 幽影领主 → 钢铁巨像 → 幽能龙 → 暗影领主 → 终极混合 → 重复），强度随属性递增。
- **同屏软上限**：同屏敌人达到 120 时暂停出怪（队列冻结不丢弃），敌人减少后自动继续——保证任何情况下帧率稳定。
- 无尽模式不计入主线通关（`victory` 只在首次通关时提示）。

### 性能保障

- **单位精灵缓存**（`draw/units/spriteCache.js`）：敌兵/飞龙/幽影按「种类 × 朝向 × 8 动画帧」预渲染到离屏 canvas，绘制时仅 `drawImage`。同屏 400 敌人稳定 60 FPS。
- 逻辑层（寻路 / 塔索敌 / 弹道）在 600 敌人时约 1.4ms/帧，非瓶颈。
- 火焰区 / 毒雾按寿命自动清理，无累积泄漏。

### 失败条件

- 英雄血量归零 → 失败。
- 任意一波累计漏怪 20 个 → 失败。
- 漏普通 1 个、飞行 1 个、隐身 1 个都算 1。
- 失败显示波次和漏怪统计，可重开关卡。

## 设计目标

- **单局 25~30 分钟**内可完成（不含无尽模式）。
- **塔种克制清晰**：5 种塔各有不可替代的角色，没有「最强塔」。
  - 兵营：覆盖近身、可挡路、可打飞行/隐身
  - 炮营：远程溅射、可打飞行、群体削血
  - 箭楼：高频单体、对空主力
  - 科技前哨站：英雄成长核心
  - 反隐塔：隐身波次必需
- **英雄是核心变量**：可被打死、需要操作；技能路线决定辅助还是输出；终极射线是救场神技。
- **塔可移动**：玩家必须根据敌人路径变化动态调整防线。
- **兵营活动范围是关键设计**：升级兵营不只是增伤，更是增「覆盖」——必须贴着路径放。
- **失败有反馈**：漏怪统计 + 英雄死亡时间点，帮助玩家复盘。
