# 多少兄弟？(how-many-dudes)

受 Steam 游戏《多少兄弟？(How Many Dudes?)》启发的**肉鸽自走棋网页 Demo**。招募兄弟、构筑羁绊、收集遗物，扛过 20 关战役后挑战随波次无限成长的敌人。

---

## 1. 核心玩法循环

```
开始 → 商店(招募/强化/羁绊) → 布阵战斗(自动) → 胜利结算(金币+遗物三选一)
  ↑                                                        ↓
  └──────────── 重铸遗物 / 跳过 ←── 选择遗物 ←──────────────┘

20 关通关 → 通关面板 → 无尽模式(波次缩放) → 阵亡 → 结算面板
```

| 阶段 | 阶段名 | 玩家操作 |
|---|---|---|
| 开始 | `PHASE.START` | 开始新游戏 |
| 商店 | `PHASE.SHOP` | 买兄弟 / 升级属性 / 刷新商店 / 卖兄弟 / 开战 |
| 战斗 | `PHASE.BATTLE` | 无操作，自动战斗（Canvas 实时渲染） |
| 结算 | `PHASE.BATTLE_RESULT` | 遗物三选一 / 重铸 / 跳过 |
| 通关 | `PHASE.VICTORY` | 进入无尽模式 |
| 失败 | `PHASE.GAME_OVER` | 查看战报，重开 |

**战斗规则**：兄弟自动索敌（最近单位）、移动、攻击；玩家零操作。己方布阵区为左侧 4×5 格，敌方从右侧进场。一方全灭即结束，同帧同灭判玩家胜。

## 2. 经济系统

| 参数 | 数值 |
|---|---|
| 初始金币 | 8 |
| 商店刷新 | 1 金（每次随机 3 个兄弟） |
| 升级费用 | baseCost × (当前等级+1)，逐级递增 |
| 卖兄弟 | 固定返 1 金 |
| 关卡奖励 | 4~25 金，随关卡递增 |
| 金币袋遗物 | 每回合额外 +2 金（可叠加） |

**阵容上限**：`4 + 回合数 × 2`，上限 50；无尽模式按 `19 + 波次` 继续增长。

**同种上限**：同名兄弟最多 5 个（`MAX_DUPLICATES`）。

购买受阻时（金币不足 / 阵容满 / 同种满）卡片置灰 + 显示红色原因标签 + 底部提示条 2 秒淡出。

## 4. 遗物系统（21 种）

- **获取**：每场战斗胜利后三选一（`common:rare:epic = 5:3:1` 加权随机），可花费金币重铸（首 2 金，每次 +1）
- **叠加**：同一遗物可重复获取并叠加，达到 `maxStacks` 后从池中剔除
- **叠加规则**：攻击/生命/移速/固定攻击等数值型效果线性叠加；**概率/减伤/反弹/吸血类（闪避、铁壁石、荆棘甲、暴击、连击、吸血牙）采用乘算递减 `1-(1-v)^N`**——每层作用于剩余部分，永不溢出，防止后期免伤/百暴（如铁壁石 6 层 ≈53.6% 而非 72%，幻影披风 5 层 ≈55.6% 而非 75%）
- **伤害下限**：减伤结算后单次伤害至少 1 点，杜绝绝对免疫
- **只作用于玩家方**：所有战斗内遗物效果（暴击/吸血/狂暴/连击/溅射/穿透等）均带 `side === 'player'` 过滤，敌方不享受

**对数增长设计**：水晶球（攻击范围）与范围光环（近战溅射）采用共享函数

```
logMult15(stacks) = 1 + 0.5 · ln(1+s) / (1 + ln(1+s))    // 渐近 1.5 倍上限
```

选择卡片时会预览「当前 X.XXXx → 选择后 X.XXXx」，方便玩家决定是否继续冲上限。

## 6. 关卡与无尽模式

### 6.1 战役（4 幕 20 关）

| 幕 | 关卡 | 登场敌人 |
|---|---|---|
| 一 | 1-5 | 熊孩子、野狼、弓箭手、大猩猩(BOSS) |
| 二 | 6-10 | +蝙蝠、自爆兵、暗影、重甲兵、战争领主(BOSS) |
| 三 | 11-15 | +医疗兵、神明、死灵法师(BOSS) |
| 四 | 16-20 | +石巨人、九头蛇(BOSS)，终局双神明+石巨人+死灵 |

### 6.2 无尽模式（通关后开启）

| 参数 | 公式 |
|---|---|
| 小怪数量 | `8 + 波次×3`，上限 200 |
| 敌人属性倍率 | `1 + 波次 × (0.08 + 0.02·√波次)` |
| Boss 概率 | `20% + 波次×5%`，上限 80%；每 5 波固定 Boss 战 |
| Boss 数量 | `1 + 波次/5`，上限 5 |
| 敌人池 | 前 5 波基础 / 5-14 中级 / 15+ 全池 |

**平衡锚点**：玩家成长与敌人成长曲线约在 **W20-25 交叉**，正常构筑 20-25 波后开始吃力，属预期体验。

## 7. 战斗引擎

- **帧率无关**：`dt = (timestamp - lastTime)/1000`，移动/投射物/回复/燃烧均按时间增量计算（`speedScale = dt×60`，60fps 时=1），120Hz/144Hz 屏节奏一致；dt 上限 0.1s 防切后台跳帧
- **性能优化**：浅引用快照（不深拷贝）、投射物碰撞预分阵营（O(P×N)→O(N+P×K)）、平方距离比较、死亡敌人定期清理、渲染边界剔除
- **投射物**：支持穿透、AOE、边界销毁、飞行 400px 上限
- **单位机制**：治疗（范围=攻击范围）、召唤（共享 id 计数器）、荆棘反弹、复活甲、牧师复活（每场一次）

## 8. 项目结构

```
how-many-dudes/
├── index.vue                    # 路由入口
├── constants.js                 # 全部数值定义（兄弟/敌人/遗物/关卡/羁绊）
├── composables/
│   ├── useGame.js               # 游戏状态机：商店/经济/遗物/关卡流转
│   └── useBattle.js             # 战斗引擎：索敌/移动/攻击/死亡/特效
├── components/
│   ├── GameMain.vue             # 主容器 + 阶段路由
│   ├── StartPanel.vue           # 开始面板
│   ├── ShopPanel.vue            # 商店（购买/升级/羁绊/购买反馈）
│   ├── BattleCanvas.vue         # Canvas 战场 + rAF 主循环
│   ├── BattleResultPanel.vue    # 遗物三选一（含倍率预览/重铸）
│   ├── GameOverPanel.vue        # 失败/无尽结算
│   └── VictoryPanel.vue         # 通关面板
└── draw/
    ├── renderer.js              # 绘制调度（血条/投射物/特效/边界剔除）
    └── units/                   # 27 个单位独立绘制函数 + 注册表
```

**约定**：所有数值集中在 `constants.js` 单点维护；公共 API 带 JSDoc；对数增长共享 `logMult15()`，供逻辑与 UI 预览统一引用。
