# 台球 · 黑八（billiards）

Vue3 + Canvas 的中式八球（黑八）单人对战 demo，玩家 vs 电脑，先猜拳决定开球权。

## 1. 核心概念

| 名称 | 说明 |
| --- | --- |
| 母球 | 白球（0 号），**唯一**能被球杆直接击打的球 |
| 全色 | 1–7 号，纯色球 |
| 花色 | 9–15 号，条纹球 |
| 黑八 | 8 号，决胜球，必须最后打 |

## 2. 规则实现

### 2.1 摆球

- 三角框 15 颗目标球摆紧，顶点（apex）落在**置球点** `FOOT_SPOT = (0.75W, 0.5H)`，顶角朝向母球。
- 行间距 `√3·r`，列间距 `2r`（`r` 为球半径），乘以 `1.004` 的贴合系数保证"摆紧但不重叠"。
- 8 号球固定第三排正中；底角两颗强制一全色一花色，其余随机。

### 2.2 开球

- 猜拳（石头/剪刀/布）决定先手，平局重来。
- 先手进入"自由摆放"状态，母球只能放在**开球线**（`0.25W`）左侧的厨房区。
- 开球结果：
  - 打进球 → 打进哪组就归哪组；两组都进 → 自己选。
  - 两组都进且是电脑 → 电脑自动挑（打进多的那组）。
  - 没进球 → 换对手，球台仍是"开放台面"。

### 2.3 轮流

打进自己组的球 → 继续；没进或犯规 → 换对手。

### 2.4 犯规（换对手 + 对手获得自由球）

| 犯规 | 判定 |
| --- | --- |
| 母球落袋 | 母球中心进入袋口半径 |
| 母球飞出台面 | 母球越过台面边界且不在袋口吸附范围内 |
| 先碰对方球 | 首个接触球不属于自己组（且自己组未清完） |
| 提前碰黑八 | 首个接触球是 8 号且自己组未清完 |
| 空杆 | 母球一颗目标球都没碰到 |
| 连击 / 推杆 | 母球与**同一颗**球在 120ms 内二次接触，且中间没有任何母球事件（撞库 / 撞球） |

### 2.5 直接输局

1. 自己组的球没清完，把黑八打进袋
2. 打黑八时母球跟着落袋
3. 黑八被打飞出台面

### 2.6 胜利

先清完自己 7 颗球 → 再把黑八打进（母球不落袋）→ 获胜。

## 3. 物理

```
摩擦：decel = FRICTION_BASE + FRICTION_K * speed      （线性 + 速度项）
静止阈值：speed < STOP_SPEED -> 归零
库边恢复系数：0.72（切向 *0.96）
球球恢复系数：0.94（等质量，沿法线交换动量）
子步长：steps = clamp(ceil(maxSpeed * dt / (r*0.3)), 1, 60)
```

- 袋口吸附：球心距袋心 < 袋口半径 → 落袋；袋口附近（`r + r*0.5`）不反射库边，越界后强制吸入最近袋口，避免卡在袋口。
- 角袋半径 24，中袋半径 20（中袋略浅，降低沿库球被误吞的概率）。

## 4. 瞄准辅助线

从母球沿瞄准方向做射线：

1. 与所有活球做「半径 `2r` 的圆-射线」求交，取最近交点 → **幽灵球**位置（碰撞瞬间母球中心）。
2. 目标球出球方向 = `normalize(目标球 - 幽灵球)`。
3. 母球分离方向 = 母球速度去掉法向分量后的切向。
4. 未命中球则画到库边交点。

## 5. 电脑 AI

- **开球**：瞄准球堆顶球，满力 + 微小角度抖动。
- **常规**：枚举「自己的球 × 6 个袋口」：
  - 幽灵球位置 `g = t - u·2r`
  - 母球 → `g` 路径无阻挡、`t` → 袋口路径无阻挡
  - 切角 `cut` 上限 ~75°
  - 打分 `cos(cut)*120 + 距离奖励 - 切角惩罚`
  - 力度 `0.34 + (母球行程 + 目标球行程)/1500 + |cut|*0.12`
- **无解**：打安全球，撞最近的自己球，中等力度 + 随机偏移。
- **自由球**：随机采样 40 个合法点，每个点跑一次选球打分，取最高分落点。
