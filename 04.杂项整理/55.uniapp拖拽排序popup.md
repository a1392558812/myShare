# uni-app 底部弹窗拖拽排序方案

基于 **uni-app + uView**（`uv-popup` / `uv-icon` / `uv-button` / `uv-empty`）实现的一套「在底部弹窗内长按拖拽排序」方案，由两个组件组成：

- `DragSort.vue`：通用拖拽排序列表，负责手势计算与列表重排，与弹窗无关，可独立使用。
- `SortPopup.vue`：基于 `uv-popup` 的弹层，内部嵌入 `DragSort`，并接入「长按拖拽、松手锁定、确认回传」的交互流程。

交互要点：**默认不可拖拽**，长按右侧手柄后开启拖拽（`disabled` 置否），松手即锁定，点击「确认」将最终顺序通过 `sortConfirm` 事件回传给父组件。

---

## DragSort.vue

通过 `touchstart / touchmove / touchend` 计算拖动项与目标索引，拖动期间用 `transform: translateY` 做位移与让位动画，松手后通过 `update:list` 抛出重排后的新数组（不直接修改 props，符合单向数据流）。

```vue
<template>
  <view v-if="componentKey > 0" :key="componentKey" class="draggable-list">
    <view
      v-for="(item, index) in props.list"
      :key="item[idKey]"
      class="draggable-item"
      :class="{ dragging: draggingIndex === index }"
      :style="getItemStyle(index)"
      @touchstart="onTouchStart($event, index)"
      @touchmove="onTouchMove($event)"
      @touchend="onTouchEnd($event)"
    >
      <slot :item="item" :index="index" />
    </view>
  </view>
</template>

<script lang="ts" setup>
import type { CSSProperties } from 'vue'
import { getCurrentInstance, nextTick, onMounted, ref, watch } from 'vue'

interface DraggableItem {
  [key: string]: any
}

const props = withDefaults(defineProps<{
  list: DraggableItem[]
  idKey: string | number
  disabled: boolean
}>(), {
  idKey: 'id',
  disabled: true,
})

const emit = defineEmits<{
  (e: 'update:list', list: DraggableItem[]): void
  (e: 'touchStart', event: any, index: number): void
  (e: 'touchMove', event: any): void
  (e: 'touchEnd', event: any): void
}>()

const instance = getCurrentInstance()
const draggingIndex = ref<number | null>(null)
const dragTargetIndex = ref<number | null>(null)
const startY = ref(0)
const offsetY = ref(0)
const isTransitioning = ref(false)
const dragStartList = ref<DraggableItem[]>([])

const itemsLayout = ref<{ top: number, bottom: number, height: number }[]>([])
const componentKey = ref(1)

const updateItemsLayout = () => {
  if (!instance)
    return

  // 等 DOM 渲染完成后再测量，避免拿到 0 尺寸
  setTimeout(() => {
    uni.createSelectorQuery().in(instance).selectAll('.draggable-item').boundingClientRect((rects: any) => {
      if (Array.isArray(rects) && rects.length > 0) {
        itemsLayout.value = rects.map(r => ({ top: r.top, bottom: r.bottom, height: r.height }))
      }
    }).exec()
  }, 50)
}

onMounted(() => nextTick(updateItemsLayout))

const onTouchStart = (event: any, index: number) => {
  if (props.disabled)
    return

  // 布局尚未测量时补测一次，仍失败则放弃本次拖拽
  if (itemsLayout.value.length === 0) {
    updateItemsLayout()
    if (itemsLayout.value.length === 0)
      return
  }

  dragStartList.value = [...props.list]

  draggingIndex.value = index
  dragTargetIndex.value = index
  startY.value = event.touches[0].clientY
  offsetY.value = 0
  isTransitioning.value = false
  emit('touchStart', event, index)
}

const onTouchMove = (event: any) => {
  if (props.disabled || draggingIndex.value === null)
    return

  const currentY = event.touches[0].clientY
  offsetY.value = currentY - startY.value

  const fromIndex = draggingIndex.value
  const layout = itemsLayout.value

  // 以被拖拽项当前中心位置，匹配最近的列表项中心，作为落点
  const draggedCenterY = layout[fromIndex].top + layout[fromIndex].height / 2 + offsetY.value

  let closestIndex = fromIndex
  let minDiff = Infinity

  for (let i = 0; i < layout.length; i++) {
    const targetItemCenterY = layout[i].top + layout[i].height / 2
    const diff = Math.abs(draggedCenterY - targetItemCenterY)
    if (diff < minDiff) {
      minDiff = diff
      closestIndex = i
    }
  }

  let newTarget = Math.max(0, Math.min(props.list.length - 1, closestIndex))

  if (newTarget !== dragTargetIndex.value)
    dragTargetIndex.value = newTarget

  emit('touchMove', event)
}

const resetDragState = () => {
  draggingIndex.value = null
  dragTargetIndex.value = null
  offsetY.value = 0
  dragStartList.value = []
}

// 强制重建组件，使过渡结束后的最终布局正确落地
const resetAndForceRender = () => {
  isTransitioning.value = false
  resetDragState()
  componentKey.value = 0
  setTimeout(() => {
    componentKey.value++
    nextTick(updateItemsLayout)
  }, 1)
}

const onTouchEnd = (event: any) => {
  if (props.disabled)
    return

  const from = draggingIndex.value
  const to = dragTargetIndex.value

  if (from === null || to === null) {
    resetAndForceRender()
    return
  }

  // 落点与起点相同：仅复位，不触发更新
  if (from === to) {
    resetDragState()
    nextTick(() => componentKey.value++)
    return
  }

  isTransitioning.value = true
  const newList = [...dragStartList.value]
  const [itemToMove] = newList.splice(from, 1)
  newList.splice(to, 0, itemToMove)
  emit('update:list', newList)
  resetDragState()
  emit('touchEnd', event)
}

const getItemStyle = (index: number): CSSProperties => {
  const from = draggingIndex.value
  const to = dragTargetIndex.value

  if (from === null || to === null)
    return {}

  // 被拖拽项：跟随手指位移并轻微放大，置于顶层
  if (index === from) {
    return {
      transform: `translateY(${offsetY.value}px) scale(1.05)`,
      transition: 'none',
      zIndex: 100,
    }
  }

  const draggedItemHeight = itemsLayout.value[from]?.height
  if (!draggedItemHeight)
    return {}

  // 让位动画：起点与目标之间的项向反方向平移一个行高
  if (from < to && index > from && index <= to) {
    return { transform: `translateY(-${draggedItemHeight}px)` }
  }
  if (from > to && index < from && index >= to) {
    return { transform: `translateY(${draggedItemHeight}px)` }
  }

  return {}
}

watch(() => props.list, (newList, oldList) => {
  // 过渡进行中且顺序确实变化时才强制重建，避免抖动
  if (isTransitioning.value && newList.length > 0 && oldList.length > 0 && JSON.stringify(newList) !== JSON.stringify(oldList)) {
    resetAndForceRender()
  }
  nextTick(updateItemsLayout)
}, { deep: true })

defineExpose({ onTouchStart })
</script>

<style scoped>
.draggable-list {
  position: relative;
}

.draggable-item {
  position: relative;
  transition: transform 0.2s ease;
}

.dragging {
  z-index: 100 !important;
  opacity: 0.9;
  background-color: #ffffff;
  box-shadow: 0 6px 16px rgba(0, 0, 0, 0.2);
}
</style>
```

## SortPopup.vue

封装 `uv-popup`，内部用 `DragSort` 渲染列表；默认 `dragSortDisabled = true` 锁定拖拽，长按右侧手柄（箭头图标）才解锁并主动调用 `DragSort` 的 `onTouchStart` 进入拖拽，松手即重新锁定。点击「确认」通过 `sortConfirm` 回传当前顺序。

```vue
<template>
  <uv-popup
    :ref="(ref: any) => sortPopup.ref = ref"
    mode="bottom"
    round="32rpx"
    @change="sortPopup.onSortPopupChange"
  >
    <view class="relative p-[28rpx]">
      <view class="absolute right-[28rpx] top-[28rpx]" @click="sortPopup.toSortPopupClose">
        <uv-icon name="close-circle" :size="`${28}rpx`" color="#4E526D" />
      </view>

      <view class="mb-[28rpx] text-left text-[30rpx] leading-[42rpx] text-[#13113E] font-[PingFangSC,_PingFang_SC] [font-weight:600] not-italic">
        调整排序
      </view>

      <view class="mb-[28rpx] text-left text-[24rpx] leading-[1.3] text-[#666F83] font-[PingFangSC,_PingFang_SC] not-italic">
        长按拖动按钮，可调整排序
      </view>

      <scroll-view
        v-if="sortPopup.list.length"
        :scroll-y="sortPopup.dragSortDisabled"
        class="mb-[28rpx] max-h-[750rpx] rounded-[24rpx] bg-[#F9FAFB]"
      >
        <view class="px-[28rpx]">
          <DragSort
            :ref="(ref: any) => sortPopup.dragSortRef = ref"
            v-model:list="sortPopup.list"
            id-key="id"
            :disabled="sortPopup.dragSortDisabled"
            @touch-end="sortPopup.onTouchEnd"
            @touch-move="sortPopup.onTouchMove"
          >
            <template #default="{ item, index }">
              <view
                class="flex items-center justify-between border-b-[2rpx] border-[#E2E4EA] py-[28rpx]"
                @touchstart="sortPopup.onTap"
              >
                <view class="flex items-center gap-[28rpx]">
                  <view class="text-left text-[30rpx] leading-[1.3] text-[#13113E] font-[PingFangSC,_PingFang_SC] not-italic">
                    {{ item.label }}
                  </view>
                </view>

                <view @longpress.stop="(e: any) => sortPopup.onLongPress(e, index)">
                  <uv-icon name="arrow-up-fill" :size="`${28}rpx`" color="#4E526D" />
                  <uv-icon name="arrow-down-fill" :size="`${28}rpx`" color="#4E526D" />
                </view>
              </view>
            </template>
          </DragSort>
        </view>
      </scroll-view>

      <view v-else class="mb-[28rpx] flex items-center justify-center">
        <uv-empty mode="list" text="暂无数据" />
      </view>

      <view class="flex items-center justify-between">
        <view class="flex-1 shrink-0">
          <uv-button
            shape="circle"
            :hairline="false"
            :custom-style="{
              height: '98rpx',
              width: '100%',
              fontFamily: 'PingFangSC, PingFang SC',
              fontWeight: 400,
              fontSize: '30rpx',
              color: '#fff',
              lineHeight: '42rpx',
              textAlign: 'center',
              fontStyle: 'normal',
              border: 'none',
              background: 'linear-gradient(45deg, #87D35C 0%, #0CBE55 100%)',
            }"
            @click="sortPopup.onSortPopupConfirm"
          >
            确认
          </uv-button>
        </view>
      </view>
    </view>
  </uv-popup>
</template>

<script setup lang="ts">
import DragSort from './drag-sort.vue'
import { nextTick, reactive } from 'vue'

type AnyFunction = (...args: any[]) => any

const emit = defineEmits<{
  (e: 'sortConfirm', list: ListItemType[]): void
}>()

export interface ListItemType {
  label: string
  value: string
}

export interface SortPopupType {
  isShow: boolean
  ref: any
  list: ListItemType[]
  dragSortRef: any
  dragSortDisabled: boolean
  onTap: AnyFunction
  onLongPress: (event: any, index: number) => void
  onTouchEnd: (event: any) => void
  onTouchMove: (event: any) => void
  onSortPopupChange: AnyFunction
  toSortPopupShow: (list: ListItemType[]) => void
  toSortPopupClose: AnyFunction
  onSortPopupConfirm: AnyFunction
}

const sortPopup = reactive<SortPopupType>({
  isShow: false,
  ref: null,
  list: [],
  dragSortRef: null,
  // 默认锁定拖拽，长按手柄后才解锁
  dragSortDisabled: true,
  onLongPress: (event: any, index: number) => {
    sortPopup.dragSortDisabled = false
    nextTick(() => {
      sortPopup.dragSortRef?.onTouchStart(event, index)
    })
  },
  onTap: () => {
    sortPopup.dragSortDisabled = true
  },
  onTouchEnd: () => {
    sortPopup.dragSortDisabled = true
  },
  onTouchMove: () => {
    sortPopup.dragSortDisabled = false
  },
  onSortPopupChange: (e: { show: boolean }) => {
    sortPopup.isShow = e.show
  },
  toSortPopupShow: (list: ListItemType[]) => {
    sortPopup.list = list.map(item => ({ ...item }))
    sortPopup.ref?.open()
  },
  toSortPopupClose: () => {
    sortPopup.ref?.close()
  },
  onSortPopupConfirm: () => {
    emit('sortConfirm', sortPopup.list)
    sortPopup.toSortPopupClose()
  },
})

defineExpose({ sortPopup })
</script>
```

## 三、使用方式

父页面通过 `ref` 拿到 `SortPopup` 暴露的 `sortPopup`，调用 `toSortPopupShow(list)` 打开并传入待排序数据，监听 `sortConfirm` 接收排序结果；同时在 `page-meta` 中根据 `isShow` 控制页面滚动锁定。

```vue
<template>
  <page-meta :page-style="sortPopupRef?.sortPopup?.isShow ? 'overflow: hidden;' : ''" />
  <view>
    <custom-list-example @sort-btn-click="onSortBtnClick" />

    <SortPopup ref="sortPopupRef" @sortConfirm="onSortPopupConfirm" />
  </view>
</template>

<script setup lang="ts">
import SortPopup from '@/components/sort-popup/index.vue'
import { ref } from 'vue'

const sortPopupRef = ref<InstanceType<typeof SortPopup>>()

const onSortBtnClick = () => {
  sortPopupRef.value?.sortPopup.toSortPopupShow(
    Array.from({ length: 10 }, (_, i) => ({
      label: `item-${i}`,
      value: `item-${i}`,
    })),
  )
}

const onSortPopupConfirm = (list: any[]) => {
  // 拿到排序后的 list，在此提交后端或更新本地状态
  console.log('sorted list:', list)
}
</script>
```

## 其他

- **`DragSort` 默认 `disabled: true`**：组件自身默认锁定拖拽，必须外部把 `:disabled` 置否才会响应手势。在 `SortPopup` 中由长按手柄触发解锁；若单独使用 `DragSort`，记得传 `:disabled="false"`。
- **`id-key` 必须唯一**：`v-for` 的 `:key` 依赖 `item[idKey]`，请确保传入的字段在列表内唯一，否则重排会出现错位。
- **布局测量时机**：通过 `setTimeout(…, 50)` 延迟测量 `.draggable-item` 的 `boundingClientRect`，若列表在 `onMounted` 时尚未渲染完成（如数据异步到达），`itemsLayout` 为空会在 `touchstart` 时补测一次。
- **弹窗内滚动冲突**：`scroll-view` 的 `:scroll-y` 与 `DragSort` 的 `:disabled` 绑定同一状态 `dragSortDisabled`——拖拽中禁止滚动，松手后恢复，避免手势互相劫持。
- **拖拽锁定滚动**， 当前实现的是在拖拽过程中禁止滚动，松手后恢复。这个为了考虑到使用者可能是**页面级滚动**或者**scroll-view滚动**，两者自动滚动的逻辑完全不同，所以这里做了统一处理，如果需要实现拖到底部自动滚动，需自行实现，在touchMove回调中判断当前 `event` 位置，然后做**页面级滚动**或者**scroll-view滚动**
