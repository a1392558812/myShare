# 链式vue3函数式dialog调用

> 该项目是 `01.杂项整理/44.Vue3封装全局自定义组件（通过js调用，也可以组件调用）.md` 的进阶版，用于在类似于批刀刀那种点完一个弹窗套下一个弹窗的场景，基本上用不到，我也是水文章
> 关于自定义打开关闭动画，这里我没有写，你可以根据须要自定义。

## 动画与链式调用的时序控制

### 顺序

```text
open A ──► ifShow=true ──► enter 动画 ──► 稳定
                                             │
              ┌──────────────────────────────┘
              ▼
        用户点乐「确定」
              │
    confirm(next) 用户回调
              │  举栗：await api.submit()
              ▼
          next()  →  settle('confirm')  →  ifShow=false
                                             │
                                        leave 动画 0.2s
                                             │
                                        @after-leave
                                             │
                                        emit('closed')
                                             │
                    handleClosed: unmount + remove + 出栈 + resolve
                                             │
                                             ▼
                              .then(res) ──► showDialog(B)（链式下一步）
```

### settle 与 resolve 分离

实现里有两个状态，很容易混淆：

| 状态                 | 时坤                         | 作用                                                       |
| -------------------- | ---------------------------- | ---------------------------------------------------------- |
| settle(result)       | 用户点按钮时立即执行         | 只记录结果（confirm / cancel），标记 settled = true 防重复 |
| resolveOuter(result) | @after-leave → closed 时执行 | 真正把 Promise 兑现给调用方                                |

### 关闭链路

- 用户点关闭/确定：done 里要先 settle 记录意图，再 innerClose() 触发动画；
- 被强制关闭（连带关闭 / forceClose）：没有用户动作，直接 settle + forceClose 触发动画。

两条路都只 settle，最终都由同一个 handleClosed（在 @after-leave 里）去 resolveOuter。所以`promise.close("confirm")`之后 `.then` 不会立刻触发，而要等约200ms动画结束,

```ts
const settle = (result) => {
  if (settled) return; // 幂等：重复关闭只认第一次
  settled = true;
  dialogResult = result;
};

const handleClosed = () => {
  // @after-leave 之后才走这里
  app.unmount();
  root.remove();
  resolveOuter(dialogResult); // 真正的 resolve
};
```

### 先入栈，再mount

// 如果顺序返过来，组件首次渲染时dialogStack里还没有自己，isTop会算成 false、zIndex会拿到默认，遮罩会先闪一下0.2透明度，再跳回0.5,先入栈就是为了保证首帧就是正确的层级。

```ts
dialogStack.value.push(dialogId); // 先入栈
activeDialogs.set(dialogId, handle);
app.mount(root); // 再挂载
```

## 全局实例与上下文注入

### 函数式挂载脱离组件树

`createApp().mount()`创建的是一个独立的Vue 应用，和调用方不在同一棵组件树上，不能靠 `<Dialog>`的props 链传值,contentSlot 里渲染的组件想yao“关闭自己”，没有emit可派发（它不是某个父组件的子节点）,解决办法是 `app.provide(DIALOG_CONTEXT_KEY, { dialogId, close, confirm })`，contentSlot内部组件只需按以下方法就能拿到关闭能力

```ts
const ctx = useDialogContext(); // 内部 inject(DIALOG_CONTEXT_KEY)
ctx?.close();
```

### 栈管理

```ts
const dialogStack = ref<string[]>([]);
app.provide(DIALOG_STACK_KEY, dialogStack);

// 组件内：

const isTop = computed(() => stack.value.at(-1) === props.dialogId);
const zIndex = computed(() => 1000 + stack.value.indexOf(props.dialogId) * 10);
```

任一弹窗关闭出栈后，所有存活弹窗的isTop与zIndex自动重算，遮罩透明度、层叠顺序实时正确，无需手动维护。

### 关闭语义

| 关闭方式                                | 走哪个通道                    | 是否触发 confirm/close 用户回调 | 结果             |
| --------------------------------------- | ----------------------------- | ------------------------------- | ---------------- |
| 用户点按钮 / promise.close()            | dialogClose / dialogConfirm   | 触发                            | confirm / cancel |
| 被父连带关闭 / closeDialogsAbove(force) | forceClose（仅 ifShow=false） | 不触发                          | cancel           |

强制关闭不能走用户回调，假设一张场景，子弹窗的 `confirm`里是“提交订单接口”,父弹窗关闭时如果子被顺带触发confirm，那么此时就是误提交了，所以`forceClose`只做一件事`ifShow = false`，让动画跑完、unmount、Promise以cancel事件兑现，绕开一切业务逻辑

### 竞态与幂等

用户手速快、或动画播放中又点了关闭，会出现重复关闭。防止办法：

- settled标记：settle只认第一次，后续forceClose直接return；
- dialogVm判空：promise.close时若VM还没挂载或已卸载，直接忽略。
- 保证一个弹窗的Promise只resolve一次，链式调用不会错乱。

## 注意

### 拖拽/归位

如果传的初始位置本身就超出视口（如 right: '-100px'，弹窗右边缘本来就在屏幕外 100px），第一次拖拽时会被 clamp 弹回视口内,这是`拖拽/归位`的预期行为，如果确实需要保持越界位置，须用 dragOutOfBounds: true。

### 循环依赖

把keys.ts单独抽出来，避免循环依赖，Vue 的`InjectionKey` 需要在 index.ts（provide 侧）和 index.vue（inject 侧）共享。如果 `DIALOG_STACK_KEY`与`DIALOG_CONTEXT_KEY` 定义在 index.ts 里，index.vue 就必须`import { DIALOG_STACK_KEY } from "./index"`,那么这样形成双向循环依赖：

```text
# 三个文件的导入关系：

index.ts ──import──► index.vue
    ▲                     │
    └───import───────────┘   ← 如果 index.vue 要从 index.ts 拿 KEY，就成环
```

ESM的执行顺序是“先跑完依赖，再跑自己”,index.ts第一行就是`import DialogComponent from "./index.vue"`,此时：
`开始执行index.ts`
转到-→ `遇到import DialogComponent,转去执行index.vue`
转到-→ `index.vue里import { DIALOG_STACK_KEY } from "./index"`
转到-→ `index.ts还没执行到export const DIALOG_STACK_KEY那一行，index.vue拿到的是 undefined`
转到-→ `index.vue里inject(undefined):Vue警告或静默返回null`
转到-→ `继续执行完index.vue,回到index.ts,才执行到export`

表现为： `inject(DIALOG_STACK_KEY)拿不到` 导致-→ `stack = null` 导致-→ `isTop恒true` / `zIndex恒1000` 且报错或兜底默认值，“多层堆叠/遮罩变淡/栈顶判断”全部静默失效

## 完整代码

### `@/components/dialog/index.vue`

```html
<template>
  <Transition name="dialog" appear @after-leave="onAfterLeave">
    <div
      v-if="ifShow"
      class="dialog-wrap"
      :style="wrapStyle"
      @click.self="dialogOutClose"
    >
      <div
        ref="dialogRef"
        class="dialog"
        :class="{
        'is-draggable': draggable,
        'is-dragging': isDragging,
        'is-drag-hover': dragHoverEnabled,
      }"
        :style="dialogStyle"
        @click.stop
        @pointerdown="onDragStart"
        @pointerover="onPointerOver"
        @pointerleave="onPointerLeave"
      >
        <div v-if="showHeader" class="header" :style="customDialogHeaderStyle">
          {{ title }}
        </div>

        <div class="content" :style="customDialogContentStyle">
          <slot name="content" :close="dialogClose" :confirm="dialogConfirm">
            <div
              class="content-default"
              :style="customDialogContentDefaultStyle"
            >
              {{ content }}
            </div>
          </slot>
        </div>

        <div v-if="showFooter" class="footer" :style="customDialogFooterStyle">
          <button
            class="btn"
            :style="customDialogFooterBtnStyle"
            @click="dialogClose"
          >
            关闭
          </button>
          <button
            class="btn btn-primary"
            :style="customDialogFooterBtnPrimaryStyle"
            @click="dialogConfirm"
          >
            确定
          </button>
        </div>
      </div>
    </div>
  </Transition>
</template>

<script setup lang="ts">
  import {
    computed,
    inject,
    onBeforeUnmount,
    onMounted,
    ref,
    watch,
    type CSSProperties,
  } from "vue";
  import { DIALOG_STACK_KEY } from "./keys";

  defineOptions({ name: "Custom-dialog" });

  export interface DialogProps {
    /** 当前弹窗唯一 id，由 showDialog 自动传入；组件方式调用可不传 */
    dialogId?: string;

    showHeader?: boolean;
    showFooter?: boolean;
    dialogABool?: boolean;
    maskClose?: boolean;
    title?: string;
    content?: string;
    /** 确定回调，必须调用 close 才会关闭并 resolve('confirm') */
    confirm?: (close: () => void) => void;
    /** 关闭回调，必须调用 close 才会关闭并 resolve('cancel') */
    close?: (close: () => void) => void;

    /** 是否可拖拽 */
    draggable?: boolean;
    /** 是否允许拖拽越出视口。false（默认）时视口即边界 */
    dragOutOfBounds?: boolean;
    /** 拖拽手柄选择器；不传则整个 dialog 可拖 */
    dragHandle?: string;
    /**
     * 拖拽排除选择器；不传（空串）则所有元素都可拖。
     * 例："button, input, textarea, a"
     */
    dragExcludeSelector?: string;

    customDialogWrapStyle?: CSSProperties;
    customDialogStyle?: CSSProperties;
    customDialogHeaderStyle?: CSSProperties;
    customDialogContentStyle?: CSSProperties;
    customDialogContentDefaultStyle?: CSSProperties;
    customDialogFooterStyle?: CSSProperties;
    customDialogFooterBtnStyle?: CSSProperties;
    customDialogFooterBtnPrimaryStyle?: CSSProperties;
  }

  const props = withDefaults(defineProps<DialogProps>(), {
    dialogId: "",
    showHeader: true,
    showFooter: true,
    dialogABool: false,
    maskClose: true,
    title: "这是一个标题",
    content: "这是一个内容",
    draggable: false,
    dragOutOfBounds: false,
    dragHandle: "",
    dragExcludeSelector: "",
    customDialogWrapStyle: () => ({}),
    customDialogStyle: () => ({}),
    customDialogHeaderStyle: () => ({}),
    customDialogContentStyle: () => ({}),
    customDialogContentDefaultStyle: () => ({}),
    customDialogFooterStyle: () => ({}),
    customDialogFooterBtnStyle: () => ({}),
    customDialogFooterBtnPrimaryStyle: () => ({}),
  });

  const emit = defineEmits<{
    (e: "closed"): void;
    (e: "update:dialogABool", v: boolean): void;
  }>();

  const ifShow = ref(props.dialogABool);

  // 组件方式：父改 props → 同步内部
  watch(
    () => props.dialogABool,
    (v) => {
      ifShow.value = v;
    },
  );

  /* ---------- 堆叠感知 ---------- */
  const stack = inject(DIALOG_STACK_KEY, null);

  const isTop = computed(() => {
    // 组件方式调用（无 dialogId）视为独立顶层
    if (!stack || !props.dialogId) return true;
    return (
      stack.value.length === 0 ||
      stack.value[stack.value.length - 1] === props.dialogId
    );
  });

  const zIndex = computed(() => {
    if (!stack || !props.dialogId) return 1000;
    return 1000 + Math.max(stack.value.indexOf(props.dialogId), 0) * 10;
  });

  const wrapStyle = computed<CSSProperties>(() => {
    const baseStyle: CSSProperties = { zIndex: zIndex.value };
    if (!isTop.value) baseStyle.backgroundColor = "rgba(0, 0, 0, 0.2)";
    return Object.assign(baseStyle, props.customDialogWrapStyle);
  });

  /* ---------- 拖拽 ---------- */
  const dialogRef = ref<HTMLElement | null>(null);
  const offsetX = ref(0);
  const offsetY = ref(0);
  const isDragging = ref(false);
  /** 当前鼠标位置是否在可拖区域（驱动 cursor） */
  const dragHoverEnabled = ref(false);

  /** 拖拽开始时的基准 rect（offset=0 时元素在视口里的真实坐标） */
  let baseRect: {
    left: number;
    top: number;
    right: number;
    bottom: number;
  } | null = null;

  let startX = 0;
  let startY = 0;
  let startOffsetX = 0;
  let startOffsetY = 0;

  /**
   * 规范化长度值：
   * - number / 纯数字字符串 → 补 px（解决 '0'、0、'100' 的问题）
   * - 带单位字符串（'0px'、'50%'、'2em'）→ 原样返回
   * - 'auto' / 空 / undefined → null（视为未传）
   */
  const normalizeLength = (v: unknown): string | null => {
    if (v === undefined || v === null) return null;
    if (typeof v === "number") return `${v}px`;
    const str = String(v).trim();
    if (
      str === "" ||
      str === "auto" ||
      str === "initial" ||
      str === "inherit" ||
      str === "unset"
    ) {
      return null;
    }
    if (/^-?\d+(\.\d+)?$/.test(str)) return `${str}px`;
    return str;
  };

  /**
   * 位置/尺寸样式：
   * - 水平轴：left 优先于 right；都没传则居中
   * - 垂直轴：top 优先于 bottom；都没传则居中
   * - transform：用户传了就完全尊重，否则按轴自动加 translate(-50% | 0)
   * - 拖拽位移通过 offsetX/offsetY 叠加到 left/top/right/bottom 的 calc 中
   */
  const dialogStyle = computed<CSSProperties>(() => {
    const user = (props.customDialogStyle || {}) as Record<string, any>;
    const style: CSSProperties = { ...user };

    const userLeft = normalizeLength(user.left);
    const userRight = normalizeLength(user.right);
    const userTop = normalizeLength(user.top);
    const userBottom = normalizeLength(user.bottom);
    const userTransform = user.transform;

    const dx = offsetX.value;
    const dy = offsetY.value;

    /* ---------- 水平轴 ---------- */
    let tx: string;
    if (userLeft) {
      style.left = `calc(${userLeft} + ${dx}px)`;
      delete (style as any).right;
      tx = "0";
    } else if (userRight) {
      (style as any).right = `calc(${userRight} - ${dx}px)`;
      delete (style as any).left;
      tx = "0";
    } else {
      style.left = `calc(50% + ${dx}px)`;
      delete (style as any).right;
      tx = "-50%";
    }

    /* ---------- 垂直轴 ---------- */
    let ty: string;
    if (userTop) {
      style.top = `calc(${userTop} + ${dy}px)`;
      delete (style as any).bottom;
      ty = "0";
    } else if (userBottom) {
      (style as any).bottom = `calc(${userBottom} - ${dy}px)`;
      delete (style as any).top;
      ty = "0";
    } else {
      style.top = `calc(50% + ${dy}px)`;
      delete (style as any).bottom;
      ty = "-50%";
    }

    /* ---------- transform：用户传了就完全尊重 ---------- */
    if (userTransform === undefined) {
      style.transform = `translate(${tx}, ${ty})`;
    }

    return style;
  });

  /**
   * 判定某个元素是否可以作为拖拽起点。
   * 拖拽触发、hover cursor 共用，保证视觉与行为一致。
   * 优先级：dragHandle > dragExcludeSelector > 全能拖
   */
  const canStartDragOn = (target: HTMLElement | null): boolean => {
    if (!target) return false;
    if (props.dragHandle) return !!target.closest(props.dragHandle);
    if (props.dragExcludeSelector)
      return !target.closest(props.dragExcludeSelector);
    return true;
  };

  /** 基于baseRect收敛offset，对 left/right/top/bottom/居中/transform 通用 */
  const clampOffset = () => {
    if (props.dragOutOfBounds || !baseRect) return;
    const vw = window.innerWidth;
    const vh = window.innerHeight;

    const newLeft = baseRect.left + offsetX.value;
    const newRight = baseRect.right + offsetX.value;
    if (newLeft < 0) {
      offsetX.value = -baseRect.left;
    } else if (newRight > vw) {
      offsetX.value = vw - baseRect.right;
    }

    const newTop = baseRect.top + offsetY.value;
    const newBottom = baseRect.bottom + offsetY.value;
    if (newTop < 0) {
      offsetY.value = -baseRect.top;
    } else if (newBottom > vh) {
      offsetY.value = vh - baseRect.bottom;
    }
  };

  const onDragMove = (e: PointerEvent) => {
    if (!isDragging.value) return;

    offsetX.value = startOffsetX + (e.clientX - startX);
    offsetY.value = startOffsetY + (e.clientY - startY);

    const beforeX = offsetX.value;
    const beforeY = offsetY.value;
    clampOffset();

    // 被 clamp 修正后重置起点，避免拖到边界后反向拖有滞后感
    if (offsetX.value !== beforeX) {
      startOffsetX = offsetX.value;
      startX = e.clientX;
    }
    if (offsetY.value !== beforeY) {
      startOffsetY = offsetY.value;
      startY = e.clientY;
    }
  };

  const onDragEnd = (e: PointerEvent) => {
    if (!isDragging.value) return;
    isDragging.value = false;
    baseRect = null;
    document.body.style.userSelect = "";
    window.removeEventListener("pointermove", onDragMove);
    window.removeEventListener("pointerup", onDragEnd);

    // 松手后用 elementFromPoint 重算 hover 状态，避免光标停在 grabbing
    if (props.draggable) {
      const el = document.elementFromPoint(
        e.clientX,
        e.clientY,
      ) as HTMLElement | null;
      dragHoverEnabled.value = canStartDragOn(el);
    }
  };

  const onDragStart = (e: PointerEvent) => {
    if (!props.draggable || isDragging.value) return;
    if (!canStartDragOn(e.target as HTMLElement)) return;

    const el = dialogRef.value;
    if (el) {
      const rect = el.getBoundingClientRect();
      // 反推 offset=0 时的真实视口位置
      baseRect = {
        left: rect.left - offsetX.value,
        top: rect.top - offsetY.value,
        right: rect.right - offsetX.value,
        bottom: rect.bottom - offsetY.value,
      };
    }

    isDragging.value = true;
    dragHoverEnabled.value = false;
    startX = e.clientX;
    startY = e.clientY;
    startOffsetX = offsetX.value;
    startOffsetY = offsetY.value;
    document.body.style.userSelect = "none";
    window.addEventListener("pointermove", onDragMove);
    window.addEventListener("pointerup", onDragEnd);
  };

  /** 动态 cursor：跟着真实可拖区域走 */
  const onPointerOver = (e: PointerEvent) => {
    if (!props.draggable || isDragging.value) return;
    dragHoverEnabled.value = canStartDragOn(e.target as HTMLElement);
  };

  const onPointerLeave = () => {
    dragHoverEnabled.value = false;
  };

  const onWindowResize = () => {
    if (!props.draggable) return;
    const el = dialogRef.value;
    if (!el) return;
    // 视口变了，基准位置也可能变（right/bottom/百分比定位），清空缓存，下次拖拽重取
    baseRect = null;

    // 视口缩小时把元素拉回可见区
    const rect = el.getBoundingClientRect();
    const vw = window.innerWidth;
    const vh = window.innerHeight;
    let fixX = 0;
    let fixY = 0;
    if (rect.left < 0) fixX = -rect.left;
    else if (rect.right > vw) fixX = vw - rect.right;
    if (rect.top < 0) fixY = -rect.top;
    else if (rect.bottom > vh) fixY = vh - rect.bottom;
    if (fixX !== 0) offsetX.value += fixX;
    if (fixY !== 0) offsetY.value += fixY;
  };

  onMounted(() => window.addEventListener("resize", onWindowResize));

  onBeforeUnmount(() => {
    window.removeEventListener("resize", onWindowResize);
    if (isDragging.value) {
      window.removeEventListener("pointermove", onDragMove);
      window.removeEventListener("pointerup", onDragEnd);
    }
  });

  /* ---------- 关闭逻辑 ---------- */
  const closeCallback = () => {
    ifShow.value = false;
    emit("update:dialogABool", false);
  };

  const dialogConfirm = () => {
    if (props.confirm) {
      return props.confirm(closeCallback);
    }
    return closeCallback();
  };

  const dialogClose = () => {
    if (props.close) {
      return props.close(closeCallback);
    }
    return closeCallback();
  };

  const dialogOutClose = () => {
    if (props.maskClose) {
      return dialogClose();
    }
  };

  const onAfterLeave = () => emit("closed");

  /** 强制关闭：绕过用户 confirm/close 回调 */
  const forceClose = () => {
    ifShow.value = false;
    emit("update:dialogABool", false);
  };

  // 暴露给函数式调度调用
  defineExpose({ dialogClose, dialogConfirm, forceClose });
</script>
```

```typescript
  type CSSProperties,

import DialogComponent from "./index.vue";
import { DIALOG_STACK_KEY } from "./keys";

export type DialogResult = "confirm" | "cancel";
export type DialogCloseFn = () => void;

export interface DialogSlotContext {
  /** 取消/关闭当前弹窗 */
  close: DialogCloseFn;
  confirm: DialogCloseFn;
  /** 当前弹窗唯一 id，配合 closeDialog(dialogId) 使用 */
  dialogId: string;
  /** 关闭指定弹窗（不传则关栈顶），方便子弹窗里控制父级 */
  closeDialog: (id?: string, result?: DialogResult) => void;
}

export interface DialogOptions {
  showHeader?: boolean;
  showFooter?: boolean;
  dialogABool?: boolean;
  maskClose?: boolean;
  title?: string;
  content?: string;
  confirm?: (close: DialogCloseFn) => void;
  close?: (close: DialogCloseFn) => void;
  contentSlot?: (ctx: DialogSlotContext) => VNode;
  customDialogWrapStyle?: CSSProperties;
  customDialogStyle?: CSSProperties;
  customDialogHeaderStyle?: CSSProperties;
  customDialogContentStyle?: CSSProperties;
  customDialogContentDefaultStyle?: CSSProperties;
  customDialogFooterStyle?: CSSProperties;
  customDialogFooterBtnStyle?: CSSProperties;
  customDialogFooterBtnPrimaryStyle?: CSSProperties;
  /**
   * 关闭当前弹窗时，是否连带强制关闭其后打开的所有子弹窗。
   * 默认 false：各弹窗独立生命周期
   * （可在关闭回调里自行调用 closeDialogsAbove / closeDialog）。
   * 设为 true 时，走 forceClose 通道（不触发子弹窗的用户回调）。

  draggable?: boolean;

  dragOutOfBounds?: boolean;
  /** 拖拽手柄选择器；不传则整个 dialog 可拖 */
  dragHandle?: string;
  /**
   * 拖拽排除选择器；不传（空串）则所有元素都可拖。
   * 例："button, input, textarea, a"
   */
  dragExcludeSelector?: string;
}

export type DialogPromise = Promise<DialogResult> & {
  dialogId: string;
  close: (result?: DialogResult) => void;
};

/* ---------- 全局响应式栈 ---------- */

const dialogStack = ref<string[]>([]);

interface DialogHandle {
  dialogId: string;
  close: (result?: DialogResult) => void;
  confirm: () => void;
  /** 强制关闭（绕过用户回调），供连带关闭使用 */
  forceClose: (result?: DialogResult) => void;
}

const activeDialogs = new Map<string, DialogHandle>();
let uid = 0;

/* ---------- 关闭辅助 ---------- */

/** 走用户逻辑关闭某一个（会触发它的 confirm / close 回调） */
const closeOne = (dialogId: string, result: DialogResult = "cancel") => {
  const handle = activeDialogs.get(dialogId);
  if (!handle) {
    return;
  }
  if (result === "confirm") {
    handle.confirm();
  } else {
    handle.close();
  }
};

/** 强制关闭 parentId 之后打开的所有弹窗，不走用户回调 */
const forceCloseChildren = (parentId: string) => {
  const ids = dialogStack.value;
  const idx = ids.indexOf(parentId);
  if (idx < 0) {
    return;
  }
  for (let i = ids.length - 1; i > idx; i--) {
    activeDialogs.get(ids[i])?.forceClose("cancel");
  }
};

/* ---------- 对外 API ---------- */

/** 通过 dialogId 关闭；不传则关闭栈顶（最后打开/最上层） */
export const closeDialog = (
  dialogId?: string,
  result: DialogResult = "cancel",
) => {
  if (dialogId) {
    closeOne(dialogId, result);
    return;
  }
  const ids = dialogStack.value;
  const lastId = ids[ids.length - 1];
  if (lastId) {
    closeOne(lastId, result);
  }
};

/** 关闭栈顶（语义别名，与 closeDialog() 等价） */
export const closeCurrentDialog = (result: DialogResult = "cancel") =>
  closeDialog(undefined, result);

/** 关闭全部（反向逐个关，各自走自己的 confirm/close 回调） */
export const closeAllDialogs = (result: DialogResult = "cancel") => {
  const ids = [...dialogStack.value];
  for (let i = ids.length - 1; i >= 0; i--) {
    closeOne(ids[i], result);
  }
};

/**
 * 关闭 parentId 之上（之后打开）的所有弹窗，控制权交给用户主动调用。
 * - force: true  绕过子弹窗的用户回调，直接关
 * - force: false 走子弹窗自己的 confirm/close 回调（默认）
 */
export const closeDialogsAbove = (
  parentId: string,
  result: DialogResult = "cancel",
  { force = false }: { force?: boolean } = {},
) => {
  const ids = [...dialogStack.value];
  const idx = ids.indexOf(parentId);
  if (idx < 0) {
    return;
  }

  for (let i = ids.length - 1; i > idx; i--) {
    const h = activeDialogs.get(ids[i]);
    if (!h) continue;
    if (force) {
      h.forceClose(result);
    } else {
      closeOne(ids[i], result);
    }
  }
};

/* ---------- provide / inject ---------- */

export interface DialogInjection {
  dialogId: string;
  /** 取消/关闭当前弹窗 */
  close: DialogCloseFn;
  confirm: DialogCloseFn;
}

export const DIALOG_CONTEXT_KEY: InjectionKey<DialogInjection> =
  Symbol("dialog-context");

/** contentSlot 内的组件在 setup 中调用，返回关闭能力 */
export const useDialogContext = () => inject(DIALOG_CONTEXT_KEY, null);

/* ---------- 核心 ---------- */

export const showDialog = (options: DialogOptions = {}): DialogPromise => {
  const {
    contentSlot,
    confirm,
    close,
    closeChildrenOnClose = false,
    ...rest
  } = options;

  const dialogId = `dialog_${++uid}`;
  const root = document.createElement("div");
  document.body.appendChild(root);

  let app!: App<Element>;
  let dialogVm: {
    dialogClose: DialogCloseFn;
    dialogConfirm: DialogCloseFn;
    forceClose: DialogCloseFn;
  } | null = null;

  let dialogResult: DialogResult = "cancel";
  let settled = false;
  let resolveOuter!: (r: DialogResult) => void;

  const settle = (result: DialogResult) => {
    if (settled) return;
    settled = true;
    dialogResult = result;
  };

  const handleClosed = () => {
    app.unmount();
    root.remove();
    activeDialogs.delete(dialogId);
    const i = dialogStack.value.indexOf(dialogId);
    if (i >= 0) dialogStack.value.splice(i, 1);
    resolveOuter(dialogResult);
  };

  /**
   * 包装用户的 confirm/close：
   * done 里先（可选）强制关子、再 settle、再真正关闭自己。
   * 时序：settle 只记结果，resolve 仍等 @after-leave → closed → handleClosed。
   */
  const wrapClose = (
    result: DialogResult,
    userFn?: (next: DialogCloseFn) => void,
  ) => {
    return (innerClose: DialogCloseFn) => {
      const done = () => {
        if (closeChildrenOnClose) {
          forceCloseChildren(dialogId);
        }
        settle(result);
        innerClose();
      };
      if (userFn) {
        userFn(done);
      } else {
        done();
      }
    };
  };

  const props = {
    dialogId,
    dialogABool: true,
    ...rest,
    confirm: wrapClose("confirm", confirm),
    close: wrapClose("cancel", close),
    onClosed: handleClosed,
  };

  // 传给 contentSlot 的上下文
  const slotCtx: DialogSlotContext = {
    dialogId,
    close: () => dialogVm?.dialogClose(),
    confirm: () => dialogVm?.dialogConfirm(),
    closeDialog,
  };

  const slots = contentSlot
    ? { content: () => contentSlot(slotCtx) }
    : undefined;

  const promise = new Promise<DialogResult>((resolve) => {
    resolveOuter = resolve;
  }) as DialogPromise;

  promise.dialogId = dialogId;
  promise.close = (result: DialogResult = "cancel") => {
    if (!dialogVm) return;
    if (result === "confirm") {
      dialogVm.dialogConfirm();
    } else {
      dialogVm.dialogClose();
    }
  };

  /** 强制关闭（绕过用户回调），供 closeDialogsAbove(force) / 连带关闭使用 */
  const forceClose = (result: DialogResult = "cancel") => {
    if (settled) return;
    settle(result);
    dialogVm?.forceClose?.();
  };

  app = createApp({
    render: () =>
      h(
        DialogComponent as never,
        {
          ...props,
          ref: (el: unknown) => {
            dialogVm = el as typeof dialogVm;
          },
        } as never,
        slots,
      ),
  });

  app.provide(DIALOG_CONTEXT_KEY, {
    dialogId,
    close: promise.close,
    confirm: () => {
      promise.close("confirm");
    },
  });

  app.provide(DIALOG_STACK_KEY, dialogStack);

  // 先入栈 + 注册句柄，再 mount，保证首帧 zIndex/isTop正确
  dialogStack.value.push(dialogId);
  activeDialogs.set(dialogId, {
    dialogId,
    close: promise.close,
    confirm: () => {
      promise.close("confirm");
    },
    forceClose,
  });

  app.mount(root);

  return promise;
};

export default showDialog;
```
