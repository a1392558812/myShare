# 轮廓式悬浮标签输入框

// 注意：这个标签不是原生 `placeholder`，原生 placeholder无法做到切断边框的效果，它是独立的 `<label>` 元素。

```html
<template>
  <div :style="[{ position: 'relative', width: '360px' }, customStyle]">
    <slot name="suffix" />
    <input
      :style="[baseInputStyle, customInputStyle]"
      v-model="computedValue"
      :disabled="disabled"
      type="text"
      placeholder=""
      @focus="onFocus"
      @blur="onBlur"
      @input="onInput"
    />
    <label :style="computedLabelStyle">{{ placeholder }}</label>
    <slot name="prefix" />
  </div>
</template>

<script setup>
  import { ref, computed } from "vue";

  const emit = defineEmits(["update:modelValue", "focus", "blur", "input"]);

  const props = defineProps({
    placeholder: {
      type: String,
      default: "请输入",
    },
    disabled: {
      type: Boolean,
      default: false,
    },
    customStyle: {
      type: Object,
      default: () => ({}),
    },
    customInputStyle: {
      type: Object,
      default: () => ({}),
    },
    customInputPlaceholderStyle: {
      type: Object,
      default: () => ({}),
    },
    customInputOnFocusPlaceholderStyle: {
      type: Object,
      default: () => ({}),
    },
    customInputOnBlurPlaceholderStyle: {
      type: Object,
      default: () => ({}),
    },
    modelValue: {
      type: String,
      default: "",
    },
  });

  const baseInputStyle = {
    width: "100%",
    boxSizing: "border-box",
    padding: "14px 16px",
    border: "2px solid #4096ff",
    borderRadius: "12px",
    fontSize: "16px",
    background: "transparent",
    outline: "none",
  };

  const isFocus = ref(false);

  const computedValue = computed({
    get: () => props.modelValue,
    set: (val) => emit("update:modelValue", val),
  });

  const computedLabelStyle = computed(() => {
    const defaultStyle = Object.assign(
      {},
      {
        position: "absolute",
        left: "14px",
        top: "50%",
        transform: "translateY(-50%)",
        fontSize: "16px",
        color: "#4096ff",
        background: "#ffffff",
        padding: "0 4px",
        transition: "all 0.2s ease",
        pointerEvents: "none",
      },
      props.customInputPlaceholderStyle,
    );

    if (isFocus.value || computedValue.value) {
      return Object.assign(
        {},
        defaultStyle,
        {
          top: "0px",
          fontSize: "13px",
          transform: "translateY(-50%) scale(0.95)",
        },
        props.customInputOnFocusPlaceholderStyle,
      );
    }

    return Object.assign(
      {},
      defaultStyle,
      props.customInputOnBlurPlaceholderStyle,
    );
  });

  const onFocus = (e) => {
    isFocus.value = true;
    emit("focus", e);
  };

  const onBlur = (e) => {
    isFocus.value = false;
    emit("blur", e);
  };

  const onInput = (e) => {
    emit("input", e);
  };
</script>
```

## 组件设计

// 水字数
本组件属是大部分UI库的实现得路线：

- 外层相对定位容器，承载输入框与悬浮标签
- input 负责输入交互，边框是连续完整圆角边框
- label 绝对定位，默认垂直居中在输入框内
- 核心 trick：`label` 设置和页面背景一致的 `background`，上浮之后盖住下方边框，视觉上制造“边框断开缺口”
- 通过 `isFocus` 和 `modelValue` 判断状态，使用计算属性合并样式，控制标签上浮、缩放、变色
- 样式分层：基础样式 + 自定义扩展样式，把默认态、聚焦态、失焦态样式钩子全部暴露给外部

## 已知坑点

> 这是本方案最核心的取舍，必须在业务使用时留意：

### 只适配纯色静态背景

label依靠定义的背景底色盖住边框,如果输入框所在父容器不是纯色（渐变、纹理、图片背景场景无法使用该方案），则遮罩会非常突兀，缺口效果很奇怪

### 圆角对齐细节

当输入框圆角很大的时候，标签上浮后的缺口位置视觉比例需要微调，很难做到和圆角完美贴合（fieldset 原生方案的缺口对齐更自然）

### 其他状态样式

根据各种状态/图标等等乱码七糟的场景，需要业务层自行通过 `props[custom-xxxx-Style]` 覆盖样式即可

## fieldset + legend 原生方案

```html
<fieldset class="wrap">
  <legend class="label">Username</legend>
  <input />
</fieldset>
```
