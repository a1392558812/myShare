# 62.浏览器插件开发

## Manifest V3概念

| 模块                      | 作用                             | 运行环境             |
| ------------------------- | -------------------------------- | -------------------- |
| `manifest.json`           | 插件清单，声明权限、入口、版本等 | 浏览器读取           |
| Background Service Worker | 后台脚本，处理事件、定时任务     | 浏览器后台（无 DOM） |
| Content Scripts           | 内容脚本，注入到页面中运行       | 网页上下文（受限）   |
| Popup                     | 点击插件图标时弹出的 HTML 页面   | 独立页面             |
| Options Page              | 插件设置页面                     | 独立页面             |
| DevTools Page             | 扩展开发者工具面板               | DevTools 上下文      |

### 插件运行上下文

```
┌─────────────────────────────────────────────────┐
│  浏览器进程                                      │
│  ┌───────────────┐  ┌───────────────────────┐  │
│  │ Background SW │  │  Popup / Options Page  │  │
│  │  (后台服务)     │  │  (独立HTML页面)         │  │
│  └───────┬───────┘  └───────────┬───────────┘  │
│          │                      │               │
├──────────┼──────────────────────┼───────────────┤
│          │    网页进程           │               │
│  ┌───────▼──────────────────────▼───────────┐  │
│  │         Content Script (注入页面)         │  │
│  │  可访问 DOM，但无法访问页面的 window 变量  │  │
│  └──────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

- Background / Popup：拥有完整的 Chrome API 权限，可直接调用 `chrome.*`
- Content Script：只能访问有限的 Chrome API（`storage`、`runtime.sendMessage`），需通过消息通信与 Background 交互

## 实现

eg: 实现网页信息提取插件,点击Popup按钮，提取当前页面的标题、URL和正文摘要，并显示在Popup。

### 共享类型定义

`src/shared/types.ts`：

```typescript
/** 消息类型枚举 */
export enum MessageType {
  GetPageInfo = "GET_PAGE_INFO",
  SaveNote = "SAVE_NOTE",
  GetNotes = "GET_NOTES",
}

/** 页面信息数据结构 */
export interface PageInfo {
  title: string;
  url: string;
  description: string;
}

/** 笔记数据结构 */
export interface Note {
  id: string;
  title: string;
  url: string;
  content: string;
  createdAt: number;
}

/** 统一的消息格式 */
export interface Message<T = unknown> {
  type: MessageType;
  payload?: T;
}

/** 消息响应格式 */
export interface MessageResponse<T = unknown> {
  success: boolean;
  data?: T;
  error?: string;
}
```

### Background Service Worker

`src/background/index.ts`：

```typescript
import {
  MessageType,
  type Message,
  type MessageResponse,
  type Note,
} from "../shared/types";

/**
 * Service Worker 生命周期
 * 事件驱动，不保持持久运行，用完即休眠
 */

// 插件安装时触发
chrome.runtime.onInstalled.addListener((details) => {
  if (details.reason === "install") {
    console.log("插件已安装");
    // 初始化默认设置
    chrome.storage.local.set({ theme: "light", maxNotes: 50 });
  }
});

// 监听来自 Popup / Content Script 的消息
chrome.runtime.onMessage.addListener(
  (
    message: Message,
    _sender: chrome.runtime.MessageSender,
    sendResponse: (response: MessageResponse) => void,
  ) => {
    handleMessage(message)
      .then((data) => sendResponse({ success: true, data }))
      .catch((err: Error) =>
        sendResponse({ success: false, error: err.message }),
      );

    // 返回 true 表示异步响应
    return true;
  },
);

/** 统一消息处理入口 */
async function handleMessage(message: Message): Promise<unknown> {
  switch (message.type) {
    case MessageType.SaveNote:
      return await saveNote(message.payload as Omit<Note, "id" | "createdAt">);
    case MessageType.GetNotes:
      return await getNotes();
    default:
      throw new Error(`未知消息类型: ${message.type}`);
  }
}

/** 保存笔记到本地存储 */
async function saveNote(
  noteData: Omit<Note, "id" | "createdAt">,
): Promise<Note> {
  const { notes = [] } = await chrome.storage.local.get("notes");
  const newNote: Note = {
    ...noteData,
    id: crypto.randomUUID(),
    createdAt: Date.now(),
  };
  notes.unshift(newNote);
  await chrome.storage.local.set({ notes });
  return newNote;
}

/** 获取所有笔记 */
async function getNotes(): Promise<Note[]> {
  const { notes = [] } = await chrome.storage.local.get("notes");
  return notes as Note[];
}
```

### Content Script内容脚本

`src/content/index.ts`：

```typescript
import {
  MessageType,
  type Message,
  type MessageResponse,
  type PageInfo,
} from "../shared/types";

/**
 * 内容脚本运行在网页上下文中
 * 可以操作 DOM，但无法直接访问 chrome.storage（需通过消息传递）
 */

// 监听来自 Popup 的请求，提取页面信息
chrome.runtime.onMessage.addListener(
  (
    message: Message,
    _sender: chrome.runtime.MessageSender,
    sendResponse: (response: MessageResponse<PageInfo>) => void,
  ) => {
    if (message.type === MessageType.GetPageInfo) {
      const pageInfo = extractPageInfo();
      sendResponse({ success: true, data: pageInfo });
    }
    return true;
  },
);

/** 从当前页面提取信息 */
function extractPageInfo(): PageInfo {
  // 获取 meta description
  const metaDesc = document.querySelector('meta[name="description"]');

  // 提取正文前 200 字作为摘要
  const article = document.querySelector("article") || document.body;
  const text = (article?.innerText || "").slice(0, 200).trim();

  return {
    title: document.title,
    url: location.href,
    description: metaDesc?.getAttribute("content") || text,
  };
}

// 向页面注入一个悬浮按钮（演示用）
function injectFloatingButton() {
  const btn = document.createElement("button");
  btn.textContent = "📝 保存笔记";
  btn.style.cssText = `
    position: fixed;
    top: 80px;
    right: 20px;
    z-index: 999999;
    padding: 8px 16px;
    background: #4285f4;
    color: white;
    border: none;
    border-radius: 8px;
    cursor: pointer;
    font-size: 14px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.2);
  `;
  btn.onclick = () => {
    const pageInfo = extractPageInfo();
    chrome.runtime.sendMessage({
      type: MessageType.SaveNote,
      payload: pageInfo,
    });
    btn.textContent = "✓ 已保存";
    setTimeout(() => (btn.textContent = "📝 保存笔记"), 1500);
  };
  document.body.appendChild(btn);
}

// 页面加载完成后注入按钮
injectFloatingButton();
```

`src/popup/index.ts`：

```typescript
import {
  MessageType,
  type MessageResponse,
  type PageInfo,
  type Note,
} from "../shared/types";

/**
 * Popup 页面逻辑
 * 运行在独立的 HTML 上下文中，拥有完整 chrome API 权限
 */

const pageInfoEl = document.getElementById("pageInfo")!;
const saveBtn = document.getElementById("saveBtn")!;
const notesListEl = document.getElementById("notesList")!;

// 页面加载时获取当前标签页信息
init();

async function init() {
  const pageInfo = await getCurrentTabPageInfo();
  renderPageInfo(pageInfo);
  await renderNotes();
}

/** 获取当前活动标签页的信息 */
async function getCurrentTabPageInfo(): Promise<PageInfo> {
  // 获取当前激活的标签页
  const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });

  if (!tab.id) throw new Error("无法获取当前标签页");

  // 向 Content Script 发送消息，请求页面信息
  const response = await chrome.tabs.sendMessage<MessageResponse<PageInfo>>(
    tab.id,
    { type: MessageType.GetPageInfo },
  );

  if (!response?.success) {
    // 如果 Content Script 未注入（如 chrome:// 等特殊页面），降级使用 tab 信息
    return {
      title: tab.title || "",
      url: tab.url || "",
      description: "",
    };
  }

  return response.data!;
}

/** 渲染页面信息 */
function renderPageInfo(info: PageInfo) {
  pageInfoEl.innerHTML = `
    <div class="page-title">${escapeHtml(info.title)}</div>
    <div class="page-url">${escapeHtml(info.url)}</div>
  `;
}

/** 保存笔记 */
saveBtn.addEventListener("click", async () => {
  const pageInfo = await getCurrentTabPageInfo();
  await chrome.runtime.sendMessage({
    type: MessageType.SaveNote,
    payload: pageInfo,
  });
  await renderNotes();
  saveBtn.textContent = "✓ 已保存！";
  setTimeout(() => (saveBtn.textContent = "保存当前页面为笔记"), 1500);
});

/** 渲染笔记列表 */
async function renderNotes() {
  const response = await chrome.runtime.sendMessage<MessageResponse<Note[]>>({
    type: MessageType.GetNotes,
  });
  const notes = response?.data || [];

  notesListEl.innerHTML = notes.length
    ? notes
        .map(
          (n) => `
        <div class="note-item">
          <strong>${escapeHtml(n.title)}</strong><br/>
          <small>${new Date(n.createdAt).toLocaleString()}</small>
        </div>
      `,
        )
        .join("")
    : '<div style="color:#999;text-align:center;padding:20px;">暂无笔记</div>';
}

/** 简单的 HTML 转义，防止 XSS */
function escapeHtml(text: string): string {
  const div = document.createElement("div");
  div.textContent = text;
  return div.innerHTML;
}
```

### 通信全景图

```
Popup ──┐
        ├──→ Background (Service Worker) ←── Content Script
Options─┘         ↑                              │
                  └──────── Content Script ──────┘
```

### 常见通信模式

| 场景                   | 发送方         | 接收方         | API                                   |
| ---------------------- | -------------- | -------------- | ------------------------------------- |
| Popup → Content Script | Popup          | 当前页面       | `chrome.tabs.sendMessage()`           |
| Popup → Background     | Popup          | Service Worker | `chrome.runtime.sendMessage()`        |
| Content → Background   | Content Script | Service Worker | `chrome.runtime.sendMessage()`        |
| Background → Content   | Background     | 指定标签页     | `chrome.tabs.sendMessage(tabId, msg)` |
| Background → Popup     | Background     | Popup          | `chrome.runtime.sendMessage()`        |

### 一次性消息与长连接

// 一次性消息（短连接，适合简单请求）

```typescript
// 发送方
const response = await chrome.runtime.sendMessage({ type: "GET_DATA" });
console.log(response);

// 接收方
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  sendResponse({ result: "ok" });
  return true; // 异步响应必须 return true
});
```

// 长连接端口（适合持续通信，如实时同步）

```typescript
// 发送方建立连接
const port = chrome.runtime.connect({ name: "content-port" });

port.postMessage({ type: "HELLO" });
port.onMessage.addListener((msg) => console.log("收到:", msg));

// 接收方监听连接
chrome.runtime.onConnect.addListener((port) => {
  console.log("新连接:", port.name);
  port.onMessage.addListener((msg) => {
    port.postMessage({ type: "ACK" });
  });
});
```

## 存储与权限

| API                      | 容量              | 同步       | 适用场景          |
| ------------------------ | ----------------- | ---------- | ----------------- |
| `chrome.storage.local`   | 5MB（可申请提升） | 否         | 本地数据、设置    |
| `chrome.storage.sync`    | 100KB             | 跨设备同步 | 用户偏好设置      |
| `chrome.storage.session` | 10MB              | 否         | 会话级临时数据    |
| `localStorage`           | 5MB               | 否         | Content Script 内 |

```typescript
// 写入
await chrome.storage.local.set({ key: "value", user: { name: "张三" } });

// 读取
const { key, user } = await chrome.storage.local.get(["key", "user"]);

// 监听变化
chrome.storage.onChanged.addListener((changes, areaName) => {
  console.log(`[${areaName}] 变化:`, changes);
});
```

### 权限声明原则

最小权限原则：只申请你真正需要的权限，过多权限会被 Chrome 商店审核拒绝。如果你想我一样插件自己写自己用或者分享给朋友用，那就没事了

`manifest.json` 中常见权限：

```javascript
{
  "permissions": [
    "storage", // 存储 API
    "activeTab", // 临时访问当前标签页（推荐，比 host_permissions 更友好）
    "scripting", // 动态注入脚本
    "tabs", // 读取标签页信息
    "cookies", // 操作 Cookie
    "contextMenus" // 右键菜单
  ],
  "host_permissions": [
    "https://*.example.com/*" // 只声明需要的域名，不要用 <all_urls>
  ]
}
```
