# 微信小程序自定义 tabBar 高度异常变高

## 问题现象

自定义 tabBar 的常见封装大致如下：

```html
<template>
  <view class="custom-tab-bar">
    <uv-tab-bar
      :value="value"
      :safe-area-inset-bottom="true"
      @change="tabBarStore.onTabBarChange"
    >
      <uv-tab-bar-item
        v-for="item in tabBarStore.list"
        :key="item.url"
        :url="item.url"
        :name="item.name"
      >
        <template #active-icon>
          <CustomIcon :url="item.activeIcon" />
        </template>

        <template #inactive-icon>
          <CustomIcon :url="item.inactiveIcon" />
        </template>

        <template #text>
          <text> {{ item.text }} </text>
        </template>
      </uv-tab-bar-item>
    </uv-tab-bar>
  </view>
</template>

<script setup lang="ts">
  import { useTabBarStore } from "@/store/use-tab-bar";

  withDefaults(
    defineProps<{
      value: string;
    }>(),
    {
      value: "home",
    },
  );

  const tabBarStore = useTabBarStore();
  uni.hideTabBar();
</script>

<style lang="scss"></style>
```

在部分机型（鸿蒙、荣耀等）上，页面切换或返回后 tabBar 的高度会异常变高。

## 原因

`safe-area-inset-bottom` 由组件内部读取系统安全区域后转成内边距。在部分机型的 webview 渲染中，这个值会偶发返回一个明显偏大的异常值（页面切换/返回时尤其容易触发），底部导航因此被撑高。

解决思路：关掉组件的 `safe-area-inset-bottom`，改由 JS 从系统信息里稳定读取安全区高度，自己算总高，并做上限封顶。

## 解决办法

```html
<template>
  <view class="custom-tabbar">
    <uv-tab-bar
      :value="value"
      :safe-area-inset-bottom="false"
      :custom-style="tabBarStyle"
      @change="tabBarStore.onTabBarChange"
    >
      <uv-tab-bar-item
        v-for="item in tabBarStore.list"
        :key="item.url"
        :url="item.url"
        :name="item.name"
      >
        <template #active-icon>
          <CustomIcon :url="item.activeIcon" />
        </template>

        <template #inactive-icon>
          <CustomIcon :url="item.inactiveIcon" />
        </template>

        <template #text>
          <text> {{ item.text }} </text>
        </template>
      </uv-tab-bar-item>
    </uv-tab-bar>
  </view>
</template>

<script setup lang="ts">
  import CustomIcon from "@/components/custom-icon/index.vue";
  import { useTabBarStore } from "@/store/use-tab-bar";
  import { computed, ref } from "vue";

  withDefaults(
    defineProps<{
      value: string;
    }>(),
    {
      value: "home",
    },
  );

  const tabBarStore = useTabBarStore();

  // 菜单项固定高度（uv-tab-bar 内部 item-wrapper 为 50px）
  const ITEM_HEIGHT = 50;
  // 安全区高度上限，挡掉异常返回值(根据自己感觉来)
  const MAX_SAFE_BOTTOM = 40;

  const getSafeAreaBottom = () => {
    try {
      const info = uni.getSystemInfoSync();
      const bottom =
        info?.safeAreaInsets?.bottom ??
        (info?.screenHeight != null && info?.safeArea
          ? info.screenHeight - info.safeArea.bottom
          : 0);
      return Math.min(
        Math.max(0, Math.ceil(Number(bottom) || 0)),
        MAX_SAFE_BOTTOM,
      );
    } catch {
      return 0;
    }
  };

  const safeBottomPx = ref(getSafeAreaBottom());

  const tabBarStyle = computed(() => ({
    zIndex: 9,
    height: `${ITEM_HEIGHT + safeBottomPx.value}px`,
    flex: "none",
    flexShrink: "0",
    boxSizing: "border-box",
    paddingBottom: `${safeBottomPx.value}px`,
  }));

  uni.hideTabBar();
</script>

<style lang="scss"></style>
```

## 要点

- `:safe-area-inset-bottom="false"` 必须显式关掉，否则组件内部仍会叠加一层安全区内边距；
- 高度走 `height` + `paddingBottom` 双写：内容区占 `ITEM_HEIGHT`，底部留 `safeBottomPx` 给安全区；
- `boxSizing: border-box` 不能漏，否则 `height` 不含 padding，总高会多出一个安全区；
- `flex: none` / `flexShrink: 0` 防止父容器是 flex 布局时被拉伸压缩；
- 安全区高度做上限封顶（示例为 40px），即便系统返回异常值也不会把 tabBar 撑爆。
