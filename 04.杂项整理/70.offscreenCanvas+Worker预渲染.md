# OffscreenCanvas + Worker预渲染：从 JSON 像素矩阵到 ImageBitmap 缓存

> 一些前置知识点于 `04.杂项整理/66.offscreencanvas+worker渲染.md` 有讲解，本篇是进阶

像素游戏看着"简单"，但它有两个很容易被低估的开销：

1. 像素数据的生成成本：一张 14 × 14 的单位、4 倍缩放后是 56 × 56 个色块，逐格 `fillRect` 一次就是 196 次绘制调用。乘以帧数、乘以配色变体、乘以单位种类，初始化阶段很容易堆到几十上百张位图的生成量。
2. 每帧的合成成本：如果每个单位每帧都重新解析矩阵、重新着色，哪怕只有几十个单位，主线程也会被 16.7ms 的帧预算榨干。

离屏预渲染把像素生成（贵、一次性）搬进 Worker，产物是`ImageBitmap`，然后主线程每帧合成（高频、但极轻），只做 `drawImage(bitmap, x, y)`。结果就是初始化不再阻塞 UI，运行时每帧每个单位只有一次 `drawImage`

---

## 三类开销，只能搬走两类

| 开销                             | 频率                             | 位置                   | 能不能搬走                                  |
| -------------------------------- | -------------------------------- | ---------------------- | ------------------------------------------- |
| 像素矩阵 → 像素数据              | 每个单位 × 每帧 × 每个变体，一次 | 任意线程               | 完全可搬进 Worker                           |
| 位图 → 画布合成                  | 每帧 × 每个单位                  | 必须在有可见画布的地方 | 可以搬，但需要 `transferControlToOffscreen` |
| 单位状态推进（位置、朝向、帧号） | 每帧                             | CPU 极轻               | 可选                                        |

绝大多数像素项目卡在第一步：他们把这件又重又只做一次的事情，放在了最不能阻塞的地方，主线程的首屏渲染路径上。我之前寄掉的demo[中世纪RPG](https://awen-blog.netlify.app/#/demo/draw-game-units) 烂尾的主要原因就是技术路线出了错，积重难返

为何选择预渲染：

- 单位尺寸小（通常 8~32 像素见方），位图内存可控；
- 帧数是有限的（idle / walk / attack，一般不超过十几帧）；
- 像素内容不可变（除非换配色），天然适合做成缓存。

## offscreenCanvas

Worker 里没有 DOM。`OffscreenCanvas`就是为了解决这个，它提供与 `HTMLCanvasElement` 几乎一致的 2D 绘图 API，但完全脱离 DOM，可以自由地在 Worker 里创建、绘制、销毁。

```typescript
// 1. 把当前画布内容"取走"，变成一个可转移的位图
const bitmap: ImageBitmap = offscreenCanvas.transferToImageBitmap();

// 2. 编码成文件（做资源导出时有用，运行时用不到）
const blob: Blob = await offscreenCanvas.convertToBlob({ type: "image/png" });
```

注意这里用的是 **transfer** 而不是 copy。`ImageBitmap` 是标准的 [transferable object](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Transferable_objects)，`postMessage` 时把它列进转移列表，就不会发生结构化克隆（不复制像素数据，也不产生内存峰值），所有权直接移交给主线程。

| 方案                                                          | Worker 里可行 | 跨线程成本                    | 结论                                         |
| ------------------------------------------------------------- | ------------- | ----------------------------- | -------------------------------------------- |
| `getImageData()` + 传 `Uint8ClampedArray`                     | v             | 几十万字节的结构化克隆 / 转移 | 可以，但要自己算 RGBA，还得处理 alpha 与缩放 |
| `OffscreenCanvas.convertToBlob()` → `createImageBitmap(blob)` | x             | PNG 编码 + 解码，双重开销     | 明显更慢，适合导出，不适合运行时             |
| `transferToImageBitmap()` + transfer 列表                     | v             | 指针级转移，零拷贝            | **选它**                                     |

## Worker

Worker 的全部职责就是把输入的矩阵变成位图，然后把位图交出去，见下文`paintFrame()函数`

注意：

**用 `fillRect` 而不是 `putImageData`。** `putImageData` 需要你自己拼 `Uint8ClampedArray`、处理 RGBA 顺序、处理 alpha 预乘；而 `fillRect` 在整数坐标、整数尺寸下就是纯色块，没有插值，天然锐利，代码量还少一半。像素画的格子是离散的，没必要走逐像素写入。

**缩放放在 Worker 里做。** `pixelScale` 在离屏阶段就乘进去了，输出位图的 `width` 已经是 `14 * 4 = 56` 物理像素。主线程拿到的是"即用型"位图，绘制时不需要再做任何缩放计算——`drawImage` 不缩放是最快的路径。

**每个单位 × 每帧都新建一张 `OffscreenCanvas`。** 见下面第 6 节的第一条坑：`transferToImageBitmap` 会清空画布，复用会串帧。

一次性生成好所有的朕，然后是一次性的批量渲染与回传，见下文`scope.onmessage`，这里的 `transferables` 是关键。如果漏传这个数组，`ImageBitmap` 会退化成结构化克隆——数据量小时看不出来，等到位图数量和尺寸上去，主线程就会在 `onmessage` 里莫名其妙地卡一下。传输结构也尽量"扁平"：一次消息把全部位图打包回传而不是每个单位一条消息,消息边界本身就是成本（序列化、调度、微任务队列），能合并就合并

## 主线程

### 一次性预加载与模式切换

一次性的加载，见下文`preloadUnits()`,主线程分支的产物同样是 `ImageBitmap`（`createImageBitmap(htmlCanvas)`），所以绘制代码一份就够

```typescript
// 主线程兜底：HTMLCanvasElement → createImageBitmap
const canvases = unit.frames.map((frame) =>
  paintOnMainThread(unit, frame.rows, pixelScale),
);
const bitmapJobs = canvases.map((canvas) => createImageBitmap(canvas));
```

`createImageBitmap` 是异步的，所以这条路径用 `Promise.all` 收口——但绘制动作本身是同步的，这段会实打实占住主线程

### 位图缓存与每帧绘制

到主线程后，所有内容变成一个 `Map`：

```typescript
const bitmapMap = new Map<string, UnitBitmaps>();

const syncBitmaps = (): void => {
  bitmapMap.clear();
  props.unitBitmaps?.forEach((item) => {
    bitmapMap.set(item.unitId, item);
  });
};
```

绘制一个单位，全部工作就是一次 `drawImage`：

```typescript
const entry = bitmapMap.get(actor.unitId);
const bitmap = entry.bitmaps[actor.frameIndex % entry.bitmaps.length];

target.drawImage(bitmap, actor.x, actor.y, entry.width, entry.height);
```

朝向改变时，不生成第二套资源，左向直接水平镜像同一张位图

```typescript
target.save();
target.translate(actor.x + width, actor.y);
target.scale(-1, 1);
target.drawImage(bitmap, 0, 0, width, height);
target.restore();
```

## 注意

### `transferToImageBitmap` 会清空画布

它不是"复制一份"，是"取走"。调用之后画布立刻被重置为透明黑。所以：

- 想复用同一张 `OffscreenCanvas` 渲染多帧，每次都必须把整帧重画一遍，不能只画"变化的部分"；
- 我们的做法是每帧新建一张画布。`OffscreenCanvas` 的创建很便宜，而且被 transfer 掉之后本来就会 GC，不存在泄漏。

反过来，这也意味着**不能用增量绘制去做动画**，预渲染是"一次画完整帧"，和"局部重绘优化"是两个思路，不要混着用。

### `ImageBitmap` 要主动 `close()`

位图在 GPU 侧是有内存的，而且不受 JS 垃圾回收管理（浏览器不保证及时回收）。切换缩放倍率、切换配色数量、切换渲染模式时，旧位图必须显式释放,见下文`disposePreload()`

```typescript
const previous = preloadResult.value;
preloadResult.value = null;
// 先让子组件把旧位图从绘制逻辑里摘掉，再统一 close()
nextTick().then(() => disposePreload(previous));
```

顺序反了就会绘制已销毁的位图，Chrome 上表现为偶尔闪一下黑块

### 转移之后的位图，原线程就不能再用了

`postMessage` 转移所有权之后,Worker侧那块内存已经归主线程,如果在 Worker 里还想再画一次，必须重新生成。

```typescript
worker.onmessage = (event: MessageEvent<RenderResponse>) => {
  stop() // terminate
  resolve({ ... })
}
```

常驻 Worker 只在需要反复重建位图（比如玩家换装、色相实时调节）时才有意义。

### 缩放必须是整数

`pixelScale` 取 2 / 3 / 4 / 6，全是整数。为什么不能是 2.5：

- 位图尺寸会被算成 `14 * 2.5 = 35` 像素，一格像素落在 2.5 个物理像素上，`fillRect` 会产生半像素覆盖；
- 即使 `imageSmoothingEnabled = false`，非整数缩放仍会让部分格子变成 2 像素、部分变成 3 像素，像素画那种"齐整"的节奏感立刻消失。

这一条在纯代码里看不出来，只有跑起来才刺眼。

### `devicePixelRatio` 要拆成两层坐标

- **逻辑像素（CSS px）**：`view.width / view.height`、单位的 `x / y`；
- **物理像素（backing store）**：`canvas.width / canvas.height`。

画布 backing store 按 `dpr` 放大，然后用一次 `setTransform` 统一缩放：

```typescript
target.setTransform(1, 0, 0, 1, 0, 0);
target.clearRect(
  0,
  0,
  view.width * devicePixelRatioCache,
  view.height * devicePixelRatioCache,
);
target.setTransform(devicePixelRatioCache, 0, 0, devicePixelRatioCache, 0, 0);
```

这样之后所有绘制都用逻辑坐标，`drawImage(bitmap, x, y)` 写的还是 `x`。因为 `pixelScale × dpr` 仍是整数（4 × 2 = 8），像素依然锐利。

顺手把 `dpr` 钳在 2 以内（`Math.min(window.devicePixelRatio || 1, 2)`）：3x 屏上再往上堆物理像素，肉眼几乎看不出差别，内存和填充率却翻倍。

### `image-rendering: pixelated` 只是兜底

CSS 上的 `image-rendering: pixelated` 管的是元素被 CSS 缩放时的采样方式,如果画布的 backing store 和显示尺寸已经 1:1，它其实不起作用。真正的锐利来源是：整数缩放 + `ctx.imageSmoothingEnabled = false`。两者都写上，但别把 CSS 当主手段。

### Worker 里没有 `requestAnimationFrame`

所以 Worker 适合做"一次性批量生成"，不适合直接当渲染循环。真想整帧离屏渲染，要么 `canvas.transferControlToOffscreen()` 把可见画布交给 Worker（由主线程的 rAF 驱动 `postMessage` 推进），要么在 Worker 里用 `setTimeout(16)` 近似,后者精度差、且不可见时不会自动停，功耗会很难看。

### Vue 的响应式不要包住热数据

单位数组、位图 Map 这些每帧都在读写的东西，一旦放进 `reactive`/`ref`，就会被包成 Proxy，每帧几百次属性读取都多一层拦截

```typescript
/** 以下都是刻意不放进 Vue 响应式的热数据：每帧都会读写，代理开销不划算 */
const actors: Actor[] = [];
const bitmapMap = new Map<string, UnitBitmaps>();
```

只有真正要驱动 UI 的东西（FPS、预渲染耗时、位图数）才用 `ref`,响应式只给 UI 用，不给渲染循环用

### Vite 里 Worker 的写法

必须让构建器知道这是一个 Worker 入口，否则它会被当成普通模块打进主 bundle：

```typescript
const worker = new Worker(
  new URL("../workers/unit-renderer.worker.ts", import.meta.url),
  {
    type: "module",
  },
);
```

`new URL(..., import.meta.url)` 这种字面量写法是 Vite / Webpack 5 都能识别的约定。别拼接变量，构建期静态分析会失效。构建产物里能看到独立的 `unit-renderer.worker-xxxx.js`，就说明配置对了。

### Worker 的类型声明别乱引 lib

`/// <reference lib="webworker" />` 会和工程已有的 `DOM` lib 产生大量重复声明，`vue-tsc` 直接报错。只声明真正用到的成员即可：

```typescript
interface WorkerScope {
  onmessage: ((event: MessageEvent<RenderRequest>) => void) | null;
  onerror: ((event: string | Event) => void) | null;
  postMessage(message: RenderResponse, transfer?: Transferable[]): void;
}

const scope = self as unknown as WorkerScope;
```

`self` 在 `DOM` lib 里是 `Window`，`postMessage` 的签名对不上，所以需要这个中间层。

### 按 y 排序制造伪深度

俯视/侧视混排的场景里，否则后画的单位永远盖住先画的：

```typescript
actors
  .slice()
  .sort((left, right) => left.y - right.y)
  .forEach(drawActor);
```

用 `.slice()` 是为了不原地改数组（下一帧的遍历顺序会乱）。几百个元素的排序每帧不到 0.05ms，完全不用操心；上千个单位时应该换成桶排序或直接维护有序列表。

### 首屏不要等预渲染

真实项目里更好的做法是先给一个占位帧,比如一张静态剪影或上一版本的位图，等 Worker回包再替换,预渲染的价值是"不阻塞交互"，不是"让画面更快出现"

## 进阶方向

### 把合成循环也搬进Worker

现在主线程每帧做 N 次 `drawImage`。单位数量上到几千时，可以把可见画布的控制权交出去：

```typescript
const canvas = document.querySelector("canvas")!;
const offscreen = canvas.transferControlToOffscreen();
const renderWorker = new Worker(
  new URL("./render.worker.ts", import.meta.url),
  { type: "module" },
);

renderWorker.postMessage({ type: "init", canvas: offscreen }, [offscreen]);
```

之后 Worker 里拿到的就是一个真正的 `OffscreenCanvas`，主线程只负责发输入事件和状态增量。注意两点：

- `transferControlToOffscreen()` **每个canvas只能调用一次**，调用后该 canvas 元素上的 2D context 就废了；
- Worker 里没有 rAF，只能靠主线程 `postMessage('tick', dt)` 驱动，或者用 `setTimeout` 凑合。

### 共享内存

上千个单位的坐标每帧回传，`postMessage` 的结构化克隆会变成瓶颈。`SharedArrayBuffer` + `Atomics` 能让 Worker 直接读写同一块内存。代价是页面必须开启 `Cross-Origin-Opener-Policy: same-origin` 与 `Cross-Origin-Embedder-Policy: require-corp`，接入成本不低，先确认真的到了瓶颈再上。

### 图集（spritesheet）

位图数量多到几百张时，`drawImage` 的调用次数和纹理切换会成为新瓶颈。我们可以把所有帧打进一张大图集（预渲染阶段本来就已经在离屏画布上了，直接按网格排版即可），运行时用 `drawImage(sheet, sx, sy, sw, sh, dx, dy, dw, dh)` 取子区域，纹理切换从 N 次降到 1 次。

### 预渲染到 WebGL 纹理

如果最终要走 WebGL 渲染，`ImageBitmap` 可以直接喂给 `texImage2D`（`gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, bitmap)`），不需要经过 `HTMLImageElement`。这条路能省掉一次 CPU 到 GPU 的解码。

## 什么时候不该这么做

- 单位只有一种、两帧、全程只画一次：直接在主线程 `fillRect` 完事，Worker 的启动和通信开销比绘制本身还大
- 需要**实时**改色、换装、调亮度:位图缓存会失效，"预渲染"的优势变成负担。这种需求应该用 WebGL shader 在绘制时染色，而不是缓存每套配色
- 位图内存吃紧的低端设备：`ImageBitmap` 是 GPU 侧的，比想象中贵。所有变体都缓存在内存里，很容易在低端安卓机上被系统回收导致白块，需要做 LRU。

## 完整代码

### src/components/PixelStage.vue

```html
<template>
  <div ref="stageRef" class="stage">
    <canvas ref="canvasRef" class="stage-canvas" />
    <div v-if="!unitBitmaps" class="stage-placeholder">正在预渲染像素位图…</div>
  </div>
</template>

<script setup lang="ts">
  import { onBeforeUnmount, onMounted, ref, watch } from "vue";
  import type { UnitBitmaps, UnitDef } from "../types/pixel";
  import {
    spawnActor,
    stepActors,
    type Actor,
    type SceneBounds,
  } from "../core/scene";

  const props = defineProps<{
    unitBitmaps: UnitBitmaps[] | null;
    units: UnitDef[];
    actorCount: number;
    paused: boolean;
  }>();

  const emit = defineEmits<{ (event: "fps", value: number): void }>();

  const stageRef = ref<HTMLDivElement | null>(null);
  const canvasRef = ref<HTMLCanvasElement | null>(null);

  let ctx: CanvasRenderingContext2D | null = null;
  let background: HTMLCanvasElement | null = null;
  let resizeObserver: ResizeObserver | null = null;
  let rafId = 0;
  let lastTime = 0;
  let devicePixelRatioCache = 1;

  /** 场景逻辑尺寸（CSS 像素），与画布 backing store 的物理像素解耦 */
  const view: SceneBounds = { width: 0, height: 0 };

  /** 以下都是刻意不放进 Vue 响应式的热数据：每帧都会读写，代理开销不划算 */
  const actors: Actor[] = [];
  const bitmapMap = new Map<string, UnitBitmaps>();
  const sizeMap = new Map<string, { width: number; height: number }>();

  let fpsSamples = 0;
  let fpsWindowStart = 0;

  const syncBitmaps = (): void => {
    bitmapMap.clear();
    sizeMap.clear();

    props.unitBitmaps?.forEach((item) => {
      bitmapMap.set(item.unitId, item);
      sizeMap.set(item.unitId, { width: item.width, height: item.height });
    });
  };

  const rebuildActors = (): void => {
    actors.length = 0;

    const playable = props.units.filter(
      (unit) => bitmapMap.has(unit.id) && sizeMap.has(unit.id),
    );
    if (!playable.length || view.width === 0) return;

    for (let index = 0; index < props.actorCount; index += 1) {
      const unit = playable[index % playable.length];
      const size = sizeMap.get(unit.id);
      if (!size) continue;

      actors.push(spawnActor(unit, size.width, size.height, view));
    }
  };

  /** 静态背景预渲染一次：渐变 + 网格，之后每帧只做一次 drawImage */
  const buildBackground = (): HTMLCanvasElement | null => {
    if (view.width === 0 || view.height === 0) return null;

    const canvas = document.createElement("canvas");
    canvas.width = Math.round(view.width * devicePixelRatioCache);
    canvas.height = Math.round(view.height * devicePixelRatioCache);

    const paint = canvas.getContext("2d");
    if (!paint) return null;

    paint.setTransform(
      devicePixelRatioCache,
      0,
      0,
      devicePixelRatioCache,
      0,
      0,
    );

    const gradient = paint.createLinearGradient(0, 0, 0, view.height);
    gradient.addColorStop(0, "#0a1120");
    gradient.addColorStop(0.55, "#111a2b");
    gradient.addColorStop(1, "#16202f");
    paint.fillStyle = gradient;
    paint.fillRect(0, 0, view.width, view.height);

    const cell = 32;
    paint.strokeStyle = "rgba(86, 148, 220, 0.10)";
    paint.lineWidth = 1;
    paint.beginPath();

    for (let x = 0; x <= view.width; x += cell) {
      paint.moveTo(x + 0.5, 0);
      paint.lineTo(x + 0.5, view.height);
    }

    for (let y = 0; y <= view.height; y += cell) {
      paint.moveTo(0, y + 0.5);
      paint.lineTo(view.width, y + 0.5);
    }

    paint.stroke();

    const glow = paint.createRadialGradient(
      view.width * 0.5,
      view.height * 0.42,
      20,
      view.width * 0.5,
      view.height * 0.42,
      view.width * 0.6,
    );
    glow.addColorStop(0, "rgba(64, 140, 220, 0.14)");
    glow.addColorStop(1, "rgba(10, 17, 32, 0)");
    paint.fillStyle = glow;
    paint.fillRect(0, 0, view.width, view.height);

    return canvas;
  };

  const resize = (): void => {
    const stage = stageRef.value;
    const canvas = canvasRef.value;
    if (!stage || !canvas) return;

    const rect = stage.getBoundingClientRect();
    if (rect.width === 0 || rect.height === 0) return;

    devicePixelRatioCache = Math.min(window.devicePixelRatio || 1, 2);
    view.width = rect.width;
    view.height = rect.height;

    canvas.width = Math.round(rect.width * devicePixelRatioCache);
    canvas.height = Math.round(rect.height * devicePixelRatioCache);
    canvas.style.width = `${rect.width}px`;
    canvas.style.height = `${rect.height}px`;

    ctx = canvas.getContext("2d");
    if (ctx) ctx.imageSmoothingEnabled = false;

    background = buildBackground();
    rebuildActors();
  };

  const drawActor = (actor: Actor): void => {
    const target = ctx;
    if (!target) return;

    const entry = bitmapMap.get(actor.unitId);
    if (!entry) return;

    const bitmap = entry.bitmaps[actor.frameIndex % entry.bitmaps.length];
    if (!bitmap) return;

    const width = entry.width;
    const height = entry.height;
    const centerX = actor.x + width * 0.5;

    target.fillStyle = "rgba(0, 0, 0, 0.30)";
    target.beginPath();
    target.ellipse(
      centerX,
      actor.y + height - 2,
      width * 0.32,
      height * 0.08,
      0,
      0,
      Math.PI * 2,
    );
    target.fill();

    if (actor.facing === 1) {
      target.drawImage(bitmap, actor.x, actor.y, width, height);
      return;
    }

    // 左向不做第二套资源：水平镜像同一张 ImageBitmap 即可
    target.save();
    target.translate(actor.x + width, actor.y);
    target.scale(-1, 1);
    target.drawImage(bitmap, 0, 0, width, height);
    target.restore();
  };

  /** 按 y 排序制造前后遮挡（伪深度），数量不大时开销可以忽略 */
  const drawScene = (): void => {
    const target = ctx;
    if (!target) return;

    target.setTransform(1, 0, 0, 1, 0, 0);
    target.clearRect(
      0,
      0,
      view.width * devicePixelRatioCache,
      view.height * devicePixelRatioCache,
    );
    target.setTransform(
      devicePixelRatioCache,
      0,
      0,
      devicePixelRatioCache,
      0,
      0,
    );

    if (background) {
      target.drawImage(background, 0, 0, view.width, view.height);
    }

    actors
      .slice()
      .sort((left, right) => left.y - right.y)
      .forEach(drawActor);
  };

  const loop = (now: number): void => {
    rafId = window.requestAnimationFrame(loop);

    const deltaSeconds = lastTime === 0 ? 0 : (now - lastTime) / 1000;
    lastTime = now;

    if (!props.paused && deltaSeconds > 0) {
      stepActors(actors, deltaSeconds, view, sizeMap);
    }

    drawScene();

    fpsSamples += 1;
    if (fpsWindowStart === 0) fpsWindowStart = now;

    if (now - fpsWindowStart >= 500) {
      emit("fps", Math.round((fpsSamples * 1000) / (now - fpsWindowStart)));
      fpsSamples = 0;
      fpsWindowStart = now;
    }
  };

  watch(
    () => props.unitBitmaps,
    () => {
      syncBitmaps();
      rebuildActors();
    },
  );

  watch(
    () => props.actorCount,
    () => {
      rebuildActors();
    },
  );

  onMounted(() => {
    syncBitmaps();
    resize();

    resizeObserver = new ResizeObserver(() => {
      resize();
    });

    if (stageRef.value) resizeObserver.observe(stageRef.value);

    rafId = window.requestAnimationFrame(loop);
  });

  onBeforeUnmount(() => {
    window.cancelAnimationFrame(rafId);
    resizeObserver?.disconnect();
    actors.length = 0;
  });
</script>

export const hexToHsl = (hex: string): [number, number, number] => {
  const value = hex.replace("#", "");
  const r = parseInt(value.slice(0, 2), 16) / 255;
  const g = parseInt(value.slice(2, 4), 16) / 255;
  const b = parseInt(value.slice(4, 6), 16) / 255;

  const max = Math.max(r, g, b);
  const min = Math.min(r, g, b);
  const delta = max - min;
  const lightness = (max + min) / 2;

  if (delta === 0) {
    return [0, 0, lightness * 100];
  }

  const saturation = delta / (1 - Math.abs(2 * lightness - 1));
  let hue = 0;

  if (max === r) {
    hue = ((g - b) / delta) % 6;
  } else if (max === g) {
    hue = (b - r) / delta + 2;
  } else {
    hue = (r - g) / delta + 4;
  }

  hue *= 60;
  if (hue < 0) hue += 360;

  return [hue, saturation * 100, lightness * 100];
};

const channelToHex = (value: number): string => {
  const channel = Math.round(Math.min(1, Math.max(0, value)) * 255);
  return channel.toString(16).padStart(2, "0");
};

export const hslToHex = (
  hue: number,
  saturation: number,
  lightness: number,
): string => {
  const h = ((hue % 360) + 360) % 360;
  const s = Math.min(100, Math.max(0, saturation)) / 100;
  const l = Math.min(100, Math.max(0, lightness)) / 100;

  const chroma = (1 - Math.abs(2 * l - 1)) * s;
  const second = chroma * (1 - Math.abs(((h / 60) % 2) - 1));
  const offset = l - chroma / 2;

  const table: [number, number, number][] = [
    [chroma, second, 0],
    [second, chroma, 0],
    [0, chroma, second],
    [0, second, chroma],
    [second, 0, chroma],
    [chroma, 0, second],
  ];

  const [r, g, b] = table[Math.floor(h / 60) % 6];
  return `#${channelToHex(r + offset)}${channelToHex(g + offset)}${channelToHex(b + offset)}`;
};

export const shiftHue = (hex: string, degrees: number): string => {
  const [h, s, l] = hexToHsl(hex);
  return hslToHex(h + degrees, s, l);
};

import type {
  PreloadMode,
  PreloadResult,
  RenderRequest,
  RenderResponse,
  UnitBitmaps,
  UnitDef,
} from "../types/pixel";

const paintOnMainThread = (
  unit: UnitDef,
  rows: string[],
  pixelScale: number,
): HTMLCanvasElement => {
  const canvas = document.createElement("canvas");
  canvas.width = unit.width * pixelScale;
  canvas.height = unit.height * pixelScale;

  const ctx = canvas.getContext("2d");
  if (!ctx) {
    throw new Error(`[main] 2d context 不可用: ${unit.id}`);
  }

  ctx.imageSmoothingEnabled = false;

  rows.forEach((row, rowIndex) => {
    const length = Math.min(row.length, unit.width);

    for (let colIndex = 0; colIndex < length; colIndex += 1) {
      const color = unit.palette[row[colIndex]];
      if (!color) continue;

      ctx.fillStyle = color;
      ctx.fillRect(
        colIndex * pixelScale,
        rowIndex * pixelScale,
        pixelScale,
        pixelScale,
      );
    }
  });

  return canvas;
};

/** 主线程同步逐格绘制 + createImageBitmap */
export const preloadOnMainThread = (
  units: UnitDef[],
  pixelScale: number,
): Promise<PreloadResult> => {
  const startedAt = performance.now();

  const jobs = units.map((unit) => {
    const canvases = unit.frames.map((frame) =>
      paintOnMainThread(unit, frame.rows, pixelScale),
    );
    const bitmapJobs = canvases.map((canvas) => createImageBitmap(canvas));

    return Promise.all(bitmapJobs).then(
      (bitmaps): UnitBitmaps => ({
        unitId: unit.id,
        frameNames: unit.frames.map((frame) => frame.name),
        width: unit.width * pixelScale,
        height: unit.height * pixelScale,
        bitmaps,
      }),
    );
  });

  return Promise.all(jobs).then((unitBitmaps) => ({
    unitBitmaps,
    elapsedMs: performance.now() - startedAt,
    mode: "main" as PreloadMode,
    transferable: false,
  }));
};

/** result → 创建它的 Worker：位图像素后端挂在 worker 上下文上，worker 必须存活到位图释放 */
const resultWorkers = new WeakMap<PreloadResult, Worker>();

/**
 * Worker 预渲染：绘制全程不占用主线程，回传的 ImageBitmap 走零拷贝转移。
 *
 * 注意不能在 onmessage 里立即 terminate()：worker 内 transferToImageBitmap
 * 产出的 ImageBitmap，其像素后端与 worker 上下文绑定，worker 一旦被终止，
 * 已转移到主线程的位图会整体变空白（宽高不变、closed 仍为 false、无任何报错）。
 * 因此 worker 生命周期跟随 result，由 disposePreload 在位图释放时统一 terminate。
 */
export const preloadInWorker = (
  units: UnitDef[],
  pixelScale: number,
): Promise<PreloadResult> =>
  new Promise((resolve, reject) => {
    const worker = new Worker(
      new URL("../workers/unit-renderer.worker.ts", import.meta.url),
      {
        type: "module",
      },
    );

    worker.onmessage = (event: MessageEvent<RenderResponse>) => {
      const result: PreloadResult = {
        unitBitmaps: event.data.payload,
        elapsedMs: event.data.elapsedMs,
        mode: "worker",
        transferable: true,
      };
      resultWorkers.set(result, worker);
      resolve(result);
    };

    // 失败路径没有产生任何位图，可以放心立即终止
    worker.onerror = (event) => {
      worker.terminate();
      reject(new Error(event.message || "[worker] 预渲染失败"));
    };

    const request: RenderRequest = { type: "render-units", units, pixelScale };
    worker.postMessage(request);
  });

/** 统一入口：Worker 可用就走 Worker，否则回退主线程 */
export const preloadUnits = (
  units: UnitDef[],
  pixelScale: number,
  mode: PreloadMode,
): Promise<PreloadResult> => {
  const workerSupported =
    typeof Worker !== "undefined" &&
    typeof OffscreenCanvas !== "undefined" &&
    typeof ImageBitmap !== "undefined";

  if (mode === "worker" && workerSupported) {
    return preloadInWorker(units, pixelScale).catch((error: unknown) => {
      console.warn(error);
      return preloadOnMainThread(units, pixelScale);
    });
  }

  return preloadOnMainThread(units, pixelScale);
};

/**
 * 释放位图内存，切换缩放/单位集时必须调用，否则 GPU 侧会持续占用。
 * 位图 close() 完成后再 terminate 创建它的 worker（顺序不能颠倒，
 * 也不能提前——worker 存活期间位图内容才有效）。
 */
export const disposePreload = (result: PreloadResult | null): void => {
  if (!result) return;

  result.unitBitmaps.forEach((item) => {
    item.bitmaps.forEach((bitmap) => bitmap.close());
  });

  const worker = resultWorkers.get(result);
  if (worker) {
    worker.terminate();
    resultWorkers.delete(result);
  }
};

  width: number;
  height: number;
}

let actorSeed = 0;

const randomBetween = (min: number, max: number): number =>
  min + Math.random() * (max - min);

/** 按单位位图尺寸随机撒一个演员 */
export const spawnActor = (
  unit: UnitDef,
  unitWidth: number,
  unitHeight: number,
  bounds: SceneBounds,
): Actor => {
  actorSeed += 1;
  const speed = randomBetween(18, 46);

  return {
    key: actorSeed,
    unitId: unit.id,
    x: randomBetween(unitWidth, Math.max(unitWidth, bounds.width - unitWidth)),
    y: randomBetween(
      unitHeight,
      Math.max(unitHeight, bounds.height - unitHeight),
    ),
    vx: speed,
    vy: randomBetween(-14, 14),
    facing: Math.random() > 0.5 ? 1 : -1,
    frameIndex: 0,
    frameTimer: Math.random() * 0.3,
    frameInterval: unit.id === "slime" ? 0.34 : 0.18,
    turnTimer: randomBetween(1.2, 3.4),
  };
};

/**
 * 一帧的纯逻辑推进：只算坐标与帧号，不碰 DOM、不碰 canvas。
 * 这样这段逻辑将来可以直接搬进 Worker（把渲染循环整体离屏化）。
 */
export const stepActors = (
  actors: Actor[],
  deltaSeconds: number,
  bounds: SceneBounds,
  unitSizes: Map<string, { width: number; height: number }>,
): void => {
  const dt = Math.min(deltaSeconds, 0.05);

  actors.forEach((actor) => {
    const size = unitSizes.get(actor.unitId);
    if (!size) return;

    actor.turnTimer -= dt;
    if (actor.turnTimer <= 0) {
      actor.turnTimer = randomBetween(1.4, 3.6);
      const speed = Math.hypot(actor.vx, actor.vy) || randomBetween(18, 46);
      const angle = randomBetween(-0.45, 0.45);
      const sign = Math.random() > 0.5 ? 1 : -1;
      actor.vx = sign * speed * Math.cos(angle);
      actor.vy = speed * Math.sin(angle);
      actor.facing = actor.vx >= 0 ? 1 : -1;
    }

    actor.x += actor.vx * dt;
    actor.y += actor.vy * dt;

    if (actor.x <= 0) {
      actor.x = 0;
      actor.vx = Math.abs(actor.vx);
      actor.facing = 1;
    } else if (actor.x + size.width >= bounds.width) {
      actor.x = bounds.width - size.width;
      actor.vx = -Math.abs(actor.vx);
      actor.facing = -1;
    }

    if (actor.y <= 0) {
      actor.y = 0;
      actor.vy = Math.abs(actor.vy);
    } else if (actor.y + size.height >= bounds.height) {
      actor.y = bounds.height - size.height;
      actor.vy = -Math.abs(actor.vy);
    }

    actor.frameTimer += dt;
    if (actor.frameTimer >= actor.frameInterval) {
      actor.frameTimer = 0;
      actor.frameIndex += 1;
    }
  });
};

import type { UnitDef, UnitsFile } from "../types/pixel";
import { shiftHue } from "./color";

/** 描边 / 眼睛 / 肤色这类低饱和或不该被染色的角色，保持原样 */
const PROTECTED_KEYS = new Set([".", "K", "E", "F"]);

const recolor = (unit: UnitDef, hueShift: number, key: string): UnitDef => ({
  ...unit,
  id: key,
  palette: Object.entries(unit.palette).reduce<Record<string, string | null>>(
    (acc, [char, color]) => {
      if (!color || PROTECTED_KEYS.has(char)) {
        acc[char] = color;
        return acc;
      }

      acc[char] = shiftHue(color, hueShift);
      return acc;
    },
    {},
  ),
});

/**
 * 同一个矩阵 × N 套配色 = N 个"变体单位"。
 * 这是演示「预渲染工作量」最省事的方式：矩阵不变，只换调色板，
 * 每个变体都要重新逐格填色并生成位图。
 */
export const buildVariantUnits = (
  file: UnitsFile,
  variantsPerUnit: number,
): UnitDef[] =>
  file.units.flatMap((unit, unitIndex) => {
    const count = Math.max(1, variantsPerUnit);

    return Array.from({ length: count }, (_, variantIndex) => {
      if (variantIndex === 0) {
        return { ...unit, id: `${unit.id}#0` };
      }

      const hueShift = (360 / count) * variantIndex + unitIndex * 96;
      return recolor(unit, hueShift, `${unit.id}#${variantIndex}`);
    });
  });

import type {
  RenderRequest,
  RenderResponse,
  UnitBitmaps,
  UnitDef,
} from "../types/pixel";

/**
 * 这里不用 /// <reference lib="webworker" />：它会和工程里的 DOM lib 产生
 * 大量重复声明，vue-tsc 会直接报错。只声明真正用到的两个成员即可。
 */
interface WorkerScope {
  onmessage: ((event: MessageEvent<RenderRequest>) => void) | null;
  onerror: ((event: string | Event) => void) | null;
  postMessage(message: RenderResponse, transfer?: Transferable[]): void;
}

const scope = self as unknown as WorkerScope;

/**
 * 把一个字符矩阵画进一张新的 OffscreenCanvas，并直接转成 ImageBitmap。
 *
 * 为什么要逐格 fillRect 而不是 putImageData：
 * - putImageData 需要自己算 RGBA，还要处理 alpha 与缩放，写起来慢；
 * - fillRect 在整数缩放下是纯纯的色块，没有插值，天然锐利。
 */
const paintFrame = (
  unit: UnitDef,
  rows: string[],
  pixelScale: number,
): ImageBitmap => {
  const canvas = new OffscreenCanvas(
    unit.width * pixelScale,
    unit.height * pixelScale,
  );
  const ctx = canvas.getContext("2d");

  if (!ctx) {
    throw new Error(`[worker] OffscreenCanvas 2d context 不可用: ${unit.id}`);
  }

  ctx.imageSmoothingEnabled = false;

  rows.forEach((row, rowIndex) => {
    const length = Math.min(row.length, unit.width);

    for (let colIndex = 0; colIndex < length; colIndex += 1) {
      const color = unit.palette[row[colIndex]];
      if (!color) continue;

      ctx.fillStyle = color;
      ctx.fillRect(
        colIndex * pixelScale,
        rowIndex * pixelScale,
        pixelScale,
        pixelScale,
      );
    }
  });

  // transferToImageBitmap 会把画布内容「取走」，画布随即被重置为透明。
  // 所以每次预渲染都新建一张 canvas，逻辑最简单，也不会串帧。
  return canvas.transferToImageBitmap();
};

const renderUnit = (unit: UnitDef, pixelScale: number): UnitBitmaps => ({
  unitId: unit.id,
  frameNames: unit.frames.map((frame) => frame.name),
  width: unit.width * pixelScale,
  height: unit.height * pixelScale,
  bitmaps: unit.frames.map((frame) => paintFrame(unit, frame.rows, pixelScale)),
});

scope.onmessage = (event: MessageEvent<RenderRequest>) => {
  const { units, pixelScale } = event.data;
  const startedAt = performance.now();

  const payload = units.map((unit) => renderUnit(unit, pixelScale));
  // 所有 ImageBitmap 都是 transferable，回传时零拷贝，主线程不产生额外内存峰值
  const transferables = payload.flatMap((item) => item.bitmaps);

  scope.postMessage(
    {
      type: "units-ready",
      payload,
      elapsedMs: performance.now() - startedAt,
    },
    transferables,
  );
};
```

<script setup lang="ts">
  import {
    computed,
    nextTick,
    onBeforeUnmount,
    onMounted,
    ref,
    shallowRef,
    watch,
  } from "vue";
  import PixelStage from "./components/PixelStage.vue";
  import unitsFile from "./data/units.json";
  import type { PreloadMode, PreloadResult, UnitsFile } from "./types/pixel";
  import { disposePreload, preloadUnits } from "./core/preloader";
  import { buildVariantUnits } from "./core/variants";

  defineOptions({
    name: "CustomCanvas",
  });

  const file = unitsFile as unknown as UnitsFile;

  const actorCount = ref(80);
  const variantCount = ref(8);
  const pixelScale = ref(4);
  const mode = ref<PreloadMode>("worker");
  const paused = ref(false);
  const fps = ref(0);
  const preloading = ref(false);
  const errorText = ref("");
  const preloadResult = shallowRef<PreloadResult | null>(null);

  const offscreenSupported =
    typeof Worker !== "undefined" &&
    typeof OffscreenCanvas !== "undefined" &&
    typeof ImageBitmap !== "undefined";

  const renderUnits = computed(() =>
    buildVariantUnits(file, variantCount.value),
  );

  const stats = computed(() => {
    const result = preloadResult.value;
    const items = result?.unitBitmaps ?? [];
    const bitmapCount = items.reduce(
      (sum, item) => sum + item.bitmaps.length,
      0,
    );
    const bytes = items.reduce(
      (sum, item) => sum + item.width * item.height * 4 * item.bitmaps.length,
      0,
    );

    return {
      unitCount: items.length,
      bitmapCount,
      memory: `${(bytes / 1024 / 1024).toFixed(2)} MB`,
      elapsed: result ? `${result.elapsedMs.toFixed(1)} ms` : "—",
      modeLabel: result
        ? result.mode === "worker"
          ? "Worker"
          : "主线程"
        : "—",
    };
  });

  const runPreload = (): void => {
    const previous = preloadResult.value;
    preloadResult.value = null;
    preloading.value = true;
    errorText.value = "";

    // 先让子组件把旧位图从绘制逻辑里摘掉，再统一 close()
    nextTick().then(() => disposePreload(previous));

    preloadUnits(renderUnits.value, pixelScale.value, mode.value)
      .then((result) => {
        preloadResult.value = result;
      })
      .catch((error: unknown) => {
        errorText.value =
          error instanceof Error ? error.message : String(error);
      })
      .finally(() => {
        preloading.value = false;
      });
  };

  watch([variantCount, pixelScale, mode], runPreload);

  onMounted(runPreload);

  // 卸载时释放位图并终止创建它们的 worker，避免空闲 worker 与 GPU 内存泄漏
  onBeforeUnmount(() => {
    disposePreload(preloadResult.value);
  });
</script>
